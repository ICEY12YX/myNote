# 类型推导与引用的关系
在模板参数中使用引用类型时，类型推导会涉及引用折叠规则

```cpp
#include <iostream>
#include <type_traits>

template<typename T>
void deduce_type(T&&) {  //用万能引用接收
    std::cout << std::boolalpha;

    //判断是不是左值引用
    //传入左值或左值引用,T都被推导为int&
    std::cout << "Is T an lvalue reference? "
             << std::is_lvalue_reference<T>::value << std::endl;

    //判断是不是右值引用
    //传入右值或右值引用的时候,T都被推导为int,所以要写T&&,让他统一变成右值引用,来判断
    std::cout << "Is T an rvalue reference? "
             << std::is_rvalue_reference<T&&>::value << std::endl;
}

int main() {
    int a = 5;
    const int& ref = a;  

    deduce_type(a);            // 传左值  T被推导为 int&
    deduce_type(10);           // 传右值  T被推导为 int
    deduce_type(ref);          // 传左值引用(且带const) T被推导为 const int&
    deduce_type(std::move(a)); // 传右值引用(将亡值)  T被推导为 int

    return 0;
}
```

```cpp
#include <iostream>
#include <type_traits>

template<typename T>
void display_type(T&& param) {
    //先判断是不是左值引用,不是左值引用就是右值引用
    //再判断"底层"类型(先剥去引用, 再用is_integral判断)
    std::cout << "Type of T: " 
              << (std::is_lvalue_reference<T>::value ? "lvalue reference" : "rvalue reference") 
              << ", "
              << (std::is_integral<typename std::remove_reference<T>::type>::value ? "Integral" : "Non-Integral")
              << std::endl;
}

int main() {
    int x = 10;
    const int& y = x;
    display_type(x);            // 传左值  T被推导为 int&
    display_type(20);           // 传右值  T被推导为 int&&
    display_type(y);            // 传左值引用  T被推导为 const int&
    display_type(std::move(x)); // 传右值引用  T被推导为 int&&

    return 0;
}
```

# 原样转发
指在模板函数中，将接收到的参数以其原有的值类别（左值或右值）传递给另一个函数

**作用**：
- 保持参数的值类别，确保正确调用函数重载。
- 利用移动语义，避免不必要的拷贝，提升性能。

为什么需要原样转发
在泛型编程中，函数模板可能需要将接收到的参数传递给其他函数。若不使用原样转发，参数会失去原有的值类别信息：
- 右值(引用)参数被当作左值处理，然后就无法利用移动语义。[[44.万能引用和右值]] 最后那个代码
- 无法正确调用目标函数的重载版本。
- 增加不必要的拷贝开销。

原样转发通常结合**模板万能引用**（转发引用）和`std::forward`来实现。
实现一个通用的wrapper函数，通过原样转发将参数传递给目标函数，同时保留参数的值类别
(和上一节最后那串代码一样)
```cpp
#include <iostream>
#include <string>
#include <utility>

// 目标函数，分别有左值和右值的重载
void process(const std::string& s) {
    std::cout << "Processing lvalue: " << s << std::endl;
}

void process(std::string&& s) {
    std::cout << "Processing rvalue: " << s << std::endl;
}

// 通用的包装函数，实现原样转发
template<typename T>
void wrapper(T&& arg) {
    process(std::forward<T>(arg));
}

int main() {
    std::string name = "Alice";
    wrapper(name);                     // 传递左值，调用process(const std::string&)
    wrapper("Bob");                    // 传递右值，调用process(std::string&&)
    wrapper(std::move(name));          // 传递右值，调用process(std::string&&)

    return 0;
}
```


40分钟或48分钟的例子还不错,可以加上
右值传进去  int& v2为什么还是能接收?
因为右值传进去,经过万能引用变右值引用,传过去以后变左值,所以左值引用可以接收

# 泛型工厂函数示例

使用原样转发实现一个泛型工厂函数，完美转发构造函数的参数
```cpp
#include <iostream>
#include <string>
#include <utility>

// 类的定义
class Person {
public:
    std::string name;
    int age;

    // 左值引用构造函数
    Person(const std::string& n, int a) : name(n), age(a) {
        std::cout << "Constructed Person(const std::string&, int)" << std::endl;
    }

    // 右值引用构造函数
    Person(std::string&& n, int a) : name(std::move(n)), age(a) {
        std::cout << "Constructed Person(std::string&&, int)" << std::endl;
    }
};

// 工厂函数，使用原样转发构造函数参数
template<typename T, typename... Args>
T create(Args&&... args) {
    return T(std::forward<Args>(args)...);
}

int main() {
    std::string name = "Alice";

    // 传递左值
    Person p1 = create<Person>(name, 30); 
    // 传递右值
    Person p2 = create<Person>(std::string("Bob"), 25); 

    return 0;
}
```

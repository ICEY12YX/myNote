# 模板特化
允许开发者为特定类型或类型组合提供专门的实现

注意:
    函数模板不支持偏特化，只能进行全特化(就是重载)

## 全特化
当模板参数完全匹配特化类型时，编译器将优先使用该特化版本

```cpp
// 通用模板
template <typename T>
class MyClass {
    // 通用实现
};

// 全特化
template <>
class MyClass<SpecificType> {
    // 仅针对 SpecificType这一个类的专门实现
};
```

给`std::string`实现全特化
```cpp
#include <iostream>
#include <string>

// 通用类模板
template <typename T>
class Printer {
public:
    void print(const T& value) {
        std::cout << "General Printer: " << value << std::endl;
    }
};

// 类模板全特化
template <>
class Printer<std::string> {
public:
    void print(const std::string& value) {
        std::cout << "String Printer: " << value << std::endl;
    }
};

int main() {
    Printer<int> intPrinter;
    intPrinter.print(100); // 输出：General Printer: 100

    Printer<std::string> stringPrinter;
    stringPrinter.print("Hello, World!"); // 输出：String Printer: Hello, World!

    return 0;
}
```

## 偏特化
允许模板对部分参数进行特定类型的处理，同时保持其他参数的通用性
    部分参数 就是比如下面T还是通用的,而对U有特殊处理

```cpp
// 通用模板
template <typename T, typename U>
class MyClass {
    // 通用实现
};

// 偏特化：当 U 是指针类型时
template <typename T, typename U>  //偏特化这里和通用版本一样的
class MyClass<T, U*> {  //偏特化,这里要加个尖括号
    // 针对 U* 的实现
};
```

```cpp
#include <iostream>
#include <string>

// 通用 Pair 类模板
template <typename T, typename U>
class Pair {
public:
    T first;
    U second;

    Pair(T a, U b) : first(a), second(b) {}

    void print() const {
        std::cout << "Pair: " << first << ", " << second << std::endl;
    }
};

// 类模板偏特化：当第二个类型是指针时
template <typename T, typename U>
class Pair<T, U*> {
public:
    T first;
    U* second;

    Pair(T a, U* b) : first(a), second(b) {}

    //因为传进来时指针,所以需要*取内容
    void print() const {
        std::cout << "Pair with pointer: " << first << ", " << *second << std::endl;
    }
};

int main() {
    Pair<int, double> p1(1, 2.5);
    p1.print(); // 输出：Pair: 1, 2.5

    double value = 3.14;
    Pair<std::string, double*> value("Pi", &value);  //优先匹配特例化版本
    p2.print(); // 输出：Pair with pointer: Pi, 3.14

    return 0;
}
```

# 函数模板的特化(only 全特化)
**函数模板不支持偏特化**，只能进行全特化

和上面模版全特化差不多
```cpp
#include <iostream>
#include <string>

// 通用函数模板
template <typename T>
void printValue(const T& value) {
    std::cout << "General print: " << value << std::endl;
}

// 函数模板全特化
template <>
void printValue<std::string>(const std::string& value) {  //这里要尖括号显示写上T的类型
    std::cout << "Specialized print for std::string: " << value << std::endl;
}

int main() {
    printValue(42); // 调用通用模板，输出：General print: 42
    printValue(3.14); // 调用通用模板，输出：General print: 3.14
    printValue(std::string("Hello")); // 调用全特化模板，输出：Specialized print for std::string: Hello
    return 0;
}
```

# 变参模版(可变参数列表)

允许模板接受可变数量的参数  
其实就是个语法糖
```cpp
//类模版
template <typename... Args>   //Args这个只是变量名,可以自己定义
class MyClass { /* ... */ };

//函数模版
template <typename T, typename... Args>
void myFunction(T first, Args... args) { /* ... */ }
```

变参模板通常与<mark style="background: #FFF3A3A6;">递归</mark>相结合
打印所有参数
```cpp
#include <iostream>

// 基础情况：无参数
void printAll() {
    std::cout << std::endl;  //打印一个换行
}

// 递归情况：至少一个参数
template <typename T, typename... Args>
void printAll(const T& first, const Args&... args) {
    std::cout << first << " ";  //先打印第一个类型的值
    printAll(args...); // 递归调用(注意三个点)
    //(之后递归传进来args中第一个参数变为了T,直到最后args里只有一个参数,那这里传进来就是空的,就用到上面无参数的printAll版本)
}

int main() {
    printAll(1, 2.5, "Hello", 'A'); // 输出：1 2.5 Hello A 
    return 0;
}
```

C++17之前这样写,17之后有了折叠表达式
```cpp
#include <iostream>

// 使用折叠表达式的printAll
template <typename... Args>
void printAll(const Args&... args) {
    // 使用左折叠展开参数包，并在每个参数之后输出一个空格
    ((std::cout << args << " "), ...);
    std::cout << std::endl;
}

int main() {
    printAll(1, 2.5, "Hello", 'A'); // 输出：1 2.5 Hello A 
    return 0;
}
```
(折叠表达式下一讲会详细讲)
`((std::cout << args << " "), ...);` 这句意思是先执行`std::cout << args << " "`,把args当普通参数用
然后想把args展开,每个参数都执行上面的输出操作那就把上面的操作括起来,然后用...
注意中间有个逗号,
<mark style="background: #FFF3A3A6;">还有外面还有个( ) 折叠表达式外层要加( )</mark>

上面例子用处
日志打印
```cpp
#include <iostream>
#include <string>

// 基础情况：无参数
void log(const std::string& msg) {
    std::cout << msg << std::endl;
}

// 递归情况：至少一个参数
template <typename T, typename... Args>
void log(const std::string& msg, const T& first, const Args&... args) {
    std::cout << msg << ": " << first << " ";
    log("", args...); // 递归调用，省略消息前缀
}

int main() {
    log("Error", 404, "Not Found");
    // 输出：Error: 404 Not Found 

    log("Sum", 10, 20, 30);
    // 输出：Sum: 10 20 30 
    return 0;
}
```

另外的例子
计算总和(用折叠表达式)
```cpp
#include <iostream>

template <typename... Args>
auto sum(Args... args) -> decltype((args + ...)) {
    return (args + ...); // 左折叠
}

int main() {
    std::cout << sum(1, 2, 3, 4) << std::endl; // 输出：10
    std::cout << sum(1.5, 2.5, 3.0) << std::endl; // 输出：7
    return 0;
}
```
`auto sum(Args... args) -> decltype((args + ...))` 用到decltype的尾置返回类型的写法
因为我们返回的是所有args中的参数加起来的值,我们并不确定返回类型
可能是int+double+string 或int+double
[[decltype]]

`args + ...` 就是args中所有参数都指向加法操作
<mark style="background: #FFF3A3A6;">还有外面还有个( ) 折叠表达式外层要加( )</mark>

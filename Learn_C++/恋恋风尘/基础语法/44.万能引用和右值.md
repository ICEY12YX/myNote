# 左值与右值

- **左值（lvalue）**：
    - 具有持久存储的对象。
    - <mark style="background: #FFF3A3A6;">可以出现在左侧(也可以出现在右边)</mark>
    - 可以被取地址（即，可以使用`&`运算符）。
    - 示例：变量名、引用等。
- **右值（rvalue）**：
    - 表示临时对象或没有持久存储的值。
    - <mark style="background: #FFF3A3A6;">一定出现在赋值语句的右侧,不能在左侧</mark>
    - 不能被取地址。
    - 示例：字面量、临时对象、表达式结果等。

C++11进一步细化了右值的分类：
- **纯右值（prvalues）**：表示<mark style="background: #FFF3A3A6;">临时对象或字面量</mark>，如`42`、`3.14`、`"Hello"`。
- **将亡值（xvalues，expiring values）**：表示即将被移动的对象，如`std::move`的结果。
```cpp
int a = 10;
int b = std::move(a);  //这个std::move(a)就是将亡值
```

举例
```cpp
#include <iostream>
#include <string>
#include <utility>  //工具库,可以判断某变量是左值右值等

int main() {
    int a = 10;           // a是一个左值
    int& b = a;           // b是a的左值引用
    int&& c = 20;         // c是一个右值引用，绑定到临时右值20
    //左值引用肯定和左值绑定
    //右值引用肯定和右值绑定

    int d = a + 5;        // (a + 5)是一个纯右值

    std::string s1 = "Hello";                   // s1是一个左值
    std::string s2 = std::string("World");      // std::string("World")是一个纯右值

    std::cout << "a: " << a << ", d: " << d << std::endl;
    std::cout << "s1: " << s1 << ", s2: " << s2 << std::endl;

    // 检查类型
    std::cout << std::boolalpha;  
    
    // 使用 decltype((a)) 获取 a 的类型，包括引用
    // `(a)` 是一个左值表达式，所以 decltype((a)) 是 `int&`
    std::cout << "a 是左值: " << std::is_lvalue_reference<decltype((a))>::value << std::endl;
    std::cout << "b 是左值引用: " << std::is_lvalue_reference<decltype((a))>::value << std::endl;
    std::cout << "c 是右值引用: " << std::is_rvalue_reference<decltype(c)>::value << std::endl;

    return 0;
}
```

# 类型判断工具

C++标准库提供了几个类型特性（type traits）用于判断表达式的值类别：
`std::is_lvalue_reference<T>`：判断类型T是否为左值引用。
`std::is_rvalue_reference<T>`：判断类型T是否为右值引用。

```cpp
#include <iostream>
#include <type_traits>

void func(int& x) {  //接收左值或左值引用
    std::cout << "func(int&)" << std::endl;
}

void func(int&& x) {  //接收右值或右值引用
    std::cout << "func(int&&)" << std::endl;
}

int main() {
    int a = 5;
    const int& ref = a;

    // 调用函数
    func(a);          // 调用func(int&)
    func(10);         // 调用func(int&&)

    return 0;
}
```
这里左值传进接收左值引用的函数
并不是隐式类型转换，而是C++引用绑定的基本规则

# 模板万能引用（转发引用）

模板万能引用
- 表现形式为`T&&`，其中`T`是模板参数。
- 在特定条件下，编译器会将其解析为左值引用或右值引用。
- 能够统一处理左值和右值，适用于泛型编程中的参数传递。

当模板参数T被推导为普通类型(int 或 string)时，T&&是右值引用。
当模板参数T被推导为引用类型(int& 或 string&)时，T&&会根据引用折叠规则解析为左值引用。

int &&  -> T就是右值引用 int&&
int& && ->int& (引用折叠)   T就是左值引用类型
int&& && ->int&& (引用折叠)

# 引用折叠规则

`&  &`、`&  &&`、`&&  &` 都折叠为 &（左值引用）。
`&&  &&` 折叠为 &&（右值引用）。
`( )  &&` 那就是右值引用      <-就是前面那个不是引用类型

```cpp
#include <type_traits>
#include <iostream>

//注意是和模版结合着用的
template<typename T>  
void check_reference(T&& x){  //用万能引用
    std::cout << std::boolalpha;
    std::cout << "T is lvalue reference: " 
            << std::is_lvalue_reference<T>::value << std::endl;
            
    std::cout << "T is rvalue reference: " 
            << std::is_rvalue_reference<T>::value << std::endl;
            
    std::cout << "T is rvalue : " 
            << std::is_rvalue_reference<T&&> ::value << std::endl;
            
    std::cout << "x is lvalue reference: " 
            << std::is_lvalue_reference<decltype(x)>::value << std::endl;
            
    std::cout << "x is rvalue reference: " 
            << std::is_rvalue_reference<decltype(x)>::value << std::endl;
}

//注意,因为没有直接判断左值或右值的函数
//所以用到std::is_rvalue_reference<T&&> ::value判断右值
//因为左值,T被推导为 int&,T&& -> int& && -> int&
//右值,T被推导为 int，  T&& -> int&&  返回true

int main() {
    int a = 10;
    //分别传左值和右值进去
    //用万能引用接收他们
    check_reference(a);          // T被推导为 int&， 因此 T&& -> int& && -> int&
    check_reference(20);         // T被推导为 int，  T&& -> int&&

    return 0;
}
```

**模板万能引用**结合原样转发
```cpp
#include <iostream>
#include <string>
#include <utility>

// 目标函数，分别有左值和右值的重载
void process(int& x){  //接收左值或左值引用
    std::cout << "process(int&)" << std::endl;
}

void process(int&& x){  //接收右值或右值引用
    std::cout << "process(int&&)" << std::endl;
}

// 通用的包装函数，内部使用原样转发
template<typename T>
void wrapper(T&& arg) {  //万能引用接收
    process(std::forward<T>(arg)); // 原样转发

    //左值传进来 T为int&,折叠后为int&
    //所以arg是左值引用,所以是第一个process接收
    //右值传进来 T为int,折叠后为int&&
    //所以arg是右值引用,所以是第二个process接收
}

int main() {
    int a = 10;
    wrapper(a);          // 传递左值，调用process(int&)
    wrapper(20);         // 传递右值，调用process(int&&)
    return 0;
}
```
为什么要写成`process(std::forward<T>(arg));`
而不是直接`process(arg);`
    传左值的时候 比如`wrapper(a)` 是没事的
    但是传右值的时候就会有区别
    右值传进wrapper
    T为int 折叠为int&&  所以arg为int&&  就是右值引用
    而此时这个右值引用有名字(arg)
    所以传进process会被当做左值,所以是第一个函数接收
    所以使用`std::forward`有利于保持数据原样转发

当传右值进入wrapper的时候,T推导为int,折叠后为int&&  所以arg是int&&
但是这样的话`std::forward`就变成`std::forward<int>(arg)` 那就不是转发右值引用了
    ![[Pasted image 20250704195920.png]]
    ![[Pasted image 20250704195833.png]]

(下面那个大概理解)
```cpp
template<typename T>
T&& forward(typename std::remove_reference<T>::type& arg) {
    return static_cast<T&&>(arg);  // 关键：万能引用的折叠
}
```
对这个原理的解释
    ![[Pasted image 20250704202618.png]]
    (上面说的T从调用处的万能引用推导来,应该说的是上一层,比如上面的  从main到wrapper经过了一层推导)
    ![[Pasted image 20250704202754.png]]
    所以arg永远是int&
    返回类型是T&&  那左值传进来  返回左值引用
    右值传进来  返回右值引用
    ![[Pasted image 20250704202826.png]]
    ![[Pasted image 20250704203425.png]]

所以传左值  就变成这样
```cpp
int& forward(int& arg) {
    return static_cast<int&>(arg);  // 保持左值
}
```
传右值  就变成这样
```cpp
int&& forward(int& arg) {
    return static_cast<int&&>(arg);  // 转为右值
}
```

# 什么是SFINAE
 “Substitution Failure Is Not An Error”（替换失败不是错误）
 在模板实例化过程中，编译器会尝试将模板参数替换为具体类型。如果在替换过程中出现不合法的表达式或类型，编译器不会报错，而是将该模板视为不可行的，继续尝试其他模板或重载。

# SFINAE的应用场景
1. **函数重载选择**：根据参数类型的不同选择不同的函数实现。
2. **类型特性检测**：检测类型是否具有某些成员或特性，从而决定是否启用某些功能。
3. **条件编译**：根据模板参数的特性决定是否编译某些代码段。

## std::enable_if

通过std::enable_if实现函数重载
```cpp
#include <type_traits>  //调用std::is_integral需要这个头文件
#include <iostream>

// 适用于整数类型
template <typename T>
typename std::enable_if<std::is_integral<T>::value, void>::type
print_type(T value) {
    std::cout << "Integral type: " << value << std::endl;
}

// 适用于浮点类型
template <typename T>
typename std::enable_if<std::is_floating_point<T>::value, void>::type
print_type(T value) {
    std::cout << "Floating point type: " << value << std::endl;
}

// 检测是不是C风格字符串
template <typename T>
typename std::enable_if<std::is_same<T, const char*>::value ||
                        std::is_same<T, char*>::value, void>::type
print_type(T value) {
    std::cout << "C-style string type: " << value << std::endl;
}

//检查是不是string
template <typename T>
typename std::enable_if<std::is_same<T, std::string>::value, void>::type
print_type(T value) {
    std::cout << "string type: " << value << std::endl;
}

//检查是不是指针类型,除了char*类型
template <typename T>
typename std::enable_if<std::is_pointer<T>::value && 
                        !std::is_same<T, const char*>::value &&
                        !std::is_same<T, char*>::value, void>::type
print_type(T value) {
    std::cout << "pointer type: " << value << std::endl;
}

//默认的版本
//但是这样写,编译器可能会当成重载,就是可能上面匹配上的时候,这个也匹配上,那就重复了
//要写的话,就要上面一样条件判断一下,就是不是上面任何一种类型,然后这个才能匹配上
//template <typename T>
//void print_type(T value) {
//    std::cout << "Other type" << value << std::endl;
//}

int main() {
    print_type(10);      // 输出: Integral type: 10
    print_type(3.14);    // 输出: Floating point type: 3.14

    const char* cstr = "hello";
    print_type(cstr);

    std::string str = "fanfanfan"
    print_type(str); 

    int p = 10;
    int* i = &p;
    print_type(i); 
    
    return 0;
}
```

```cpp
template <typename T>
concept Intergral = std::is_integral_v<T>;

template <typename T>
concept FloatingPoint = std::is_floating_point_v<T>;

template <typename T>
concept CString = std::is_same_v<T, const char*> || std::is_same_v<T, char*>;

template <typename T>
concept stdString = std::is_same_v<T, std::string>;

template <typename T>
concept Pointertype = std::is_pointer_v<T> && !std::is_same_v<T, const char*> && !std::is_same_v<T, char*>;

void cout_type(Intergral auto value) {
	std::cout << "Intergral type" << std::endl;
}

void cout_type(FloatingPoint auto value) {
	std::cout << "FloatingPoint type" << std::endl;
}

void cout_type(CString auto value) {
	std::cout << "CString type" << std::endl;
}

void cout_type(stdString auto value) {
	std::cout << "stdString type" << std::endl;
}

void cout_type(Pointertype auto value) {
	std::cout << "Pointertype type" << std::endl;
}

template <typename T>
	requires (!Intergral<T> && !FloatingPoint<T> && !CString<T> && !stdString<T> && !Pointertype<T>)
void cout_type(T value) {
	std::cout << "Other type" << std::endl;
}
```

## 检测类型是否具有特定成员

```cpp
#include <type_traits>
#include <iostream>

// 辅助类型，检测类类型(下面的WithFoo,WithoutFoo)是否存在成员函数 foo
template <typename T>
class has_foo {
private:
    typedef char yes[1];
    typedef char no[2];

    template <typename U, void (U::*)()>
    struct SFINAE {};

    template <typename U>
    static yes& test(SFINAE<U, &U::foo>*);

    template <typename U>
    static no& test(...);

public:
    static constexpr bool value = sizeof(test<T>(0)) == sizeof(yes);
};

// 函数仅在 T 有 foo() 成员时启用
template <typename T>
typename std::enable_if<has_foo<T>::value, void>::type
call_foo(T& obj) {
    obj.foo();
    std::cout << "foo() called." << std::endl;
}

class WithFoo {
public:
    void foo() { std::cout << "WithFoo::foo()" << std::endl; }
};

class WithoutFoo {};

int main() {
    WithFoo wf;
    call_foo(wf); // 输出: WithFoo::foo() \n foo() called.

    // WithoutFoo wf2;
    // call_foo(wf2); // 编译错误，没有匹配的函数
    return 0;
}
```
大体情况是
首先我们想检测类类型(下面的WithFoo,WithoutFoo)是否存在成员函数 foo
所以写了有foo成员函数的WithFoo  和  WithoutFoo
然后写了模版类has_foo类测试类里有没有成员函数 foo
最后用一个函数模版call_foo接收WithFoo  和  WithoutFoo 并且通过模版类has_foo类判断有没有foo
有foo就执行

call_foo的调用比较好理解,和上面`std::enable_if`的运用差不多
重点是has_foo类
(注意到has_foo类的调用和上面的std::is_integral差不多,所以可能他们实现原理是一样的)

# 通过模板特化实现不同的行为

```cpp
#include <type_traits>
#include <iostream>

//先需要声明一下,否则报错
//因为下面两个算偏特化的版本
template <typename T ,typename = void>
struct TypePrinter;

// T 有不是 void 的 `value_type`   后面就返回true
template <typename T>
struct TypePrinter<T, typename std::enable_if<!std::is_void
                            <typename T::value_type>::value>::type>
//注意上面std::is_void_v<typename T::value_type> 有个typename
//不写typename 一般是这种情况std::is_integral<T>

//这里完整写法是
//std::enable_if<!std::is_void<typename T::value_type>::value, void>::type
//第二个参数默认就是void
//然后std::enable_if<...>::type就是返回第二个参数
//详见下面的解释
{
    static void print(){
        std::cout << "T has a member type 'value_type'." << std::endl;
    }
};

// T 没有 `value_type` 或 `value_type` 是 void
template <typename T>
struct TypePrinter<T, void> {
    static void print(){
        std::cout << "hello world! T does not have a member type 'value_type'." << std::endl;
    }
};

// 测试结构体
struct WithValueType{
    using value_type = int;
};

struct WithoutValueType{};

struct WithVoidValueType{
    using value_type = void;
};

int main() {
    TypePrinter<WithValueType>::print();        // 输出: T has a member type 'value_type'.
    TypePrinter<WithoutValueType>::print();     // 输出: hello world! T does not have a member type 'value_type'.
    TypePrinter<WithVoidValueType>::print();    // 输出: hello world! T does not have a member type 'value_type'.
    return 0;
}
```

但是上面代码是不对的,main里三个调用都会走到`struct TypePrinter<T, void>`版本
因为上面我们写了`template <typename T, typename = void>` 所以只传一个类型的时候,第二个类型就会默认为void
所以就都走到`struct TypePrinter<T, void>`这个版本里了
所以要写成下面这个样子

```cpp
#include <type_traits>
#include <iostream>

//和上面一样,需要先有主模版
// 1. 定义一个 Trait 用于检测 T 是否有非 void 的 `value_type`
template <typename T, typename = void>  //因为用不到后面的typename,所以没有变量名
struct has_non_void_value_type : std::false_type {};
//因为继承std::false_type,所以此时has_non_void_value_type<T>::value 为false

// 仅当 T 有 `value_type` 且 `value_type` 不是 void 时，特化为 std::true_type
template <typename T>
struct has_non_void_value_type<T, std::enable_if_t<!std::is_void_v
                            <typename T::value_type>>> : std::true_type {};
//因为继承std::true_type,所以此时has_non_void_value_type<T>::value 为true

// 2. 定义 TypePrinter 主模板，使用一个布尔参数控制特化
template <typename T, bool HasValueType = has_non_void_value_type<T>::value>
struct TypePrinter;

// 3. 特化：当 HasValueType 为 true 时，表示 T 有非 void 的 `value_type`
template <typename T>
struct TypePrinter<T, true> {
    static void print(){
        std::cout << "T has a member type 'value_type'." << std::endl;
    }
};

// 特化：当 HasValueType 为 false 时，表示 T 没有 `value_type` 或 `value_type` 是 void
template <typename T>
struct TypePrinter<T, false> {
    static void print(){
        std::cout << "hello world! T does not have a member type 'value_type'." << std::endl;
    }
};

// 测试结构体
struct WithValueType{
    using value_type = int;
};

struct WithoutValueType{};

struct WithVoidValueType{
    using value_type = void;
};

int main() {
    TypePrinter<WithValueType>::print();        // 输出: T has a member type 'value_type'.
    TypePrinter<WithoutValueType>::print();     // 输出: hello world! T does not have a member type 'value_type'.
    TypePrinter<WithVoidValueType>::print();    // 输出: hello world! T does not have a member type 'value_type'.
    return 0;
}
```

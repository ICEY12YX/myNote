上一节有局限
每次pop都要从风险数组中选择一个空闲的节点作为标记。
其次删除节点前要遍历风险数组对比节点是否被风险指针所指涉，如果被风险指针指涉则需放入待删列表。
最后pop结束时也要回收待删列表中的节点，还要依次将待删列表中的节点和风险数组对比，如果未被风险指针指涉则需删除，否则跳过。

栈结构
```cpp
template<typename T>
class single_ref_stack {
public:
    single_ref_stack():head(nullptr) {}

    ~single_ref_stack() {
        //循环出栈
        while (pop());
    }

private:
    struct ref_node {
        //1 数据域智能指针
        std::shared_ptr<T> _data;
        //2 引用计数
        std::atomic<int> _ref_count;
        //3  下一个节点
        ref_node* _next;
        ref_node(T const& data_) : _data(std::make_shared<T>(data_)),
            _ref_count(1), _next(nullptr) {}
    };

    //头部节点
    std::atomic<ref_node*> head;
};
```

push
```cpp
void push(T const& data) {
    auto new_node = new ref_node(data);
    new_node->next = head.load();
    while (!head.compare_exchange_weak(new_node->next, new_node));
}
```

```cpp
std::shared_ptr<T> pop() {
    ref_node* old_head = head.load(); //用指针,保证所有线程这里数据一致
    for (;;) {
        if (!old_head) {
            return std::shared_ptr<T>();  //不加makeshared?
        }
        //1 只要执行pop就对引用计数+1
        ++(old_head->_ref_count);
        //2 比较head和old_head相等则交换否则说明head已经被其他线程更新
        if (head.compare_exchange_strong(old_head, old_head->_next)) {
            auto cur_count = old_head->_ref_count.load();
            auto new_count;
            //3  循环重试保证引用计数安全更新
            do {
                //4 减去本线程增加的1次和初始的1次
                new_count = cur_count - 2;  //要是-2以后等于0说明没有其他进程访问old_head结点
            } while (!old_head->_ref_count.compare_exchange_weak(cur_count,  new_count)); //因为可能其他线程给old_head->_ref_count++了
            //那这个线程cur_count就不等于这时候的old_head->_ref_count
            //就要再循环一次
            
            //返回头部数据
            std::shared_ptr<T> res;
            //5  交换数据
            res.swap(old_head->_data);
            //6
            if (old_head->_ref_count == 0) {
                delete old_head;
            }

            return res;
        }
        else {
            //7 
            //fetch_sub是先对old_head->_ref_count-1,然后返回减之前的
            //这里会发生问题?见下
            if (old_head->_ref_count.fetch_sub(1) == 1) {
                //old_head-1,就是减掉上面if之前加的1
                //如果减1之前是1,那说明此时没有线程需要old_head

                //原本设计初衷
                //比如两个线程让old_head引用计数是3,有一个线程成功进入上面的if,
                //就会让old_head->_ref_count - 2  变1  不等于0
                //那上面就不会delete old_head
                //这里delete old_head
                //但是实际并不会这样做,见下
                delete old_head;
            }
        }
    }
}
```

问题
    线程1,2都访问到同一个old_head  然后都指向到`++(old_head->_ref_count);`
    那此时`old_head->_ref_count` 就是3
    线程1先执行`if (head.compare_exchange_strong(old_head, old_head->_next))` 进if
    那此时`head`就是`old_head->_next`
    执行`!old_head->_ref_count.compare_exchange_weak(cur_count,  new_count)` ,然后成功退出了循环
    那此时`old_head->_ref_count` 就是1
    然后线程2执行`if (head.compare_exchange_strong(old_head, old_head->_next))`,head此时不等于old_head
    那old_head就会等于head  即old_head等于`old_head->_next`
    然后会进else
    此时执行`if (old_head->_ref_count.fetch_sub(1) == 1)` 返回true了,就把这个old_head删掉了
    结果就是线程1成功pop了一个元素,还没删
    线程2没pop元素,但删了
    (但是线程1,线程2操作的元素位置是对的,线程2那个元素应该删,但是应该pop元素之后再删)

结论  (可以直接看下面的代码理解)
1. head的类型修改为ref_node类型而不是指针。就是用副本  用拷贝(这个记住就好,为什么我也不知道)

2. 现有的引用保留，我们用其表示增加的引用计数，该引用计数可以用原子类型，也可以不用原子类型。为简化和节省效率我们用普通int类型。

3. 新增一个表示减少的引用计数，因为这个表示减少的引用计数要在多个线程中同步，并且要保证安全性，那我们将其放入node类里, 因为node类的指针被存储在栈的节点中，所以可以达到多个线程修改这个减少的引用计数的效果。(这个是线程局部的)

4. 一个节点能否被回收取决于整体的引用计数是否为0。

解释
    假设线程1,线程2先都执行了`ref_node old_head = head.load();`
    线程1执行do while,成功, 执行了`head.compare_exchange_weak(old_head, new_head)`和`old_head = new_head;` 
    所以head和old_head1的_ref_count是2
    线程2执行到`!head.compare_exchange_weak(old_head, new_head)` 不等于,所以old_head2等于head, old_head2的_ref_count是2
    线程2再执行一次循环,然后head和ld_head2的_ref_count是3
    线程1继续执行`if (head.compare_exchange_strong(old_head, node_ptr->_next))`
    失败,head的_ref_count和old_head的_ref_count不等了,然后old_head1的_ref_count会等于3,就和head平齐,然后进入else
    线程2这里成功,head变为`node_ptr->_next`  head的_ref_count就是1了
    继续执行 `int increase_count = old_head._ref_count - 2;` 得到increase_count=1  (就是说除自己还有1个线程在访问这个节点)
    此时线程1往下执行 到else
    `node_ptr->_dec_count`初始是0,fetch_sub(1)以后`node_ptr->_dec_count`等于-1
    (if条件不满足,所以不delete node_ptr)
    然后线程1会进入下一次for循环
    线程2执行`node_ptr->_dec_count.fetch_add(increase_count) == -increase_count`
    `node_ptr->_dec_count`是-1  加上increase_count  是0  
    加之前的-1和-increase_count相等, 则此时可以删node_ptr

为什么此时可以删node_ptr?

所以`node_ptr->_dec_count.fetch_sub` 可以看做别的线程自动放弃争夺这个节点
`if (node_ptr->_dec_count.fetch_add(increase_count) == -increase_count) `可以看做是否除了我之外在用这个节点的线程都已经放弃这个节点了




完整代码
```cpp
#pragma once
#include <atomic>

template<typename T>
class single_ref_stack {
public:
	single_ref_stack(){}

	~single_ref_stack() {
		//循环出栈
		while (pop());
	}

	void push(T const& data) {
		auto new_node = ref_node(data);
		new_node._node_ptr->_next = head.load();
		while (!head.compare_exchange_weak(new_node._node_ptr->_next, new_node));
	}

	std::shared_ptr<T> pop() {
		ref_node old_head = head.load();
		for (;;) {
			//1 只要执行pop就对引用计数+1并更新到head中
			ref_node new_head;
			do {
				new_head = old_head;
				new_head._ref_count += 1;
			} while (!head.compare_exchange_weak(old_head, new_head));

			old_head = new_head;

			auto* node_ptr = old_head._node_ptr;
			if (node_ptr == nullptr) {
				return  std::shared_ptr<T>();
			}

			//2 比较head和old_head想等则交换否则说明head已经被其他线程更新
			if (head.compare_exchange_strong(old_head, node_ptr->_next)) {
				
				//要返回的值
				std::shared_ptr<T> res;
				//交换智能指针
				res.swap(node_ptr->_data);

				//增加的数量
				int increase_count = old_head._ref_count - 2;
				
				if (node_ptr->_dec_count.fetch_add(increase_count) == -increase_count) {
					delete node_ptr;
				}

				return res;
			}else {
				if (node_ptr->_dec_count.fetch_sub(1) == 1) {
					delete node_ptr;
				}
			}
		}
	}

private:
	struct ref_node;
	struct node {
		//1 数据域智能指针
		std::shared_ptr<T> _data;
		//2  下一个节点
		ref_node _next;
		node(T const& data_) : _data(std::make_shared<T>(data_)) {}

		//减少的数量
		std::atomic<int>  _dec_count;
	};

	struct ref_node {
		// 引用计数
		int _ref_count;
	
		node* _node_ptr;
		ref_node( T const & data_):_node_ptr(new node(data_)), _ref_count(1){}

		ref_node():_node_ptr(nullptr),_ref_count(0){}
	};

	//头部节点
	std::atomic<ref_node> head;
};

```

```cpp
void TestSingleRefStack() {
    single_ref_stack<int> single_ref_stack;
    std::set<int> rmv_set;
    std::mutex set_mtx;

    std::thread t1([&]() {
        for (int i = 0; i < 20000; i++) {
            single_ref_stack.push(i);
            std::cout << "push data " << i << " success!" << std::endl;
            std::this_thread::sleep_for(std::chrono::milliseconds(5));
        }
        });

    std::thread t2([&]() {

            auto head = single_ref_stack.pop();
            if (!head) {
                std::this_thread::sleep_for(std::chrono::milliseconds(10));
                continue;
            }
            std::lock_guard<std::mutex> lock(set_mtx);
            rmv_set.insert(*head);
            std::cout << "pop data " << *head << " success!" << std::endl;
            i++;
        }
        });

    std::thread t3([&]() {
        for (int i = 0; i < 10000;) {
            auto head = single_ref_stack.pop();
            if (!head) {
                std::this_thread::sleep_for(std::chrono::milliseconds(10));

            }
            std::lock_guard<std::mutex> lock(set_mtx);
            rmv_set.insert(*head);
            std::cout << "pop data " << *head << " success!" << std::endl;
            i++;
        }
        });

    t1.join();
    t2.join();
    t3.join();

    assert(rmv_set.size() == 20000);
}
```

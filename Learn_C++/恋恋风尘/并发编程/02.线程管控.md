# 线程归属权

每个线程都应该有其归属权，也就是归属给某个变量管理
```cpp
void some_function() {

}

std::thread t1(some_function);
```
t1是一个线程变量，管理一个线程，该线程执行`some_function()`
<mark style="background: #FFF3A3A6;">对于std::thread C++ 不允许其执行拷贝构造和拷贝赋值(不然会报错),</mark> 
所以只能通过移动和局部变量返回的方式将  线程变量管理的线程  转移给其他变量管理
比如可以使用`std::mutex`, `std::ifstream`, `std::unique_ptr`

随意移动线程归属权,没充分考虑的话,会出问题
```cpp
void some_function() {
    //这个做的事情就是  循环睡觉1s
    while (true) {
        std::this_thread::sleep_for(std::chrono::seconds(1));
        //固定的睡眠语句
    }
}

void some_other_function() {
    while (true) {
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}

int main() {
    //1 t1 绑定some_function
    std::thread t1(some_function); 

    //2 转移t1管理的线程给t2，转移后t1无效
    std::thread t2 = std::move(t1);

    //3 t1 可继续绑定其他线程(因为上面t1被move了),执行some_other_function
    t1 = std::thread(some_other_function);

    //4  创建一个线程变量t3
    std::thread t3;
    //5  转移t2管理的线程给t3
    t3 = std::move(t2);
    //6  转移t3管理的线程给t1
    //   但是t1上面有绑定新的线程了,所以这里会崩溃
    t1 = std::move(t3);

    //这里我们没有给子线程join和detach
    //所以防止因为main执行完,线程没执行完的崩溃
    std::this_thread::sleep_for(std::chrono::seconds(2000));
}
```

和`std::unique_ptr`一样，我们可以在函数内部返回一个局部的`std::thread`变量
```cpp
//1................................................(安全的)
void some_function() {
    //这个做的事情就是  循环睡觉1s
    while (true) {
        std::this_thread::sleep_for(std::chrono::seconds(1));
        //固定的睡眠语句
    }
}

//这个函数 内部创建一个线程,并返回这个线程
std::thread  f() {
    return std::thread(some_function);
}

auto t = f();

//2...............................................(安全的)
void param_function(int a) {
    while (true) {
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}

//这个函数 内部创建一个线程,并返回这个线程
std::thread g() {
    std::thread t(param_function, 43);
}

auto t2 = g();
```

# joining_thread

上一节我们写了`class thread_guard` 让线程可以做到在主进程结束之前  线程"自动提前"join出来
但是里面是用`std::thread& _t;` 引用存的进程
能不能直接存进程?
可以的
实现一个类似joining_thread类
```cpp
class joining_thread {
    std::thread  _t;
public:
    joining_thread() noexcept = default;  //默认的构造函数

    //模版,会传进来一个可调用对象Callable(函数,仿函数,lambda) 和 一些参数
    template<typename Callable, typename ...  Args>

    //有参的构造函数
    //因为要兼容左值,右值,所以用到万能引用
    //并且用原样转发把数据给线程
    explicit joining_thread(Callable&& func, Args&& ...args):
        _t(std::forward<Callable>(func),  std::forward<Args>(args)...){}

    //另外一种构造函数,把传进来的线程,move进joining_thread类的_t
    explicit joining_thread(std::thread t) noexcept: _t(std::move(t)){}
    
    //另外一种构造函数,传进来的是本类型
    //用右值引用接收右值,用move剥离other的_t(实现移动构造)
    //注意这里不是万能引用,而是右值引用(用模版的才是右值引用)
    joining_thread(joining_thread&& other) noexcept: _t(std::move(other._t)){}

    //重载赋值运算符  (接收右值引用,所以可以叫移动赋值)
    joining_thread& operator=(joining_thread&& other) noexcept
    {
        //如果当前线程可汇合，则汇合等待线程完成再赋值
        //防止当前线程变量已经绑定了一个线程了
        //要是再绑一个线程,而之前的线程没有运行完,就会崩溃
        if (joinable()) {
            join();
        }
        _t = std::move(other._t);
        return *this;  
        //this是指针,*this返回实例内容
        //要返回joining_thread&(引用类型),所以返回*this
    }

    //重载赋值运算符 (接收左值)
    joining_thread& operator=(joining_thread other) noexcept
    {
        //如果当前线程可汇合，则汇合等待线程完成再赋值
        if (joinable()) {  //这里之所以可以直接joinable(),因为下面写了"重载"
            //而且能直接joinable()这样调用,应该C++的特性,就是省略this->
            join();
        }
        _t = std::move(other._t);
        return *this;
    }

    //和上一节的thread_guard的析构一样
    ~joining_thread() noexcept {
        if (joinable()) {
            join();
        }
    }

    void swap(joining_thread& other) noexcept {
        _t.swap(other._t);  //这里应该是std::thread内部也有swap函数
    }

    std::thread::id get_id() const noexcept {
        return _t.get_id();
    }

    bool joinable() const noexcept {
        return _t.joinable();
    }

    void join() {
        _t.join();
    }

    void detach() {
        _t.detach();
    }

    //返回实际的线程变量(返回引用类型)
    std::thread& as_thread() noexcept {
        return _t;
    }

    //(返回const引用类型)
    const std::thread& as_thread() const noexcept {
        return _t;
    }
};
```

# 选择运行数量

通过std::thread::hardware_concurrency()函数，得到最大核数,从而确定最大线程运行数量
然后用vector存这些同时进行的线程
很妙哦
```cpp
//类模版
//模版接收一个迭代器类型(比如vector)  还有迭代器中实际存储的类型(比如int,double)
//因为下面要实现元素相加,所以T类型得是可以支持+操作的(有重载过+操作的也可以)
template<typename Iterator, typename T>
struct accumulate_block{
    //实现仿函数
    void operator() (Iterator first,Iterator last,T& result){
        result = std::accumulate(first,last,result);
    }
}

//函数模版
template<typename Iterator, typename T>
//和上面类似的传入这些
T parallel_accumulate(Iterator first, Iterator last, T init) {
    //得到迭代器first到last的距离,得到要处理多少个数据
    unsigned long const length = std::distance(first, last);
    
    //长度为0,就没必要后续计算了,直接返回初始值
    if (!length) {
        return init;   
    }
    
    unsigned long const min_per_thread = 25;  //每个线程算25个
    unsigned long const max_threads =
        (length + min_per_thread - 1) / min_per_thread;  //最大可能线程数
        
    unsigned long const hardware_threads =
        std::thread::hardware_concurrency();  //硬件支持的线程数,就是硬件有几个核
        
    unsigned long const num_threads =
        std::min(hardware_threads != 0 ? hardware_threads : 2, max_threads);
    //最终使用的线程数，取硬件线程数和最大线程数中的较小值
           
    unsigned long const block_size = length / num_threads; //每个线程实际处理的元素数量
    
    std::vector<T> results(num_threads);  //存每个线程计算结果(默认初始值是0)
    std::vector<std::thread> threads(num_threads - 1);  //存每个线程 
    Iterator block_start = first;  //后面会改变first,所以这里需要副本

    //循环num_threads次,每次创建一个线程
    for (unsigned long i = 0; i < (num_threads - 1); ++i) {
        Iterator block_end = block_start;  //让block_end到这次开始的位置,配合下一句
        std::advance(block_end, block_size);  //让block_end前进block_size个位置
         //这样block_end就到了这次结束的位置

        //创建第i个线程
        threads[i] = std::thread(
                accumulate_block<Iterator, T>(),
                block_start, block_end, std::ref(results[i]));
        //std::ref(results[i])传递结果的引用，使线程能修改结果
        
        block_start = block_end;  //让下一次的开始到这次的结束位置
    }

    //主线程处理最后一块数据(可能比其他块稍大)
    accumulate_block<Iterator, T>()(
        block_start, last, results[num_threads - 1]);   

    //等待每个线程执行完
    for (auto& entry : threads) {
            entry.join();    
    }

    //再计算所有线程的计算结果和
    return std::accumulate(results.begin(), results.end(), init);   
}

void use_parallel_acc() {
    std::vector <int> vec(10000);
    for (int i = 0; i < 10000; i++) {
        vec.push_back(i);
    }
    int sum = 0;
    sum = parallel_accumulate<std::vector<int>::iterator, int>
                    (vec.begin(), vec.end(), sum);

    std::cout << "sum is " << sum << std::endl;
}
```

# 识别线程

`get_id()`获取线程id
在线程外面获取id
```cpp
std::thread t([](){
    std::cout << "thread start" << std::endl;
});

t.get_id();
```

在线程里面获取id
```cpp
std::thread t([](){
    std::cout << "in thread id " << 
    std::this_thread::get_id() << std::endl;
    std::cout << "thread start" << std::endl;
});
```

先用一个例子了解std::async和std::future
```cpp
#include <iostream>
#include <future>
#include <chrono>

// 定义一个异步任务(假装从数据库查数据)
std::string fetchDataFromDB(std::string query) {
    //因为不是真的去数据库查数据,所以这里睡一会假装查了数据
    std::this_thread::sleep_for(std::chrono::seconds(5));
    return "Data: " + query;
}

void use_asyns() {
    // 使用 std::async 异步调用 fetchDataFromDB
    std::future<std::string> resultFromDB = std::async(std::launch::async, fetchDataFromDB, "Data");

    //因为下面那句话可能阻塞主线程
    //所以可以在主线程中先做其他事情
    std::cout << "Doing something else..." << std::endl;

    // 从 future 对象中获取数据
    std::string dbData = resultFromDB.get();  //会阻塞(等子线程拿到结果)
    std::cout << dbData << std::endl;
}
```

# future的wait和get

1. **std::future::get()**:
`std::future::get()` 是一个阻塞调用，用于获取 `std::future` 对象表示的值或异常。
如果异步任务还没有完成，`get()` 会阻塞当前线程，直到任务完成。
如果任务已经完成，`get()` 会立即返回任务的结果。
<mark style="background: #FFF3A3A6;">重要的是，`get()` 只能调用一次，因为它会移动或消耗掉 `std::future` 对象的状态。</mark>

2. **std::future::wait()**:
`std::future::wait()` 也是一个阻塞调用，
但它与 `get()` 的主要区别在于 <mark style="background: #FFF3A3A6;">`wait()` 不会返回任务的结果。它只是等待异步任务完成。</mark>
如果任务已经完成，`wait()` 会立即返回。
如果任务还没有完成，`wait()` 会阻塞当前线程，直到任务完成。
<mark style="background: #FFF3A3A6;">与 `get()` 不同，`wait()` 可以被多次调用，它不会消耗掉 `std::future` 对象的状态。</mark>

`wait_for()`或`wait_until()`方法来检查异步操作是否已完成
```cpp
//等5毫秒,然后判断子线程是否完成(用std::future_status判断)
if(fut.wait_for(std::chrono::seconds(5)) == std::future_status::ready) {  
    // 操作已完成  
} else {  
    // 操作尚未完成  
}
```

# 将任务和future关联

`std::packaged_task`是一个可调用目标，它包装了一个任务(1)
该任务可以在另一个线程上运行。(2)
它可以捕获任务的返回值或异常，并将其存储在`std::future`对象中，以便以后使用。(3)
(可以和下面代码对应)
```cpp
//模拟超时操作
int my_task() {
    std::this_thread::sleep_for(std::chrono::seconds(5));
    std::cout << "my task run 5 s" << std::endl;
    return 42;  //随便返回了一个值
}

void use_package() {
    // 创建一个包装了任务的 std::packaged_task 对象  
    std::packaged_task<int()> task(my_task);  //(1)

    // 获取与任务关联的 std::future 对象  
    std::future<int> result = task.get_future();  //(3)

    // 在另一个线程上执行任务  
    //虽然把task移动给了子线程,但是上面拿到的task.get_future();还是可以用的
    std::thread t(std::move(task));  //(2)
    t.detach(); // 将线程与主线程分离

    // 等待任务完成并获取结果  
    int value = result.get();  //上面move前从task中拿到的future对象
    std::cout << "The result is: " << value << std::endl;

}
```
`std::packaged_task<int()> task(my_task);`
    就是把原来可以直接传给子线程的回调函数,先让`std::packaged_task`包装一下
    `<int()>`代表传进去的函数类型  是个返回值为int,无参的函数

`t.detach();`
    先理解为将子线程放后台运行
    use_package()函数结束,t被回收,子线程依然会继续在后台执行
    除非主线程整个退出

# promise 用法

```cpp
#include <iostream>
#include <thread>
#include <future>

void set_value(std::promise<int> prom) {
    // 设置 promise 的值
    prom.set_value(10); //上面写了prom是关联的int类型值,所以传入的也是int类型值
    std::cout << "Promise set value success \n";
}

void use_promise() {
    // 创建一个 promise 对象
    std::promise<int> prom;
    // 获取与 promise 相关联的 future 对象
    std::future<int> fut = prom.get_future();  //要和std::promise<int>设置的类型对应
    // 在新线程中执行set_value(设置 promise 的值)
    std::thread t(set_value, std::move(prom));
    
    std::cout << "Waiting for the thread to set the value...\n";
    std::cout << "Value set by the thread: " << fut.get() << '\n';
    t.join(); //这句勿忘
}
```
乍一看,有点类似于上面的std::packaged_task
但是不大一样
    `std::future<int> fut = prom.get_future();` 同样是拿到future对象
    `std::thread t(set_value, std::move(prom));`这句比较不一样,逻辑是普通线程的逻辑
    `std::move(prom)`是把外面定义的`std::promise<int>`对象当参数传进回调函数
    然后回调函数里修改了prom

还能通过promise抛出异常
```cpp
#include <iostream>
#include <thread>
#include <future>

//子线程抛出异常
void set_exception(std::promise<void> prom) {
    try {
        // 抛出一个异常
        throw std::runtime_error("An error occurred!");
    } catch(...) {  //上面抛出异常以后,这里捕获到了异常,所以执行catch里面的逻辑
        // 设置 promise 的异常
        prom.set_exception(std::current_exception());
    }
}

int main() {
    //还是一样的
    std::promise<void> prom;
    std::future<void> fut = prom.get_future();
    std::thread t(set_exception, std::move(prom));

    //然后子线程上面开始执行,子线程抛出异常,并把异常写进promise
    //注意!!!此时主线程也要写try catch(捕获异常)
    try {
        std::cout << "Waiting for the thread to set the exception...\n";
        fut.get();
    } catch(const std::exception& e) {
        std::cout << "Exception set by the thread: " << e.what() << '\n';
    }
    t.join();
    return 0;
}
```

# 共享类型的future

```cpp
void myFunction(std::promise<int>&& promise) {
    // 模拟一些工作
    std::this_thread::sleep_for(std::chrono::seconds(1));
    promise.set_value(42); // 设置 promise 的值
}

void threadFunction(std::shared_future<int> future) {
    try {
        int result = future.get();  //通过shared_future拿到别的线程(线程1)中修改的promise值
        std::cout << "Result: " << result << std::endl;
    }
    //如果线程1中的promise修改失败,future.get()捕捉到异常,那就需要捕获
    catch (const std::future_error& e) { 
        std::cout << "Future error: " << e.what() << std::endl;
    }
}

void use_shared_future() {
    std::promise<int> promise;
    //这句话promise.get_future()返回的是一个std::future类型
    //但是有隐式转换,所以可以用std::shared_future接收
    std::shared_future<int> future = promise.get_future();
    std::thread myThread1(myFunction, std::move(promise)); //线程1,修改promise值

    //当线程1修改了promise, 线程2.线程3里面可以通过上面的shared_future,得到修改的值
    //(上面的shared_future,绑定到了线程1中的promise)
    //线程2.线程3 future.get();同样是  一旦线程1promise改了,那里就能得到值
    std::thread myThread2(threadFunction, future);
    std::thread myThread3(threadFunction, future);

    myThread1.join();
    myThread2.join();
    myThread3.join();
}
```

# 异常处理

std::future和std::async,也可以捕获异常(这节应该放上面)
```cpp
#include <iostream>
#include <future>
#include <stdexcept>
#include <thread>

void may_throw()
{
    // 这里我们抛出一个异常。在实际的程序中，这可能在任何地方发生。
    throw std::runtime_error("Oops, something went wrong!");
}

int main()
{
    // 创建一个异步任务
    std::future<void> result(std::async(std::launch::async, may_throw));

    try
    {
        // 获取结果（如果在获取结果时发生了异常，那么会重新抛出这个异常）
        result.get();
    }
    catch (const std::exception &e)
    {
        // 捕获并打印异常
        std::cerr << "Caught exception: " << e.what() << std::endl;
    }

    return 0;
}
```

右值看重对象的值而不考虑地址，<mark style="background: #ABF7F7A6;">move函数可以对一个左值使用，使操作系统不再在意其地址属性，将其完全视作一个右值</mark>
```cpp
const int i = 100;
//int&& rrefi = i; //不行
int&& rrefi = std::move(i);  //可以,使用了move函数,std::move(i)是个右值
```

<mark style="background: #ABF7F7A6;">move函数让操作的对象失去了地址属性，所以我们有义务保证以后不再使用该变量的地址属性，简单来说就是不再使用该变量</mark>
    (这个的理解我们等移动语义的时候再理解)
    大概总结就是 单纯std::move(i),i还是能当做左值用的
    但是一般用std::move(i),是为了移动语义,达到移动语义的目的以后i就不能被当做左值用了,所以std::move以后要避免使用操作对象的地址属性

<mark style="background: #ABF7F7A6;">右值引用主要负责处理的就是临时对象。</mark>
<mark style="background: #ABF7F7A6;">程序执行时生成的中间对象就是临时对象</mark>，注意，所有的临时对象都是右值对象，因为临时对象产生后很快就可能被销毁，一般要使用的是它的值属性。
(这里意思是介绍 右值引用多被用在什么地方)
```cpp
int getI() {
	return 10;
}

int main() {
	int i = 100;
	int&& rref = getI();  //比如函数返回一个临时的变量,就可以用右值引用接收
	
	std::cin.get();
}
```

比如int i = 10，i和10都是<mark style="background: #ABF7F7A6;">对象</mark>
(大佬所说的对象,一般是变量的意思,先大概这样理解吧)

<mark style="background: #ABF7F7A6;">左值：拥有地址属性的对象就叫左值</mark>，左值来源于c语言的说法，<mark style="background: #FFF3A3A6;">能</mark>放在“=”左面的就是左值，注意，左值也可以放在“=”右面。
右值：不是左值的对象就是右值。或者说<mark style="background: #ABF7F7A6;">无法操作地址的对象就叫做右值</mark>。
```cpp
int i = 10;
```
i有地址属性,就是左值
10是右值,没有地址属性

<mark style="background: #ABF7F7A6;">临时对象，就都是右值，临时对象的地址属性无法使用</mark>
    比如上面的10,算是个临时对象
    i+1也是个临时地址, 但是算有地址, 但是这个地址我们无法使用(但我觉得这个整体不算有地址,而是只是i有地址, 算了先按"有地址理解"吧)
    (问了deepseek,所以大佬是对的)

<mark style="background: #ABF7F7A6;">注意：左值也可以放在“=”右面，但右值绝对不可以放在等号左面</mark>
```cpp
int i = 10;
int i1 = i; //左值也可以放在“=”右面
//10=9;  右值绝对不可以放在等号左面
```

___

<mark style="background: #ABF7F7A6;">一般来说，判断一个对象是否为右值，就看它是不是左值，有没有可以用的 地址属性，不是左值，那就是右值</mark>
```cpp
int i = 10; //i左
int i2= (i+1);  //i+1右
//(i+1) = 100;  //i+1右所以不行

++i = 200;  //++i左值
//i++ = 200 //不行,此时i++是右
//因为++i是先给i +1,再返回i,所以是可以用的地址属性
//i++是先返回一个临时变量,再给临时变量+1,是不可用的地址属性

```

<mark style="background: #ABF7F7A6;">普通左值引用：就是一个对象的别名，只能绑定左值，无法绑定常量对象。</mark>
(像int& ref就是一个左值引用)
就是说左值引用可以绑定非const的左值
像下面i是const int,此时ref就不能绑定i
因为这个时候ref不是const,ref可以随便改,而这相当于直接修改i, 那i设定为const就没有意义了
```cpp
int i = 100;
int& ref = i;  //可以,  ref就是一个左值引用

const int i = 100;
//int& ref = i;  //不行
//ref = 200; 

//int& ref = 100;  //不行
```

<mark style="background: #ABF7F7A6;">const左值引用：可以对常量起别名，可以绑定左值和右值。</mark>
```cpp
const int i = 100;
const int& ref = i;  //可以,绑一个常量的左值
const int& ref1 = (i+1)  //可以,绑右值
```

<mark style="background: #ABF7F7A6;">右值引用: 只能绑定右值</mark>
int&&代表右值引用
```cpp
const int i = 100;
int&& rrefi = 200; //可以
int&& rrefi1 = (i+1); //可以
int&& rrefi2 = i++; //可以
```

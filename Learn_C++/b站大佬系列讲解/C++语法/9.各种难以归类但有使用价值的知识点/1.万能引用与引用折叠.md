模版型 万能引用
```cpp
using boost::typeindex::type_id_with_cvr;

template<typename T>
void test(T&& parm) {
	std::cout << type_id_with_cvr<decltype(parm)>().pretty_name() << std::endl;
	std::cout << type_id_with_cvr<T>().pretty_name() << std::endl;
}

int main() {
	int i = 10;
	test(i);  //传入左值
	test(10);  //传入右值

}
```
当传入右值, parm为右值引用,T为int类型  这是对的
当传入左值,parm和T都是左值引用   我们想应该是T是int parm是左值引用才对
![[Pasted image 20250625161755.png]]

为什么parm和T都是左值引用
    总结就是因为 引用折叠
    ![[Pasted image 20250625162256.png]]
    ![[Pasted image 20250625162421.png]]

只有上面那样写`void test(T&& parm)` 才是万能引用
`void test(const T&& parm)`  `void test(vector<T> && parm)`  这些都不是万能引用,这些是普通的右值引用

```cpp
template<typename T>
class MyVector {
public:
    void push_back(T&& elem)    //这个也不是万能引用
}
```

```cpp
template<typename T>
class MyVector {
public:
    template<typename T2>
    void push_back(T2&& elem)  //这个是万能引用
}
```
为什么呢?
这涉及类型推到
首先我们看上面的代码
```cpp
template<typename T>
void test(T&& parm) {
	//...
}

int main() {
	int i = 10;
	test(i);  //传入左值
	test(10);  //传入右值
    //这里传入的时候并没有明确传进去的类型,而是让系统自己推导
}

```

auto型万能引用
```cpp
int main() {
	int j = 10;
	auto&& elem = j;  //左值  输出左值引用
	auto&& elem = 10;  //右值  输出右值引用
	std::cout << type_id_with_cvr<decltype(elem)>().pretty_name() << std::endl;

    //const auto&& elem = j;  这个不算万能引用
}
```

智能指针就是通过引用计数来判断释放堆内存时机的。
<mark style="background: #ABF7F7A6;">use_count()函数可以得到shared_ptr对象的引用计数。</mark>
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
	std::cout << sharedI.use_count() << std::endl;  //1

	std::shared_ptr<int> sharedI2(sharedI);  //这就是shared_ptr"共享"的体现 
	std::cout << sharedI.use_count() << std::endl;  //2

	sharedI2.reset();  //将sharedI2置空,就是sharedI2放弃对此块内存的控制权
	std::cout << sharedI.use_count() << std::endl;  //1
}
```

<mark style="background: #ABF7F7A6;">智能指针可以像普通指针那样使用，”share_ptr”早已对各种操作进行了重载，就当它是普通指针就可以了</mark>
    就是普通指针可以* 取内容, &取地址
    智能指针都是可以的(后面学的两种智能指针也可以的)
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
	std::cout << *sharedI << std::endl; 
	std::cout << &sharedI << std::endl; 

     *sharedI = 101;
	std::cout << *sharedI << std::endl;  
}
```

<mark style="background: #ABF7F7A6;">unique函数：判断该shared_ptr对象是否独占若独占，返回true。否则返回false。</mark>
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
    std::cout << sharedI.unique() << std::endl;  //t(1)
    
	std::shared_ptr<int> sharedI2(sharedI);  //这就是shared_ptr"共享"的体现 
	std::cout << sharedI.unique() << std::endl;  //f(0)

	sharedI2.reset();  //将sharedI2置空,就是sharedI2放弃对此块内存的控制权
	std::cout << sharedI.unique() << std::endl;  //t(1)
}
```

reset函数：
当reset函数有参数时，<mark style="background: #ABF7F7A6;">改变此shared_ptr对象指向的内存</mark>。
当reset函数无参数时，将此shared_ptr对象置空，也就是将对象内存的指针设置为nullptr
    无参数时上面演示过了
    有参数时 比如这样 `sharedI.reset(new int(1000))`,就让sharedI指向一块新的堆内存

注意 reset里面参数只能这样写
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
    sharedI.reset(new int(1000));  //此时原本那块内存(就是上面那个int 100),因为引用计数变为了0,就会自动delete
}
```

```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
	std::shared_ptr<int> sharedI2 = std::make_shared<int>(1000);
	
    //sharedI.reset(sharedI2);  //这样不行
    sharedI = sharedI2;  //这个时候直接赋值就好了
}
```

swap函数：<mark style="background: #ABF7F7A6;">交换两个智能指针所指向的内存</mark>
<mark style="background: #ABF7F7A6;">shared_ptr类提供的swap函数</mark>
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
	std::shared_ptr<int> sharedI2 = std::make_shared<int>(1000);
	
    sharedI.swap(sharedI2);
    std::cout << *sharedI << std::endl;  //1000
    std::cout << *sharedI2 << std::endl;  //100
}
```
<mark style="background: #ABF7F7A6;">std命名空间中全局的swap函数</mark>
```cpp
int main() {
	std::shared_ptr<int> sharedI = std::make_shared<int>(100);
	std::shared_ptr<int> sharedI2 = std::make_shared<int>(1000);
	
    std::swap(sharedI,sharedI2);
    std::cout << *sharedI << std::endl;  //1000
    std::cout << *sharedI2 << std::endl;  //100
}
```

void Func(std::shared_ptr<int> sharedI) {

}

	Func(sharedI);  //当做函数参数传递

	//测试大小

主线程介绍：<mark style="background: #ABF7F7A6;">一个程序执行起来就是一个进程。而main函数就是主线程</mark>，一旦主线程执行完毕，主线程结束了，整个进程就会结束了
    就是main函数是主线程
    并且主线程和之后要讲的子线程 实际上是平级的
    只不过主线程要结束的时候,会向其他子线程发个消息,让他们结束

子线程介绍：在一个线程执行时，我们可以创建出另外一个线程。两个线程各自执行，互补干涉。注意，当主线程执行完毕，就会强制结束所有子线程，然后进程结束，从这个角度来说，可以认为子线程是主线程的辅助线程。<mark style="background: #ABF7F7A6;">但是要明白主线程和子线程是平级的，只不过主线程执行完毕后会给所有子线程发送一个信号，使所有子线程强制结束。</mark>

子线程的创建方式：很简单，<mark style="background: #ABF7F7A6;">直接使用thread类就可以了</mark>
```cpp
int main(){
    //std::thread myTread();  括号里面要传入一个可调用对象,就是一个函数或仿函数或lambda表达式  ,下面展示lambda表达式
    std::thread myTread([](){
        //我们这里只让子线程输出hello,输出完以后,子线程就结束了
        std::cout << "hello" << std::endl;
    });
}
```

<mark style="background: #ABF7F7A6;">有些子线程负责对部分数据的处理，主线程必须要等到子线程处理完毕才能继续执行</mark>
<mark style="background: #ABF7F7A6;">使用了join函数后，主线程就会处于挂起状态，直到子线程执行完毕才可以继续执行</mark>

    是的,就线程名后面跟.join( )就可以实现,执行到这句的时候判断一下子线程结束了没,然后主线程等子线程结束了,主线程再继续执行


<mark style="background: #ABF7F7A6;">有些子线程和主线程完全分离，各自执行各自的</mark>。但主线程执行完毕，子线程就会立马被强制结束，容易导致各种bug
    就是此时主线程没办法在具体哪一句后面写join,来等子线程,因为他们执行的逻辑根本都不得噶,都是自己执行自己的
这个时候就用detach函数(用法和join差不多)

比如下面这个子线程,要是不写detach,就会报错
```cpp
int main(){
    std::thread myTread([](){
        for(int i=0;i<10000000;i++){
            //...
        }
    });

    myTread.detach();
}
```

为什么不写detach,就会报错?

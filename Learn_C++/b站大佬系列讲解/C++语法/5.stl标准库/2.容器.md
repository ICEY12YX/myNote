# 顺序容器
## vector  动态数组
<mark style="background: #ABF7F7A6;">数组尾部添加或删除元素非常迅速。但在中部或头部就比较费时</mark>

先简单认识一下
```cpp
int main(){
    std::vector<int> ivec{1,2,3,4};
    std::cout << ivec[1] << std::endl;
    std::cout << ivec.at(1) << std::endl;
}
```
用at比较好
    因为ivec[1]这种方式,如果越界(如ivec[10])只会单纯的报错
    而at会抛出异常
    我们可以对异常进行处理
```cpp
int main() {
	std::vector<int> ivec{ 1,2,3,4 };
	try {
		std::cout << ivec.at(10) << std::endl;  //明显越界
	}
	catch (const std::out_of_range& except) {
		std::cout << except.what() << std::endl;
	}
}
```

### 增加函数
```cpp
std::vector<int> ivec(3, 5);
ivec.push_back(10);

int i = 9;
ivec.push_back(i);

ivec.insert(ivec.cbegin(), 100);  //这里写成begin()也可以,表示在头部0号位插
ivec.insert(++ivec.cbegin(), 200);  //表示在头部后面那个位置插入,就是1号位
ivec.insert(ivec.cbegin() + 2, 300);  //2号位插

ivec.insert(ivec.cbegin() + 3, { 400,500 });  //3号位插

ivec.insert(ivec.cbegin() + 5, 2,60);  //5号位插,插入2个60

for (int elem : ivec) {
	std::cout << elem << std::endl;
}
```

### 删除函数
```cpp
std::vector<int> ivec{1,2,3,4,5,6,7,8};
ivec.erase(ivec.begin());  //删0号位

ivec.erase(ivec.begin(),ivec.begin()+3);  //删0号位到3号位为止,就是说3号位不删(总共删3个!!!,先闭后开)

ivec.pop_back();  //删队尾一个
ivec.clear();  //清空

for (int elem : ivec) {
	std::cout << elem << std::endl;  
}
```

erase函数 <mark style="background: #ABF7F7A6;">返回指向被删除元素后面的那个元素的迭代器</mark>
```cpp
std::vector<int> ivec{1,2,3,4,5,6,7,8};
auto iter = ivec.erase(ivec.begin());  //删0号位
std::cout << *iter << std::endl;  //返回2

std::vector<int> ivec2{1,2,3,4,5,6,7,8};
auto iter2 = ivec2.erase(++ivec.begin());  //删1号位
std::cout << *iter2 << std::endl;  //返回3

```

### 遍历函数

`begin()`返回指向容器第一个元素的迭代器
`cbegin()` 可以主动调用的begin函数的常量版本
`rbegin()` 反向迭代器，指向最后一个元素
`crbegin()` 上面的常量版本

`end()` 返回指向容器最后一个元素的下一个元数的迭代器
同理也有`cend()` `rend()`反向迭代器，指向第一个元素之前的元素  `crend()`
```cpp
std::vector<int> ivec{1,2,3,4,5,6,7,8};

for(auto iter = ivec.begin();iter != ivec.end();++iter){
    std::cout << *iter << std::endl;
}
```

## deque 双端队列
<mark style="background: #ABF7F7A6;">本质仍然是优化过的动态数组，只不过相比于单纯的动态数组，在前面添加或删除元素非常快了</mark>
<mark style="background: #ABF7F7A6;">头部和尾部添加或删除元素都非常快（略慢与vector）。但在中间插入元素比较费时（和vector差不多）</mark>

简单认识一下
```cpp
std::deque<int> ideque{ 1,2,3,4 };
ideque.push_front(0);  //vector不能这样做
ideque.pop_front();
```

## list 链表

<mark style="background: #ABF7F7A6;">在任何位置插入和删除元素都比较迅速。（在任何位置插入删除元素的时间相同，在元素头部操作慢于deque，在元素尾部操作慢于deque和vector）</mark>

简单认识一下
```cpp
std::list<int> iList{ 1,2,3,4 };

//没有at函数
iList.push_back(5)
iList.push_front(0);  
iList.pop_front();
iList.insert(iList.cbegin(), 100);

//因为list是链表,所以上面几个插入的时间复杂度是一样的
```

## forward_list  单向列表  (使用较少)

<mark style="background: #ABF7F7A6;">凡是list不支持的功能，它都不支持</mark>

<mark style="background: #ABF7F7A6;">ForwordList 只提供前向迭代器，而不是双向迭代器。因此它也不支持反向迭代器</mark>
```cpp
std::forward_list<int> iforList{1,2,3,4};
auto iter = iforList.begin();
++iter;  //可以
//--iter;  //不行,这就是不支持反向迭代器,就是只能往前,不能往后

//所以forward_list也没有rbegin()
```

<mark style="background: #ABF7F7A6;">ForwordList 没有指向最末元素的锚点。基于这个原因，不提供用以处理最末元素的成员 back(),push_back(),pop_back()</mark>
    可以理解为只用头指针,没有尾指针

# 关联容器

简单认识一下
```cpp
std::set<int> iset{ 1,9,0,2 };
for (int elem : iset) {
	std::cout << elem << std::endl;  //0,1,2,9
}
```
说明 <mark style="background: #ABF7F7A6;">元素位置取决于元素的值，和插入顺序无关</mark>

## set/multiset
内部元素的值依据元素的值自动排列，与插入顺序无关。
<mark style="background: #ABF7F7A6;">set内部相同数值的元素只能出现一次，multiset内部相同数值的元素可出现多次</mark>
```cpp
std::set<int> iset{ 1,1,2 };
for (int elem : iset) {
	std::cout << elem << std::endl;  
}

std::multiset<int> imset{ 1,1,2 };
for (int elem : imset) {
	std::cout << elem << std::endl;  
}
```

## map/multimap

内部元素是成对的“key/value”，也就是“键值/实值”，<mark style="background: #ABF7F7A6;">内部元素依据其键值自动排序</mark>
<mark style="background: #ABF7F7A6;">map内部相同的键值只能出现一次，multimap则可以出现多次</mark>
```cpp
std::map<int, std::string> imap;
imap.insert(std::pair<int, std::string>(1, "888"));
imap.insert(std::pair<int, std::string>(999, "808"));
imap.insert(std::pair<int, std::string>(39, "chns8"));
imap.insert(std::pair<int, std::string>(39, "chns8"));
imap.insert(std::pair<int, std::string>(12, "oam"));

for (const auto& elem : imap) {
	std::cout << elem.first << '\t' << elem.second << std::endl;
}
```

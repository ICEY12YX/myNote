```cpp
void outPut() const{
```

完整写法是
```cpp
void outPut() const{
        std::cout<<"name="<<this->name<<"   age="<<this->age<<std::endl;

```
所以对象首先是个<mark style="background: #FFF3A3A6;">指针</mark>,并且代表一个对象

C++类的本质就是C语言的结构体外加几个类外的函数，C++最后都要转化为C语言来实现，<mark style="background: #ABF7F7A6;">类外的函数就是通过this来指向这个类的</mark>
    C是下面这样实现的
```cpp
class Test{
public:  //先别管这个怎么变成public了
    std::string name;
    unsigned age;
}

void outPut(Test* const myThis){
        std::cout<<"name="<<myThis->name<<"   age="<<myThis->age<<std::endl;
    }

```
因为<mark style="background: #FFF3A3A6;">C语言的结构体里面没法写函数</mark>, 所以都是上面这样结构体外面 加上一些天降的函数, 来实现的
所以this就是系统为成员函数自动传进去的一个指针, 这个指针(this)指向这个成员函数目前作用的对象

<mark style="background: #ABF7F7A6;">每个类函数的参数根本没有名	叫this的指针。这不过是编译器赋予的功能罢了</mark>
```cpp
class Test{
public:
    Test(const std::string& name_,unsigned age_);
    ~Test();
    
    void outPut() const{
        std::cout<<"name="<<name<<"   age="<<age<<std::endl;
    }
private:
    std::string name;
    unsigned age;
}

Test::Test(const std::string& name_,unsigned age_):name(name_),age(age_){}

Test::~Test(){}

//函数指针
//&Test::outPut 表示获取类成员函数的地址
//
void (Test::*pf)() const = &Test::outPut;  //记得加const,因为成员函数里有const

int main(){
    Test test("fanfan",6);
    (test.*pf)();
    test.outPut();
}
```
上面写了个函数指针,发现可以这样直接得到类里成员函数的指针,不需要传入Test类型指针,说明每个类函数的参数根本没有名 叫this的指针

<mark style="background: #ABF7F7A6;">常成员函数就是无法修改成员变量的函数。可以理解为将this指针指向对象用const修饰的函数。</mark>
底层C语言是下面这样实现的
```cpp
class Test{
public:
    Test(const std::string& name_,unsigned age_);
    ~Test();
    
    void outPut(Test* const myTest);  //和类外面定义的保持一致
private:
    std::string name;
    unsigned age;
}

Test::Test(const std::string& name_,unsigned age_):name(name_),age(age_){}

Test::~Test(){}

//比如这里要写outPut的定义
//注意类外面定义函数怎么写
void Test:: outPut(Test* const myTest){
    //myTest->name="hello";  //比如我们不希望函数里能这样修改成员变量,怎么办呢
}
```

那在类里,想实现这样的效果, 参数又不显示传this,怎么办呢?
<mark style="background: #ABF7F7A6;">因为类的成员函数已经将this指针省略了，只能在函数后面加const关键字来实现无法修改类成员变量的功能了</mark>
```cpp
class Test{
public:
    Test(const std::string& name_,unsigned age_);
    ~Test();
    
    void outPut() const{  //就这里写个const就好了
         std::cout<<"name="<<name<<"   age="<<age<<std::endl;
    };  
private:
    std::string name;
    unsigned age;
}
```

<mark style="background: #ABF7F7A6;">常对象就是用const修饰的对象，定义好之后就再也不需要(也不能)更改成员变量的值了。</mark>常对象在大型程序中还是很有意义的。
```cpp
int main(){
    const Test test("fanfan",6); //这样这个实例的成员变量就不能被改变
}
```

<mark style="background: #ABF7F7A6;">常函数无法调用了普通成员函数，否则常函数的这个“常”字还有什么意义</mark>
    比如const的成员函数里面 调用了一个普通成员函数, 这个普通成员函数里面 修改了实例,那就没意义了

<mark style="background: #ABF7F7A6;">成员函数能写作常成员函数就尽量写作常成员函数</mark>
    成员函数能加const,尽量加

<mark style="background: #ABF7F7A6;">同名的常成员函数和普通成员函数是可以重载的，常量对象会优先调用常成员函数，普通对象会优先调用普通成员函数</mark>

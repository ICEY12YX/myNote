C语言的静态成员变量，<mark style="background: #ABF7F7A6;">在编译期就已经在静态变量区明确了地址，所以生命周期为程序从开始运行到结束，作用范围为与普通的成员变量相同。</mark>这些对于类的静态成员变量同样适用
```cpp
class Test{
public:
    static unsigned i;  
};

unsigned Test::i = 20;  //静态成员变量需要在外部声明

int main(){
    std::cout << Test::i << std::endl;  //注意static成员变量是这样调用的,不是点.调用
}
```

类的静态成员变量因为创建在静态变量区，所以<mark style="background: #ABF7F7A6;">直接属于类，也就是我们可以直接通过类名来调用，当然通过对象调用也可以</mark>
```cpp
class Test{
public:
    static unsigned i;  
};

unsigned Test::i = 20;  //静态成员变量需要在外部声明

int main(){
    Test test;
    std::cout << test.i << std::endl;  //这样也可以
}
```

<mark style="background: #ABF7F7A6;">静态成员变量必须在类外进行初始化，否则会报未定义的错误，不能用构造函数进行初始化。</mark>
<mark style="background: #ABF7F7A6;">因为静态成员变量在静态变量区，只有一份，而且静态成员变量在编译期就要被创建，成员函数那都是运行期的事情了</mark>
    要是不在外面初始化,那上面这个i就会变成未定义的值

___

<mark style="background: #ABF7F7A6;">静态成员函数就是为静态成员变量设计的，就是为了维持封装性</mark>
    直接用类调用, 如Test::i有点破坏封装性
    所以会用到静态成员函数,来调用静态成员变量,而不是直接Test::i这样调用
```cpp
class Test {
public:
	static unsigned getI() {  //静态成员函数
		return i;
	}

private:
	static unsigned i;
};

unsigned Test::i = 20;  //静态成员变量需要在外部声明

int main() {
	std::cout << Test::getI() << std::endl;  //这样也可以
}
```

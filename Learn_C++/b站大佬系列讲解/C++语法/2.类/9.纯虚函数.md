<mark style="background: #ABF7F7A6;">基础的枪类有对应的对象吗？没有。它唯一的作用就是被子类继承</mark>
    就是说,基础的枪类,没有必要产生实例,它唯一的作用就是被子类继承

语法
```cpp
class Qiang{
public:
    Qiang(const std::string& name_,const int speed_,const int hit_):name(name_),speed(speed_),hit(hit_){
        std::cout << "Qiang()" << std::endl;
    }

    virtual void Fire() const = 0;  //直接写=0, 就是纯虚函数了
    
protected:
    std::string name;
    int speed;
    int hit;
}

class xiaoLv : public Qiang{
public:
    xiaoLv(const std::string& name_,const int speed_,const int hit_,const  int a_):Qiang(name_,speed_,hit_),a(a_){  //这里要写上调用父类构造函数
        std::cout << "xiaoLv()" << std::endl;
    }

    virtual void Fire() const override{  //重写
        std::cout << "xiaoLv::Fire()" << std::endl;
    }
private:
    int a; //随便取的
}
```

<mark style="background: #ABF7F7A6;">只要将一个虚函数写为纯虚函数，那么该类将被认为无实际意义的类，无法产生对象。纯虚函数也不用去写实际部分。写了编译期也会自动忽略。</mark>
    就是说 一个类里只要有纯虚函数,那这个类就不能被实例化,变为**抽象类**
    实例化了,编译器会报错
    ![[Pasted image 20250610224543.png]]
    并且 纯虚函数不需要写函数体,直接写=0就好了, 类似于接口
    但是 **抽象类**的构造,析构(要是有父类指向子类的情况,析构加virtual),还是要写的

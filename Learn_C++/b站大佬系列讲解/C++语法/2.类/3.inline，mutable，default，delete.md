函数返回类型前加上关键字inline就可以把函数指定为内联函数。
内联函数的作用，<mark style="background: #ABF7F7A6;">普通函数在调用时需要给函数分配栈空间以供函数执行，压栈等操作会影响成员运行效率，于是C++提供了内联函数将函数体放到需要调用函数的地方，用空间换效率。</mark>
    普通函数调用时要分配栈空间,就是获得一个栈帧, 
    然后,比如从main函数调用fun函数,要先存下main函数的位置,再创建fun函数栈帧,参数压栈,最后销毁fun函数栈帧,返回main函数断点位置
    这个开销比较大
    而inline,会将函数内部的执行语句,直接插入进来,就是相当于把函数体的代码拿过来直接执行
    ![[Pasted image 20250609155321.png]]

inline代码演示   比如要把类的成员函数写成inline的
```cpp
class Test {
public:
	void outPut();  //这里可写可不写inline关键字
};

inline void Test::outPut() {  //这里一定要写
	}

```

<mark style="background: #ABF7F7A6;">inline关键字只是一个建议，开发者建议编译器将成员函数当做内联函数，一般适合搞内联的情况编译器都会采纳建议</mark>
    就是说有时候没加inline, 编译器可能转为汇编的时候,为了性能优化,这部分功能会自动加上
    还有的时候加了inline,不一定就真的inline
        比如一个inline的fun函数里面10万行代码
        我在main函数里要执行10次这个fun函数
        那main函数就会变得出奇的大
        编译器此时就有可能不采纳写成inline的意见
        总结就是,编译器可能有自己的一套优化方案,大多数情况不需要我们写inline

Mutable意为可变的，与const相对，<mark style="background: #ABF7F7A6;">被mutable修饰的成员变量，永远处于可变的状态，即便处于一个常函数中，该变量也可以被更改</mark>
这个关键字在现代C++中使用情况并不多，<mark style="background: #ABF7F7A6;">一般来说只有在统计函数调用次数时才会用到</mark>
```cpp
class Test {
public:
	void outPut() const; 

    mutable unsigned outPutCount = 0;  //这是C++11才有的偷懒写法,就是定义成员变量的时候直接赋初值(一般是要构造函数里才能实现)
};

void Test::outPut() const{  //函数被设置为const,即不能改变实例的成员变量
    ++outPutCount;   //这里改变了成员变量值,因为上面加上了mutable才实现的
    std::cout << outPutCount << std::endl;
}
```

default关键字, <mark style="background: #ABF7F7A6;">在编译时不会生成默认构造函数时便于书写</mark>
<mark style="background: #ABF7F7A6;">可以对默认复制构造函数，默认的赋值运算符和默认的析构函数使用，表示使用的是系统默认提供的函数</mark>
    当我们既想要自己写的构造函数,又想要默认的构造函数怎么办
```cpp
class Test {
public:
	Test(unsigned age_):age(age_){}  //写一个普通构造函数
	Test(){}  //没有default关键字,只能这样写默认的构造函数
	
private:
    unsigned age;
};
```

```cpp
class Test {
public:
	Test(unsigned age_):age(age_){}  //写一个普通构造函数
	Test() = default;  //有default关键字,就可以这样写
	Test(const Test& test) = default;  //同样拷贝构造也可以这样写(这句不写也可以,不写也是生成一个默认的拷贝构造,写了就可读性好点)
	~Test() = default; //默认的析构
	Test& operator= (const Test& test) = default;  //默认的运算符'重载'
	
private:
    unsigned age;
};
```

___

C++会为程序生成默认构造函数，默认复制构造函数，默认重载赋值运算符(这个重载赋值运算符后面讲)
<mark style="background: #ABF7F7A6;">在很多情况下，我们并不希望这些默认的函数被生成，在C++11以前，只能有将此	函数声明为私有函数或是将函数只声明不定义两种方式</mark>。
<mark style="background: #ABF7F7A6;">C++11于是提供了delete关键字，只要在函数最后加上“=delete”就可以明确告诉	编译期不要默认生成该函数</mark>
```cpp
class Test {
public:
	Test(unsigned age_):age(age_){}  //写一个普通构造函数
	
	Test(const Test& test) = delete;  //比如我们想禁止默认拷贝,又不想也不需要自己写个拷贝构造,那可以直接delete
	Test& operator= (const Test& test) = delete;  //运算符的默认行为也能delete

    //析构函数也能delete,但是一般没人delete析构
private:
    unsigned age;
};
```
这个做法在单例类中比较有用

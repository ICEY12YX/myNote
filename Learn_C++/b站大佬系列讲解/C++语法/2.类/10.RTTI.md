C++为了支持多态，<mark style="background: #ABF7F7A6;">C++的指针或引用的类型可能与它实际指向对象的类型不相同</mark>
RTTI（Run Time Type Identification）即<mark style="background: #ABF7F7A6;">通过运行时类型识别，程序能够通过基类的指针或引用来检查这些指针或引用所指向的对象的实际派生类。</mark>
    就是说可能会有向上转型的代码
    如Parent* p = new Child();
    虽然这句很容易看出,此时p指向子类
    但是程序一大,就会很难看出
    所以有时候我们需要知道,这个类指针指向父类还是子类

___

typeid函数：<mark style="background: #ABF7F7A6;">typeid函数返回的一个叫做type_info的结构体，该结构体包括了所指向对象的实际信息，其中name()函数就可以返回函数的真实名称</mark>。type_info结构体其他函数没什么用
```cpp
class Qiang{
public:
    Qiang(const std::string& name_,const int speed_,const int hit_):name(name_),speed(speed_),hit(hit_){
        std::cout << "Qiang()" << std::endl;
    }

    virtual void Fire() const = 0;  //直接写=0, 就是纯虚函数了
    
protected:
    std::string name;
    int speed;
    int hit;
}

class xiaoLv : public Qiang{
public:
    xiaoLv(const std::string& name_,const int speed_,const int hit_,const  int a_):Qiang(name_,speed_,hit_),a(a_){  //这里要写上调用父类构造函数
        std::cout << "xiaoLv()" << std::endl;
    }

    virtual void Fire() const override{  //重写
        std::cout << "xiaoLv::Fire()" << std::endl;
    }
private:
    int a; //随便取的
}

int main(){
    Qiang* q = new xiaoLv("xiaoLv",10,10,1);
    std::cout << typeid(*q).name() << std::endl; //输出此时这个指针指向哪个类型
    //同样这里省略了delete
}
```

<mark style="background: #ABF7F7A6;">dynamic_cast函数：C++提供的将父类指针转化为子类指针的函数</mark>
    上面我们写 `Qiang* q = new xiaoLv("xiaoLv",10,10,1);`
    q此时只是指向子类, 但其类型还是父类指针
    (这里我也想明白一点, 能这样父指向子,因为是指针啊,指针只存个地址,类型决定这块地址后面多大一片区域是自己的)
    (然后能保留子类的虚函数表指针,也是因为虚函数表指针在地址开始的那里,所以被保留了)
    要想把q 转为xiaoLv* 就用dynamic_cast
```cpp
int main(){
    Qiang* q = new xiaoLv("xiaoLv",10,10,1);
    std::cout << typeid(*q).name() << std::endl; //输出

    xiaoLv* xl = dynamic_cast<xiaoLv*>(q); //用法长这样,记一下

    //同样这里省略了delete
}
```

标准的文件功能代码
<mark style="background: #ABF7F7A6;">让客户输入文件名称，如果文件不存在，就让客户重新输入文件名称，如果文件存在，就将文件全部内容输出到终端</mark>
```cpp
int main() {
	std::string fileName;
	std::string fileContent;

	while (std::cin >> fileName, !std::cin.eof()) {
		if (std::cin.bad()) {
			throw std::runtime_error("cin is corrupted");
		}

		std::ifstream ifs(fileName);
		if (ifs.is_open()) {
			while (std::getline(ifs, fileContent)) {
				std::cout << fileContent << std::endl;
			}
			if (ifs.bad()) {
				throw std::runtime_error("ifs is corrupted");
			}
			ifs.close();
		}
		else {
			ifs.clear();
			ifs.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
			std::cout << "file not exist,please try again" << std::endl;
			continue;
		}
	}

	std::cout << "process complete" << std::endl;
}
```

文件模式
最重要几点:

<mark style="background: #FFF3A3A6;">用fstream进行写文件,会先把文件里面清空再写</mark>
但不是完全清空,比如文件第一行1111,第二行2222
我写入文件3333,然后文件会变成第一行3333,第二行2222(相当于覆盖,不是清空)
```cpp
int main(){
    std::fstream fs("num.txt");
    if( fs.is_open() ){
        fs << "hello world" << std::endl;
        fs.close();
    }
    return 0;
}
```
如果要实现"追加",要代码改成
`std::fstream fs("num.txt", std::ios::app);`

一般写文件是用ofstream,这个时候<mark style="background: #FFF3A3A6;">写文件就是完全清空</mark>了
```cpp
int main(){
    std::ofstream ofs("num.txt");
    if( ofs.is_open() ){
        ofs << "hello world" << std::endl;
        ofs.close();
    }
    return 0;
}
```
同样,如果要实现"追加",要代码改成
`std::ofstream ofs("num.txt", std::ios::app);`

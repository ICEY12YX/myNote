要理解io状态先看这段代码
```cpp
int main() {
	int i = 10;
	while (std::cin >> i, !std::cin.eof()) {
		if (std::cin.bad()) {
			throw std::runtime_error("cin is corrupted");
		}
		if (std::cin.fail()) {
			std::cin.clear();
			std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');  //清除输入流中的无效字符，直到遇到换行符 \n
			std::cout << "data format error,please try again" << std::endl;
		}
		std::cout << i << std::endl;
	}

	std::cout << "process complete" << std::endl;
}
```

具体介绍io状态

出现错误比如,上面的代码
    <mark style="background: #ABF7F7A6;">比如我们使用cin向一个int类型的数中 输入一个字符串，会使cin这个对象出现错误
    所以我们在使用io对象时都应该判断io对象的状态
    比如：while(cin >> val) 或if(cin >> val)（不要只用这两个进行控制，最好搭配iostate来使用）</mark>

badbit状态  系统级错误
failbit状态  可恢复错误
eofbit状态  到达文件结束位置
goodbit状态  无错误

badbit位被置1时，failbit位也会被置1
eofbit置1, failbit位也会被置1
<mark style="background: #ABF7F7A6;">badbit位被置1或eofbit位被置1时，failbit位也会被置为1。所以用fail()函数可以准确判断出流对象是否出现错误</mark>。

总结就是, 记住bad()检查系统级错误, fail()检查可恢复错误

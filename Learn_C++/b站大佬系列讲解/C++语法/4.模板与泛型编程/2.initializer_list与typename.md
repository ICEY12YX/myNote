#include<type_traits>  //下面使用is_pointer需要这个库

//加上特化
template<typename T>
struct get_type
{
	using type = T;
};

template<typename T>
struct get_type<T*>
{
	using type = T;
};

template<typename T>
class MyArray { ... }  //里面和上面一样

template<typename T>
MyArray<T>::MyArray(const std::initializer_list<T>& list) {

	if (list.size()) {  //不为空就创建数组

		unsigned count = 0;
		data = new T[list.size()]();

        //如果T是指针类型,做深拷贝
		if (std::is_pointer<T>::value) {
			for (auto elem : list) {
				data[count++] = new typename get_type<T>::type(*elem);
			}
		}
		else {  //不是指针类型就简单赋值
			for (const auto& elem : list) {
				data[count++] = elem;
			}
		}

	}
	else {
		data = nullptr;
	}
}  //左值版本

//右值版本就这样,没啥好说的
template<typename T>  
MyArray<T>::MyArray(const std::initializer_list<T>&& list) {
	if (list.size()) {  //不为空就创建数组

		unsigned count = 0;
		data = new T[list.size()]();
		for (const auto& elem : list) {
			data[count++] = elem;
		}
	}
	else {
		data = nullptr;
	}
}  //右值版本

`get_type<T>::type` 这是什么?
    应该是定义在模版中的结构体的标准用法,[[题外话 之 萃取&特化]]  这里有写
    ![[Pasted image 20250613194821.png]]

具体解释
    ![[Pasted image 20250613194859.png]]
    (然后typename代表 `get_type<T>::type`这一整个是个类型)
    (相当于把* elem给`get_type<T>::type`这个类型的变量)
    (比如T是int*  那elem就是指针,* elem取指针内容,然后把这个内容给一个新的`get_type<T>::type`这个类型的变量)
    就做到深拷贝了(让两个变量互相不得噶, 独立,不会两个指针指向同一片内存)

但是上面还没完,只是这样写,会内存泄漏
    因为如果T是int*,比如创建了MyArray类型的arrI2,里面存了好多int*
    当main结束,arrI2要析构,那就调用MyArray类型的析构
    MyArray类型的析构里面把arrI2的data置空
    data是T* 类型,就是int** 类型  (注意区分  data是int** 类型 arrI2是MyArray* 类型)
    (这里arrI2不需要delete,因为arrI2不是new出来的, 而arrI2内部的数组,就是data需要delete,这个delete在析构里自动完成)
    但是此时data是int**
    析构里只delete了一层

大佬说要改的话
```cpp
private:
	T* data;
```

```cpp
private:
	std::vector<T> data;  //改成这样
```
此时data不是简单的指针类型,它是vector类型, 可能是vector对`delete[] data;` 这样的写法有做处理,可以把里面的内存彻底释放

其他地方不需要改,因为其他我们在用data的地方std::vector类型是适配的, 比如`data = new T[list.size()]();`  `data[count++]`

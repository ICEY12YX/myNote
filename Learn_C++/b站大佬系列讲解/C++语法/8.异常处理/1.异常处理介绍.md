<mark style="background: #ABF7F7A6;">接收传递过来的被除数，我们难以判断被除数是否为0，此时异常处理就很有意义了</mark>

//除法
int divide(int divisior, int dividend) {
	if (!dividend) {  //除数为0
		//throw "dividend is zero";
		throw std::string("dividend is zero"); //一般不会直接抛出字符串,而是用string封装一下
	}
	return divisior / dividend;
}

//标准的封装输入功能
void clientInputNum(const std::string& str, int& num) {
	std::cout << str << std::endl;  //这个str什么用,请看main里怎么用(就是个提示现在输入的是什么)

	while (std::cin >> num, !std::cin.eof()) {
		if (std::cin.bad()) {
			throw std::runtime_error("cin is corrupted");
		}
		if (std::cin.fail()) {
			std::cin.clear();
			std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
			std::cout << "number format error,please input again" << std::endl;
			continue;
		}
		break;  //输入成功就break循环
	}
}

int main() {
	int divisior = 0;
	int dividend = 0;

	clientInputNum("please input divisior", divisior);
	clientInputNum("please input dividend", dividend);

	//可能抛出异常的放try里
	try {
		std::cout << divide(divisior, dividend) << std::endl;
	}
	catch (const std::string& except) {  //上面抛出的是字符串,这里也要用字符串接收
		std::cout << "exception occers: " << except << std::endl;
	}
	//一般处理异常,都要写这个
	catch (...) {  //接收任何种类的异常(就不局限于string了,这里只是演示catch (...),代码里没有抛出别的异常的可能)
		std::cout << "exception occers: unknown exception" << std::endl;
	}
}

<mark style="background: #ABF7F7A6;">接收文件名，如果文件不存在，我们可以按照之前的写法要求重发一遍，也可以直接报异常，异常就是文件不存在</mark>

void outPutFileContent(const std::string& fileName) {
	std::ifstream ifs(fileName);
	std::string fileLineContent;

	if (ifs.is_open()) {  //打开了
		while (ifs >> fileLineContent) {
			std::cout << fileLineContent << std::endl;
		}
		if (ifs.bad()) {
			throw std::runtime_error("ifs is corrupted");
		}
		ifs.close();
	}
	else {  //没打开
		if (ifs.bad()) {
			throw std::runtime_error("ifs is corrupted");
		}
		if (ifs.fail()) {
			throw std::runtime_error("ifs not exist");
		}
	}
}


int main() {

	try {
		outPutFileContent(str);

	catch (const std::string& except) {
		std::cout << "exception occers: " << except << std::endl;
	}
	catch (...) {
		std::cout << "exception occers: unknown exception" << std::endl;

<mark style="background: #ABF7F7A6;">我们在动态分配内存时，经常出现内存不足的情况（在大型程序中，这是非常常见）。比如我们需要动态分配一个未知大小的数组，数组大小等待传入。使用new操作符会直接抛出bad_alloc的异常</mark>
```cpp
int main() {
	try {
		while (1) {
			int* pi = new int[1000000000]();  //可能太大导致内存分配失败(虽然实测我的vs不会丢出异常)
		}
	}
	catch (const std::bad_alloc& except) {
		std::cout << except.what() << std::endl;  //.what()是所有c++标准异常都自带的函数,返回此时发生的异常全名
	}
	catch (...) {
		std::cout << "exception occers: unknown exception" << std::endl;
	}

}
```
上面的代码可能抛出bad allocation异常

此外<mark style="background: #ABF7F7A6;">使用智能指针时如果内存分配不够也会抛出bad_alloc的异常</mark>
```cpp
int main() {
	std::vector<std::shared_ptr<int>> shared_int_vec;  //创建一个存shared_ptr的数组

	try {
		while (1) {
			std::unique_ptr<int> uniqueI(new int[1000000]());
			shared_int_vec.push_back(std::move(uniqueI));  //智能指针也是会内存泄漏的
		}
	}
	catch (const std::bad_alloc& except) {
		std::cout << except.what() << std::endl;  //.what()是所有c++标准异常都自带的函数,返回此时发生的异常全名
	}
	catch (...) {
		std::cout << "exception occers: unknown exception" << std::endl;
	}

}
```
上面如果都用unique_ptr,那出了{ },unique_ptr就会被释放
我们为了演示内存不够导致内存分配失败的异常,不想让unique_ptr释放
那就用shared_ptr

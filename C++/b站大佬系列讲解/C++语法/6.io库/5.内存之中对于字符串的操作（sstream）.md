___
对于文件流来说,必须关联文件,就是必须给它一个文件名,让它去找关联的文件
字符串流不一样,它内部有默认关联的字符串(是个空串)

<mark style="background: #ABF7F7A6;">对于string流，io库是没有像cout，cin这样的自定流对象的。流对象需要我们自己去定义</mark>
同样也有3种初始化方式
sstream strm：strm是一个未绑定的stringstream对象(就是默认构造函数)
```cpp
int main(){
    std::istringstream istrStream;
    std::ostringstream ostrStream;
    std::stringstream strStream;
}
```

Sstream strm(s)：<mark style="background: #ABF7F7A6;">strm是一个绑定了s的拷贝的string流对象。s是一个string对象</mark>
```cpp
int main(){
    std::string str("hello");
    std::istringstream istrStream(str);
}
```

strm.str()： 空参的str,返回strm所保存的string的拷贝,打印出来就是string的内容
strm.str(s)：将s拷贝到strm中，返回void, 就是原本strm绑定的string内容被销毁了,保存新的字符串了
```cpp
int main(){
    std::string str("hello");
    std::istringstream istrStream(str);

    std::cout << istrStream.str() << std::endl;
    
    istrStream.str("fanfan");
    std::cout << istrStream.str() << std::endl;
}
```

___

string流对象的作用: **对数据类型进行转化**(占比95%)  &&  对空格分隔的字符串的切分

<mark style="background: #ABF7F7A6;">string转化为int等类型</mark>
    比如"12" 可以转换成 int 12
    但是"wdhsdfhu"  肯定转换不成int
```cpp
int main() {
	std::string str("12");
	//std::string str("aaa");  此时就不行
	std::stringstream strStream(str);

	int i = 0;
	strStream >> i;
	if (strStream.bad()) {
		throw std::runtime_error("strStream is corrupted");
	}
	else if (strStream.fail()) {
		strStream.clear();
		strStream.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
	}
	else {
		std::cout << i << std::endl;
	}

	std::cout << "process complete" << std::endl;
}
```
(用istringStream也可以,因为本来就是输入)


<mark style="background: #ABF7F7A6;">int等类型转化为string</mark>
```cpp
int main() {
    int srcI = 100;
	std::stringstream strStream;
	strStream << srcI << std::endl;  

	if (strStream.bad()) {
		throw std::runtime_error("strStream is corrupted");
	}
	else {
		std::cout << strStream.str() << std::endl;
	}

	std::cout << "process complete" << std::endl;
}
```

<mark style="background: #ABF7F7A6;">对空格分隔的字符串的切分</mark>  就是把字符串按空格切分单词
```cpp
int main() {
    std::string srcStr("fan fan fan");
    std::string destStr;
	std::stringstream strStream(srcStr);
	while(strStream >> destStr){  //这样就可以做到分隔单词
    	std::cout << destStr << std::endl;
	}

	if (strStream.bad()) {
		throw std::runtime_error("strStream is corrupted");
	}
}
```

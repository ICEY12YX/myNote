<mark style="background: #ABF7F7A6;">友元就是可以让另一个类或函数访问私有成员</mark>
    友元是针对某个类而言的,想拉另一个类或函数做自己的朋友

下面这样写,Test2里的outPut肯定拿不到test.name,test.age
```cpp
class Test{
    
private:
    std::string name;
    unsigned age;
};

class Test2{
public:
    void outPut(const Test& test){
        std::cout<< test.name << test.age << std::endl;
    }
}
```
下面那样写一句,让某个类做自己的朋友
```cpp
class Test{
    friend class Test2;  //Test2是我的朋友,可以用我的类里的私有成员了

private:
    std::string name;
    unsigned age;
};

class Test2{
public:
    void outPut(const Test& test){
        std::cout<< test.name << test.age << std::endl;
    }
}
```
也可以让某个函数成为我的朋友
```cpp
class Test{
    friend void outPut(const Test& test);  //outPut函数是我的朋友

private:
    std::string name;
    unsigned age;
};

void outPut(const Test& test){
    std::cout<< test.name << test.age << std::endl;
}
```

<mark style="background: #ABF7F7A6;">友元会破坏封装性，一般不推荐使用，所带来的方便写几个接口函数就解决了</mark>
    可以这样改
```cpp
class Test{
public:
    std::string getName() const {
        return name;
    }

    unsigned getAge() const {
        return age;
    }

private:
    std::string name;
    unsigned age;
};

void outPut(const Test& test){
    std::cout<< test.getName() << test.getAge() << std::endl;
}
```

<mark style="background: #ABF7F7A6;">某些运算符的重载必须用到友元的功能，这才是友元的真正用途</mark>

多态可以实现,<mark style="background: #FFF3A3A6;">父类实例,调用子类函数</mark>
    为什么要调子类函数?
    因为可以父类写一个函数,然后子类重写这个函数
    父类有时候需要这么做(就是调用子类那些重写过的函数)

<mark style="background: #ABF7F7A6;">当父类指针指向子类对象，且子类重写父类某一函数时。父类指针调用该函数</mark>，就会产生以下的可能
该函数为<mark style="background: #ABF7F7A6;">虚函数：父类指针调用的是子类的成员函数</mark>。
该函数<mark style="background: #ABF7F7A6;">不是虚函数：父类指针调用的是父类的成员函数</mark>。
```cpp
class Qiang{
public:
    Qiang(const std::string& name_,const int speed_,const int hit_):name(name_),speed(speed_),hit(hit_){
        std::cout << "Qiang()" << std::endl;
    }

    void Fire() const{  
        std::cout << "Qiang::Fire()" << std::endl;
    }
protected:
    std::string name;
    int speed;
    int hit;
}

class xiaoLv : public Qiang{
public:
    xiaoLv(const std::string& name_,const int speed_,const int hit_,const  int a_):Qiang(name_,speed_,hit_),a(a_){  //这里要写上调用父类构造函数
        std::cout << "xiaoLv()" << std::endl;
    }

    void Fire() const{  //重写
        std::cout << "xiaoLv::Fire()" << std::endl;
    }
private:
    int a; //随便取的
}

void Fire(const Qiang* qiang){
    qiang->Fire();
    delete qiang;  //这句跟本节无关,但很重要,因为对象是被我们new出来的,这里记得delete
}

int main(){
    Fire(new xiaoLv("xiaoLv",10,10,1));  //数据随便编的
}
```

<mark style="background: #ABF7F7A6;">父类的析构函数必须为虚函数：这一点很重要，当父类对象指向子类对象时，容易使独属于子类的内存泄露。会造成内存泄露的严重问题</mark>
    当父类对象指向子类对象时,然后父类的析构函数不是虚函数
    那像上面说的,就不会去找虚函数表,就只会调用父类的析构
    然后父类的析构只能释放父类那部分成员变量的内存,子类独有的成员释放不掉
    就会内存泄漏
    所以这个时候必须明确写出父类析构,加上virtual

静态绑定：<mark style="background: #ABF7F7A6;">程序在编译时就已经确定了函数的地址，比如非虚函数就是静态绑定</mark>。
动态绑定：<mark style="background: #ABF7F7A6;">程序在编译时确定的是程序寻找函数地址的方法，只有在程序运行时才可以真正确定程序的地址，比如虚函数就是动态绑定</mark>
    静态绑定 就是如果要调用成员函数,编译的时候就已经知道函数地址了,执行的时候只用去对应地址就好了
    动态绑定 这里就是编译时确定之后要去虚函数表里找函数地址

<mark style="background: #ABF7F7A6;">每个有虚函数的类都会有一个虚函数表，对象其实就是指向虚函数表的指针，编译时编译器只告诉了程序会在运行时查找虚函数表的对应函数。每个类都会有自己的虚函数表，所以当父类指针引用的是子类虚函数表时，自然调用的就是子类的函数。</mark>

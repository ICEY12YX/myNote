多继承, 就是一个类同时继承多个类，在内存上，该类对象前面依次为第一个继承的类，第二个继承的类，依次类推
    像下面的代码,子类Son被创建时,会先调用Base1构造函数,再Base2构造函数,最后Son构造函数
    析构也是一样的
    (所以和普通的继承是一样的)
```cpp
class Base1 {
public:
	Base1(int base1_) :base1(base1_) {}
protected:
	int base1;
};

class Base2 {
public:
	Base2(int base2_) :base2(base2_) {}
protected:
	int base2;
};

class Son :public Base1, public Base2 {  //同时继承两个父类
public:
	Son(int base1_, int base2_, int i_) :Base1(base1_), Base2(base2_), i(i_) {}
private:
	int i;
};
```

多继承最需要注意的点就是<mark style="background: #ABF7F7A6;">重复继承的问题</mark>
    比如下面的情况,父类子类都有一个叫i的变量(这个还好,问题不大)
```cpp
class Base1 {
public:
	Base1(int base1_) :base1(base1_) {}
protected:
	int base1;
	int i = 10;
};

class Base2 {
public:
	Base2(int base2_) :base2(base2_) {}
protected:
	int base2;
	int i = 20;
};

class Son :public Base1, public Base2 {  //同时继承两个父类
public:
    //上面偷懒了,父类的i直接赋值了,所以这里子类构造函数和父类构造函数都没写,父类i的初始化
	Son(int base1_, int base2_, int i_) :Base1(base1_), Base2(base2_), i(i_) {}
private:
	int i; 
};
```
最后如果main里创建Son实例 son,并调用i  `son.i`最后拿到的是子类的i

但如果只是两个父类里有重复的成员变量
```cpp
class Base1 {
public:
	Base1(int base1_) :base1(base1_) {}
protected:
	int base1;
	int a = 10;
};

class Base2 {
public:
	Base2(int base2_) :base2(base2_) {}
protected:
	int base2;
	int a = 20;
};

class Son :public Base1, public Base2 {  //同时继承两个父类
public:
    //上面偷懒了,父类的i直接赋值了,所以这里子类构造函数和父类构造函数都没写,父类i的初始化
	Son(int base1_, int base2_, int i_) :Base1(base1_), Base2(base2_), i(i_) {}
private:
	int i; 
};
```
此时`son.a`就不知道调用哪个父类的a
但是可以通过`son.Base1::a`这样调用 ,指明调用哪个类的成员变量

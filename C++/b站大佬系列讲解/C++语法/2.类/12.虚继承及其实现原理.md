<mark style="background: #ABF7F7A6;">虚继承就是为了避免多重继承时产生的二义性问题</mark>
    比如下面这种情况
```cpp
class TrueBase {  //定义一个父类的父类
public:
	int a = 100;  //偷懒的写法
};

class Base1 : public TrueBase {  //继承
public:
	Base1(int base1_) :base1(base1_) {}
protected:
	int base1;
};

class Base2 : public TrueBase {  //继承
public:
	Base2(int base2_) :base2(base2_) {}
protected:
	int base2;
};

class Son :public Base1, public Base2 {
public:
	Son(int base1_, int base2_, int i_) :Base1(base1_), Base2(base2_), i(i_) {}
private:
	int i;
};

int main() {
	Son son = Son(10, 20, 1);
	std::cout << son.a << std::endl;  //现在乍看这样没问题
}
```
现在乍看这样没问题,实际上son.a会报错
![[Pasted image 20250611012631.png]]
原因是Base1,Base2分别继承TrueBase,那Base1,Base2里面都会有a
则Son在继承的时候,Son里就会有两个成员变量都叫a

所以用到虚继承
    虚继承可以让重名的成员变量,"变为"一个
```cpp
class TrueBase {  //定义一个父类的父类
public:
	int a = 100;  //偷懒的写法
};

class Base1 : virtual public TrueBase {  //继承
public:
	Base1(int base1_) :base1(base1_) {}
protected:
	int base1;
};

class Base2 : virtual public TrueBase {  //继承
public:
	Base2(int base2_) :base2(base2_) {}
protected:
	int base2;
};

class Son :public Base1, public Base2 {
public:
	Son(int base1_, int base2_, int i_) :Base1(base1_), Base2(base2_), i(i_) {}
private:
	int i;
};

int main() {
	Son son = Son(10, 20, 1);
	std::cout << son.a << std::endl;  //现在就没问题了
}
```

原理:
<mark style="background: #ABF7F7A6;">使用了虚继承的类会有一个虚继承表，表中存放了父类所有成员变量相对于类的偏移地址。</mark>
    就是说虚继承的父类,此时子类不是直接存下父类成员变量,而是存下偏移地址

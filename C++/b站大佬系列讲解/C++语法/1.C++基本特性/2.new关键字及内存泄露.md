new就是想把变量或类啥的放堆上
<mark style="background: #FFF3A3A6;">用new关键字返回的都是指针</mark>
new关键字要搭配delete使用

分配单个对象的内存时。
<mark style="background: #ABF7F7A6;">当对象是普通变量时，可以用new分配对应的内存</mark>
```cpp
int main() {
	int* pi = new int(100);  //用new分配普通变量
	std::cout << *pi << std::endl;
	
	int* pi1 = new int();  //这样不行,会得到一个未定义的值(就是不知道到底是啥值)
	std::cout << *pi1 << std::endl;
	
	delete pi; //和new配套(这里只是为了演示,所以只写了一个delete)
	std::cin.get();
	
}
```

分配单个对象的内存时。
<mark style="background: #ABF7F7A6;">当对象是类对象时，会调用构造函数，如果没有对应的构造函数，就会报错</mark>
```cpp
int main() {
	std::string* pString = new std::string("hello");  //用new分配对象
	std::cout << *pString << std::endl;
	
	//因为是系统自带的类,所以应该是定义了这种行为(没有像上面说的那样报错)
	std::string* pString1 = new std::string;  //这里不写,和下面指向()都会返回默认值,就是空字符串
	std::cout << *pString1 << std::endl;
	
	std::string* pString2 = new std::string();
	std::cout << *pString2 << std::endl;
	
	delete pString; //和new配套(这里只是为了演示,所以只写了一个delete)
	std::cin.get();
}
```


在分配数组对象内存时：
<mark style="background: #ABF7F7A6;">对于普通变量：可以使用“（）”将所有对象全部初始化为0。</mark>
```cpp
int main() {
	int* pi = new int[100]();  //用new分配数组,会给每个元素分配默认值0
	std::cout << pi[20] << std::endl;  //得到0
	
	int* pi1 = new int[100];  //这样不行,会得到未定义的值(就是不知道到底是啥值)
	std::cout << pi1[20] << std::endl;  
	
	int* pi2 = new int[100](100);  //想这样赋初值不行
	
	//注意数组的delete要写成这样,加个[]
	delete[] pi; //和new配套(这里只是为了演示,所以只写了一个delete)
	std::cin.get();
	
}
```

在分配数组对象内存时：
<mark style="background: #ABF7F7A6;">对于类对象，有没有“（）”都一样，均使用默认构造函数，如果没有默认构造函数就会报错。</mark>
```cpp
int main() {
	std::string* pString = new std::string[100]();  //用new分配对象数组
	std::cout << pString[20] << std::endl;  //因为均使用默认构造函数,所以全是空字符串
	
	std::string* pString1 = new std::string[100];  //所以这样也可
	std::cout << pString1[20] << std::endl;
	
	std::string* pString = new std::string[100]("hello");  //想这样赋初值不行
	
	std::cin.get();
}
```

```cpp
//类里有一些书写习惯,比如private的成员变量会名字前加'm_'
//构造函数的形参会名字后加'_',

class Test {
public:
	Test(int i_):m_i(i_){}
private:
	int m_i;
};

int main() {
	Test* test = new Test[100]();  //这样不行,因为并没有默认构造函数
	std::cin.get();
}
```
	只定义了一个带参数的构造函数 Test(int i_)，这个时候编译器 就不会自动生成默认构造函数 Test()
	如果类没有默认构造函数，就不能用 new Test[N] 或 new Test[N]() 的方式动态分配数组
	
```cpp
class Test {
public:
    Test() : m_i(0) {}  // 默认构造函数
    Test(int i_) : m_i(i_) {}
private:
    int m_i;
};

int main() {
    Test* test = new Test[100]();  // 现在可以编译
    delete[] test;  // 记得释放内存
    std::cin.get();
}
```

___
<mark style="background: #ABF7F7A6;">如果一个对象可以使用调用运算符“()”，()里面可以放参数，这个对象就是可调用对象</mark>
这个可调用对象,就三种函数/仿函数/lambda表达式

___

函数
```cpp
void test() {
	std::cout << "hello" << std::endl;
}

int main() {
	test();  //test就是可调用对象,()是个运算符
	std::cin.get();
}
```

函数也可以当做另一个函数传入的参数(就是用到函数指针)
```cpp
void test(int i) {
	std::cout << "hello" << std::endl;
}

using pf_type = void(*)(int);  //c++风格
//也可以写成
//typedef void(*pf_type)(int)  //c风格

int myFunc(pf_type pf,int i) {
	pf(i)
}

int main() {
	int i = 100;
	myFunc(test, i);
	std::cin.get();
}
```

___

仿函数
<mark style="background: #ABF7F7A6;">具有operator()函数的类对象,此时类对象可以当做函数使用，因此称为仿函数</mark>
(先知道有这么个东西,后面会讲)
```cpp
class Test {
public:
	void operator()(int i) {
		std::cout << "operator" << std::endl;
		std::cout << i << std::endl;
	}
};

int main() {
	int i = 100;
	Test t;
	t(i);  //本来是类对象,但是现在可以像函数一样使用了
	std::cin.get();
}
```

lambda表达式
lambda表达式的格式：最少是“[] {}”，完整的格式为“[] () ->ret {}”
```cpp
//比如我直接main里写个lambda,下面这样写就是直接定义函数+运行了
int main() {
	[] {
		std::cout << "hello" << std::endl;
		}();
	std::cin.get();
}
```
```cpp
//加上捕获列表
int main() {
    int i = 10;
	[=] {  //也可以[&]捕获引用,那就是不产生copy了
    	std::cout << i << std::endl;
		std::cout << "hello" << std::endl;
		}();
	std::cin.get();
}
```
```cpp
//加上传入的参数(前面表示定义传参,后面表示传入参数)
int main() {
    int i = 10;
	[](int number) {  
    	std::cout << number << std::endl;
		std::cout << "hello" << std::endl;
		}(200);
	std::cin.get();
}
```
```cpp
//加上传入的参数(前面表示定义传参,后面表示传入参数)
int main() {
    int i = 10;
    //这里写了个ret用来存函数返回值(跟函数本身的定义没关系)
	auto ret= [](int number) ->int {  //->int表示指定函数返回类型为int
    	return number; //函数体里一样要写返回什么
		}(200);

    auto ret1= [](int number) {  //这里也可以不写,那lambda表达式会推断出返回类型
    	return number; //函数体里一样要写返回什么
		}(200);
	std::cin.get();
}
```
```cpp
//lambda最常用的地方,就是函数指针
//(下面的代码稍微有点绕,需要理解一下)
using pf_type = void(*)(int);

//myFunc定义
void myFunc(pf_type pf, int i) {
	pf(i);
}

int main() {
	//myFunc调用
	//传入lambda,就省的在外面写一个可能只用一次的函数 的定义了
	//(int i)是lambda的传参
	//200是myFunc的传参
	myFunc([](int i) {
		std::cout << i << std::endl;
		}, 200);

	std::cin.get();
}
```

```cpp
//补充

//还是上面的代码
int main() {
	int a=90;  //多写一个变量
	//如果这里直接捕获a,会报错,因为当lambda作为函数指针的时候,捕获列表必须为空,写外面的变量,是捕获不到的
	myFunc([a](int i) {  
		std::cout << i << std::endl;
		}, 200);

	std::cin.get();
}
```

```cpp
//解决办法就是用functional包裹函数指针,
#include<functional>

using func_type = std::function<void(int)>;

//myFunc定义
void myFunc(func_type pf, int i) {
	pf(i);
}

int main() {
	int a=90;  //多写一个变量
	myFunc([a](int i) {  //这样就能捕获到了
		std::cout << i << std::endl;
		}, 200);

	std::cin.get();
}
```

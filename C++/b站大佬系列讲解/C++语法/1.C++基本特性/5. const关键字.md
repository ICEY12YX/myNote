const是让编译期将变量视为常量，<mark style="background: #ABF7F7A6;">用const修饰的变量和真正的常量有本质的区别</mark>
```cpp
int main() {
	const int a = 10;
	int b = 10;
	std::cin.get();
}
```
    像上面的a虽然是常量,但是实际上和b存的位置是一样的,存在栈区(黄色的)(只是a不能修改)
    像1,20,"sjs"等是真正的常量存在只读区(绿色的)

<mark style="background: #ABF7F7A6;">unque_ptr禁止复制构造函数，也禁止赋值运算符的重载。否则独占便毫无意义</mark>
    因为unque_ptr本来就是 **独占式**智能指针,
    就是这块内存只能一个unque_ptr接管
    想要"共享",请用shared_ptr
```cpp
int main() {
	std::unique_ptr<int> uniqueI = std::make_unique<int>(100);
	std::unique_ptr<int> uniqueI2(uniqueI);  //不行
}
```

```cpp
int main() {
	std::unique_ptr<int> uniqueI = std::make_unique<int>(100);
	std::unique_ptr<int> uniqueI2 = std::make_unique<int>(1000);
	uniqueI2 = uniqueI; //不行
}
```

reset函数：
不带参数的情况下：释放智能指针的对象，并将智能指针置空。
带参数的情况下：<mark style="background: #ABF7F7A6;">释放智能指针的对象，并将智能指针指向新的对象</mark>。
```cpp
int main() {
	std::unique_ptr<int> uniqueI = std::make_unique<int>(100);
	
	uniqueI.reset(new int(10)); //把原来的堆内存释放,然后uniqueI指向新的堆内存
}
```

___

<mark style="background: #ABF7F7A6;">将unque_ptr的对象转化为shared_ptr对象，当unique_ptr的对象为一个右值时，就可以将该对象转化为shared_ptr的对象</mark>
这个使用的并不多，需要将独占式指针转化为共享式指针常常是因为先前设计失误。
注意：<mark style="background: #ABF7F7A6;">shared_ptr对象无法转化为unique_ptr对象</mark>。
    就是说用std::move把uniqueI转换成右值,然后让sharedI接管这片内存完成"转化"
```cpp
void Fun(std::unique_ptr<int> uniqueI){
    //可能函数里想让uniqueI可以共享
    //那可以转换成shared_ptr
    std::shared_ptr<int> sharedI(std::move(uniqueI));  
    //但是因为用到了std::move所以要保证,之后绝不再用uniqueI
}
```

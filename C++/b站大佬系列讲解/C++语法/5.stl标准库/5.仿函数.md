常用的仿函数:
`std::plus` 就加法
```cpp
int main(){
    std::plus<int> iPlus;
    std::cout << iPlus(1,2) << std::endl;
}
```


```cpp
int main(){
    std::vector<int> ivec{7,3,5,9,4};
    //std::sort(ivec.begin(),ivec.end(),[](int a,int b){
    //    return a > b;
    //});
    
    //或者这样实现降序
```

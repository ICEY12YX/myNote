用miniproject的三个文件开始
刚开始直接在VS 上运行 是不行的(大概原因是VS找不到.h文件,不知道这几个文件是一个项目)

先创建CmakeLists.txt
```txt
cmake_minimum_required(VERSION 4.1.0)
project(MiniProject LANGUAGES CXX VERSION 0.1.0 DESCRIPTION "Demo Project of Complex Number")
add_executable(demo)
target_sources(demo
    PRIVATE
        main.cpp
        complex.cpp
        complex.h
)
```

`g++ main.cpp complex.o -o demo` `

使用cmake
```txt
cmake_minimum_required(VERSION 4.1.0)
project(MiniProject LANGUAGES CXX VERSION 0.1.0 DESCRIPTION "Demo Project of Complex Number")
add_executable(demo)
target_sources(demo PRIVATE main.cpp)

#add_library这个会生成.lib文件
add_library(complex)
target_sources(complex PRIVATE complex.cpp complex.h)

target_link_libraries(demo PRIVATE complex)
```

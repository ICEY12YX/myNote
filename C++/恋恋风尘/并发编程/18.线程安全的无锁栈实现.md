单线程入栈(用链表)
1 创建新节点
2 将元素入栈，将新节点的next指针指向现在的head节点。
3 将head节点更新为新节点的值

多线程下,没锁的话,就用原子变量
可以通过原子变量的compare_exchange(比较交换操作)来控制更新head节点

节点结构
```cpp
template<typename T>
struct node
{
    T data;
    node* next;
    node(T const& data_) : 
            data(data_)
    {}
};
```

无锁栈的结构
```cpp
template<typename T>
class lock_free_stack {
private:
    struct node {
    T data;
    node* next;
    node(T const& data_) : data(data_){}
};

    //拷贝构造和拷贝赋值删除
    lock_free_stack(const lock_free_stack&) = delete;
    lock_free_stack& operator = (const lock_free_stack&) = delete;

    std::atomic<node*> head;
public:
    lock_free_stack() {}
}
```

push操作
```cpp
template<typename T>
void push(const T& value){
    auto new_node = new Node(value);  //创建新结点
    do{
        new_node->next = head.load();
    }while(!head.compare_exchange_strong(new_node->next, new_node));
}
```
[[12.通过内存顺序实现内存模型]]里有讲到`compare_exchange_strong`
    这里就先head和new_node->next比较
    等于  那就head置为new_node  然后整体返回true(非一下false)退出循环
    不等于那就new_node->next置为head  然后整体返回false(继续循环)

比如两个线程都push
都执行到`new_node->next = head.load();` 只有一个线程能成功执行`head.compare_exchange_strong(new_node->next, new_node)` 让head等于new_node
退出循环
另一个线程此时的head不等于new_node->next,那就new_node->next等于head(其实这句就相当于执行了do里面的语句)  然后继续循环


单线程pop操作的顺序
1 取出头节点元素
2 更新head为下一个节点。
3 返回取出头节点元素的数据域。

我们也像push的思路,写一个pop
```cpp
template<typename T>
void pop(T& value){
    do{
        node* old_head = head.load(); //1
    }while(!head.compare_exchange_strong(old_head, old_head->next)); //2
    value = old_head->data; //3
}
```

但是这个pop有几点问题
1. 未判断空栈的情况，这一点比较好处理，如果为空栈我们可以令pop返回false，或者抛出异常，当然抛出异常不可取。
2.  将数据域赋值给引用类型的value时存在拷贝赋值(3处)，我们都知道拷贝赋值会存在异常的情况(比如数据太大了,没空间了)，当异常发生时元素已经从栈定移除了,那数据就丢失了，这一点和锁处理时不一样，锁处理的时候是先将元素数据域取出赋值再出栈，所以不会有问题，但是无锁的方式就会出现栈被破坏的情况。解决方式也比较简单，数据域不再存储T类型数据，而是存储`std::shared_ptr<T>`类型的数据。智能指针在赋值的时候开销小,异常概率小
3. 未释放弹出的节点的内存

修改node结构
```cpp
struct node{
    std::shared_ptr<T> data;
    node* next;
    node(T const& data_) : data(std::make_shared<T>(data_)){}
};
```

修改pop
只是node的data部分是智能指针
old_head仍然是裸指针,需要释放内存
```cpp
template<typename T>
std::shared_ptr<T> pop() {
    node* old_head = nullptr;        
    do {
        old_head = head.load();
        if (old_head == nullptr) {
            return nullptr; 
        }
    } while (!head.compare_exchange_strong(old_head, old_head->next));      

    std::shared_ptr<T> res;  
    //将old_head的data值转移给res,相当于清除old_head的data(变成空智能指针)
    res.swap(old_head->data); 
    delete old_head;  
    return res;   
}
```
但是上面`delete old_head; ` 仍然存在问题
    比如线程1执行到`delete old_head;`，
    而线程2刚好执行到`head.compare_exchange_weak(old_head, old_head->next)`用到了和线程1相同的old_head，`old_head->next`会引发崩溃。

所以我们需要延迟删除节点
思路如下
1. 如果有多个线程同时pop，而且存在一个线程1已经交更新了head值，另一个线程2即将基于旧有的head获取next数据，如果线程1删除了旧有head，线程2就有可能产生崩溃。这种情况我们就要将线程1取出的head放入待删除的列表。(就是上面的情况)

2. 同一时刻仅有一个线程1执行pop函数，不存在其他线程。那么线程1可以将旧head删除，并删除待删列表中的其他节点。(此时想怎么删怎么删)

3. 如果线程1已经将head节点交换弹出，线程2还未执行pop操作，当线程1准备将head删除时,此时线程2进入执行pop操作,此时线程2执行`old_head = head.load();`已经取到的是head新值，那么线程1能将旧head删除.
    此情形和情形1略有不同，情形1是两个线程同时pop只有一个线程交换成功的情况，情形3是一个线程已经将head交换出，准备删除之前发现线程2执行pop进入，所以这种情况下线程1可将head删除，但是线程1不能将待删除列表删除，因为有其他线程可能会用到待删除列表中的节点。

还有一种情况
    线程1 执行pop已经将head换出
    线程2 执行pop函数，发现线程1正在pop操作，线程2就将待删除的节点head(此head非线程1head)放入待删列表.
    线程3 和线程2几乎同时执行pop函数但是还未执行head的交换操作，此head和线程2的head相同。
    这种情况下线程1可能读取待删列表为空，因为线程2可能还未更新，也可能读取待删列表不为空(线程2已更新)，但是线程1不能删除这个待删列表，因为线程3可能在用。

所以
1. 如果head已经被更新，且旧head不会被其他线程引用，那旧head就可以被删除。否则放入待删列表。
2. 如果仅有一个线程执行pop操作，那么待删列表可以被删除，如果有多个线程执行pop操作，那么待删列表不可被删除。
(就先大致理解)

修改的代码
(`std::atomic<node*> to_be_deleted;` `std::atomic<int> threads_in_pop;`  增加这两个变量)
```cpp
std::shared_ptr<T> pop() {
     //1 计数器(同时多少线程在pop)首先自增，然后才执行其他操作
    ++threads_in_pop;  
    node* old_head = nullptr;     
    do {
        //2 加载head节点给旧head存储
        old_head = head.load();  
        if (old_head == nullptr) {
            --threads_in_pop;  //退出前,计数器--
            return nullptr; 
        }
    } while (!head.compare_exchange_weak(old_head, old_head->next)); // 3    
    //3处 比较更新head为旧head的下一个节点    

    std::shared_ptr<T> res;
    if (old_head)  //防御性措施，确保 swap 不会对 nullptr->data 操作（未定义行为）
    //但是实际上old_head也不会是nullptr
    {
        // 4 只要有可能，就回收已删除的节点数据
        res.swap(old_head->data);    
    }
    // 5 从节点提取数据，而非复制指针
    try_reclaim(old_head);   
    return res;
}

void try_reclaim(node* old_head)
{
    //1 原子变量判断仅有一个线程进入
    if(threads_in_pop == 1)
    {
        //2 当前线程把待删列表取出
        //to_be_deleted是node*,即待删链表的头指针
        node* nodes_to_delete = to_be_deleted.exchange(nullptr);
        //3 更新原子变量获取准确状态，判断pop是否仅仅正被当前线程唯一调用
        //(万一进来已经threads_in_pop就不是1了,所以要再判断一下)
        if(!--threads_in_pop)
        {
            //4 如果唯一调用则将待删列表删除
            delete_nodes(nodes_to_delete);
        }else if(nodes_to_delete)  //还有别的线程在pop,并且待删列表不为空
        {
            //5 那此时就很有可能to_be_deleted里面又有待删节点了
            //现在就是两条待删链表nodes_to_delete和to_be_deleted
            //所以要把nodes_to_delete重新合并到to_be_deleted
            chain_pending_nodes(nodes_to_delete);
        }
        delete old_head;
    }
    else { //多个线程pop竞争head节点，此时不能删除old_head
        //将其放入待删列表
        chain_pending_node(old_head);
        --threads_in_pop;
    }
}

//循环删除整个待删链表
static void delete_nodes(node* nodes)
{
    while (nodes)
    {
        node* next = nodes->next;
        delete nodes;
        nodes = next;
    }
}

void chain_pending_node(node* n)
{
    chain_pending_nodes(n, n);   
}

//上面调用chain_pending_node(old_head);的时候比较好理解,此时first,last是一个东西
//就相当于往to_be_deleted前面插一个节点
void chain_pending_nodes(node* first, node* last)
{
    //1 先将last的next节点更新为待删列表的首节点
    last->next = to_be_deleted;    
    //2  借循环保证 last->next指向正确
    // 将待删列表的首节点更新为first节点
    while (!to_be_deleted.compare_exchange_weak(last->next, first));     
}

//当调用chain_pending_nodes(nodes_to_delete);
//下面首先找到nodes_to_delete的末端,记为last,然后调用上面的函数
//上面的函数是  把nodes_to_delete的尾结点和to_be_deleted连上
//然后让to_be_deleted变为first(就是nodes_to_delete的头结点)
void chain_pending_nodes(node* nodes)
{
    node* last = nodes;
    //1 沿着next指针前进到链表末端
    while (node* const next = last->next)    
    {
        last = next;
    }
    //2 将链表放入待删链表中
    chain_pending_nodes(nodes, last);
}
```

完整代码
```cpp
﻿#pragma once
#include <memory>
#include <atomic>

template<typename T>
class lock_free_stack {
private:
	struct node {
		std::shared_ptr<T> data;
		node* next;
		node(T const& data_) :data(std::make_shared<T>(data_)) {}
	};
	lock_free_stack(const lock_free_stack&) = delete;
	lock_free_stack& operator = (const lock_free_stack&) = delete;
	std::atomic<node*> head;
	std::atomic<node*> to_be_deleted;
	std::atomic<int> threads_in_pop;
public:
	lock_free_stack() {}

	void push(T const& data) {
		node* const new_node = new node(data);    //⇽-- - 2			
		new_node->next = head.load();    //⇽-- - 3			
		while (!head.compare_exchange_weak(new_node->next, new_node));    //⇽-- - 4	
	}

	std::shared_ptr<T> pop() {
		++threads_in_pop;   //1 计数器首先自增，然后才执行其他操作
		node* old_head = nullptr; 	
		do {
			old_head = head.load();  //2 加载head节点给旧head存储
			if (old_head == nullptr) {
				--threads_in_pop;
				return nullptr; 
			}
		} while (!head.compare_exchange_weak(old_head, old_head->next)); // 3	比较更新head为旧head的下一个节点	
	
		std::shared_ptr<T> res;
		if (old_head)
		{
            // 4 只要有可能，就回收已删除的节点数据
			res.swap(old_head->data);    
		}
        // 5 从节点提取数据，而非复制指针
		try_reclaim(old_head);   
		return res;
	}

    void try_reclaim(node* old_head)
	{
        //1 原子变量判断仅有一个线程进入
		if(threads_in_pop == 1)
		{
			//2 当前线程把待删列表取出
            node* nodes_to_delete = to_be_deleted.exchange(nullptr);
            //3 更新原子变量获取准确状态，判断pop是否仅仅正被当前线程唯一调用
            if(!--threads_in_pop)
            {
	            //4 如果唯一调用则将待删列表删除
                delete_nodes(nodes_to_delete);
            }else if(nodes_to_delete)
            {
	            //5 如果pop还有其他线程调用且待删列表不为空，
	            //则将待删列表首节点更新给to_be_deleted
                chain_pending_nodes(nodes_to_delete);
            }
            delete old_head;
        }
        else {
            //多个线程pop竞争head节点，此时不能删除old_head
            //将其放入待删列表
            chain_pending_node(old_head);
            --threads_in_pop;
        }
	}

	static void delete_nodes(node* nodes)
	{
		while (nodes)
		{
			node* next = nodes->next;
			delete nodes;
			nodes = next;
		}
	}

	void chain_pending_node(node* n)
	{
		chain_pending_nodes(n, n);   
	}

	void chain_pending_nodes(node* first, node* last)
	{
		//1 先将last的next节点更新为待删列表的首节点
		last->next = to_be_deleted;    
		//2  借循环保证 last->next指向正确
		// 将待删列表的首节点更新为first节点
		while (!to_be_deleted.compare_exchange_weak(
			last->next, first));     
	}

	void chain_pending_nodes(node* nodes)
	{
		node* last = nodes;
		//1 沿着next指针前进到链表末端
		while (node* const next = last->next)    
		{
			last = next;
		}
		//2 将链表放入待删链表中
		chain_pending_nodes(nodes, last);
	}
};
```

```cpp
void TestLockFreeStack() {

    lock_free_stack<int> lk_free_stack;  
    std::set<int> rmv_set;  //存移出的元素
    std::mutex set_mtx;  //互斥访问set

    std::thread t1([&]() {
        for (int i = 0; i < 20000; i++) {
            lk_free_stack.push(i);
            std::cout << "push data " << i << " success!" << std::endl;
            std::this_thread::sleep_for(std::chrono::milliseconds(5));
            }
        });

    std::thread t2([&]() {
		for (int i = 0; i < 10000;) {
            auto head = lk_free_stack.pop();
            if (!head) {
				std::this_thread::sleep_for(std::chrono::milliseconds(10));
				continue;
            }
			std::lock_guard<std::mutex> lock(set_mtx);
			rmv_set.insert(*head);
            std::cout << "pop data " << *head << " success!" << std::endl;
            i++;
		}
      });

	std::thread t3([&]() {
		for (int i = 0; i < 10000;) {
			auto head = lk_free_stack.pop();
            if (!head) {
                std::this_thread::sleep_for(std::chrono::milliseconds(10));
                continue;
            }
            std::lock_guard<std::mutex> lock(set_mtx);
            rmv_set.insert(*head);
            std::cout << "pop data " << *head << " success!" << std::endl;
            i++;
		}
		});

    t1.join();
    t2.join();
    t3.join();

    assert(rmv_set.size() == 20000);
}
```

# 函数模版

函数模版是为了 定义一个和类型无关的函数
```cpp
template <typename T>
T functionName(T param) {
    // 函数体
}
```

最大值函数
```cpp
template <typename T>
T maxValue(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    //编译器根据函数参数自动推导模板参数类型(就是自动推导T是啥)
    std::cout << maxValue(3, 7) << std::endl;         // int 类型
    std::cout << maxValue(3.14, 2.72) << std::endl;  // double 类型
    std::cout << maxValue('a', 'z') << std::endl;    // char 类型
    return 0;
}
```
注意: 
    模版的定义 和 实现 要放一起
    模板参数列表以` template <typename T>` 或 `template <class T>` 开头，两者等价

# 类模版

```cpp
template <typename T>
class ClassName {
public:
    T memberVariable;
    // 构造函数、成员函数等
};
```

简单的pair类
```cpp
#include <iostream>
#include <string>

template <typename T, typename U>  //一个T类型一个U类型
class Pair {
public:
    T first;
    U second;

    Pair(T a, U b) : first(a), second(b) {}  //构造

    void print() const {
        std::cout << "Pair: " << first << ", " << second << std::endl;
    }
};

int main() {
    Pair<int, double> p1(1, 2.5);  //p1实例
    p1.print(); // 输出：Pair: 1, 2.5

    Pair<std::string, std::string> p2("Hello", "World");
    p2.print(); // 输出：Pair: Hello, World

    Pair<std::string, int> p3("Age", 30);
    p3.print(); // 输出：Pair: Age, 30

    return 0;
}
```
注意:
    类模版,必须用的时候用<>显示写你要的类型

# 非类型参数

可以是如整数、指针或引用
比如下面的`int N`
```cpp
template <typename T, int N>
class FixedArray {
public:
    T data[N];
};
```

固定大小的数组类(实现类似动态数组)
```cpp
#include <iostream>

template <typename T, std::size_t N>
class FixedArray {
public:
    T data[N];

    //因为我们自己写了一个数组类
    //为了让这个数组类可以通过arr[0]这样取值,要重载[]运算符

    //注意这里要用T&,否则返回的data[index]只是个副本,外部是没法实现修改的(可以试试看)
    T& operator[](std::size_t index) {
        return data[index];
    }

    void print() const {
        for(std::size_t i = 0; i < N; ++i)
            std::cout << data[i] << " ";
        std::cout << std::endl;
    }
};

int main() {
    FixedArray<int, 5> arr;
    for(int i = 0; i < 5; ++i)
        arr[i] = i * 10;
    
    arr.print(); // 输出：0 10 20 30 40 
    return 0;
}
```
注意:
    非类型参数 允许的类型包括整型、枚举、指针、引用等，但不包括浮点数和类类型

# 模板模板参数
(较难理解,看看就好)

允许模板接受另一个模板作为参数
```cpp
template <template <typename, typename> class Container>
class MyClass { /* ... */ };
```

比如下面的代码
实现一个**容器适配器**
```cpp
#include <iostream>
#include <vector>
#include <list>

template <template <typename, typename> class Container, typename T>
class ContainerPrinter {
public:
    //这里就先知道一下语法,allocator先不管是啥
    //这里有&引用,为了传参高效一点
    //这里写的一长串,就是规定传进来的container,作为模版,这个Container模版应该长啥样
    //Container<T, std::allocator<T>>就是定义模版应该长啥样
    void print(const Container<T, std::allocator<T>>& container) {
        for(const auto& elem : container)  //只是打印,所以不会修改
            std::cout << elem << " ";
        std::cout << std::endl;
    }
};

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::list<int> lst = {10, 20, 30};

    ContainerPrinter<std::vector, int> vecPrinter;
    vecPrinter.print(vec); // 输出：1 2 3 4 5 

    ContainerPrinter<std::list, int> listPrinter;
    listPrinter.print(lst); // 输出：10 20 30 

    return 0;
}
```

`template <template <typename, typename> class Container, typename T>`
    可以理解为`template <typename, typename> class Container`这是一个整体,后面的`typename T`就类型参数
    `template <typename, typename> class Container` 就当做模版类
    类模版不是一般这样写的,所以上面那句就是下面两句的简化
    `template <typename U, typename T>'
    `class Container`{...}
    然后上面不写`<typename U, typename T>` 因为U和T用不到

# 折叠表达式的概念与背景

**折叠表达式**可分为：
- **一元折叠表达式（Unary Fold）**：对参数包中的每个参数应用一个一元操作符。
- **二元折叠表达式（Binary Fold）**：对参数包中的每个参数应用一个二元操作符。

**二元折叠表达式**可进一步细分为**左折叠（Left Fold）** 和 **右折叠（Right Fold）** 取决于操作符的结合方向

___
#  一元折叠表达式

用于在参数包的每个参数前或后应用一元操作符

**前置一元折叠**
```cpp
(op ... pack)   //就是op是个操作符, 对pack进行展开,依次执行op的操作
```
编译器首先看到op,知道执行什么操作
然后...知道是对后面的参数展开,执行op操作

**后置一元折叠**
```cpp
(pack ... op)
```
<mark style="background: #FFF3A3A6;">好像前置还是后置都是可以的,没有规定哪个操作符要前置,哪个要后置</mark>
<mark style="background: #FFF3A3A6;">记得外面加()</mark>
(但是上面这个语法实际也不会用到可能,这个...的位置很难判断放在哪里)

(注意C++17才能用折叠表达式)

逻辑非操作
```cpp
#include <iostream>

//对每个参数非操作，然后再将这些操作&&
//(!args && ...) 相当于 !a && !b && ...
template<typename... Args>
bool allNot(const Args&... args){
    return (!args && ...);
}
```
(&&是二元操作符)
`(!args && ...)` 意思是 先把args取反 然后&&与上其他取反的参数
就是!a && !b && .........

# 二元折叠表达式

在参数包的每个参数之间应用一个二元操作符

**二元左折叠**
```cpp
(init op ... op pack)
```
```cpp
(pack1 op ... op packN)  //简化
```

**二元右折叠**
```cpp
(pack1 op ... op init op ...)
```
```cpp
(pack1 op ... op packN)  //简化
```
(上面的语法不用理解)


**左折叠与右折叠的区别**
- **二元左折叠（Binary Left Fold）**：操作符从左至右结合，等价于 `(((a op b) op c) op d)`。
- **二元右折叠（Binary Right Fold）**：操作符从右至左结合，等价于 `(a op (b op (c op d)))`。

求和(上一节的例子)
```cpp
#include <iostream>

// 二元左折叠：((arg1 + arg2) + arg3) + ... + argN
template<typename... Args>
auto sumLeftFold(const Args&... args) -> decltype((args + ...))  {  //尾置类型推导
    return (args + ...); // 左折叠
}

int main() {
    std::cout << sumLeftFold(1, 2, 3, 4) << std::endl; // 输出：10
    return 0;
}
```
因为是从左到右算,所以是左折叠

乘积
```cpp
#include <iostream>

// 二元右折叠：arg1 * (arg2 * (arg3 * ... * argN))
template<typename... Args>
auto productRightFold(const Args&... args) -> decltype((... * args)){ //尾置类型推导
    return (... * args); // 右折叠
}

int main() {
    std::cout << productRightFold(2, 3, 4) << std::endl; // 输出：24
    return 0;
}
```
因为是从右到左算,所以是右折叠

用左折叠也可以
```cpp
template<typename... Args>
auto productRightFold(const Args&... args) -> decltype((args * ...)){ //尾置类型推导
	return (args * ...); // 左折叠
}
```

逻辑与
```cpp
#include <iostream>

template<typename... Args>
bool allTrue(const Args&... args) -> decltype((args && ...)){ //尾置类型推导
    return (args && ...); // 左折叠
}

int main() {
    std::cout << std::boolalpha;
    std::cout << allTrue(true, true, false) << std::endl; // 输出：false
    std::cout << allTrue(true, true, true) << std::endl;  // 输出：true
    return 0;
}
```

左移操作
```cpp
#include <iostream>

template<typename... Args>
void printAll(const Args&... args) {
    (std::cout << ... << args) << std::endl; // 使用 '<<' 进行左折叠
    //(std::cout << args << ...)  不能这样写,这里是固定只能左折叠
    //但是大佬说这是左折叠
    //(std::cout << (... << args)) 这是右折叠
    //并且右折叠,会被编译器理解为位移操作
    //所以只能记住  (std::cout << ... << args)这样写
}

int main() {
    printAll("Hello, ", "world", "!", 123); // 输出：Hello, world!123
    return 0;
}
```

使用自定义操作符
假设有一个自定义类型Point，并重载了+操作符以支持点的相加
```cpp
#include <iostream>

struct Point {
    int x, y;

    // 重载 '+' 操作符
    Point operator+(const Point& other) const {
        //为了不修改原实例,或修改传进来的实例
        //返回一个新创建的Point类实例
        return Point{ x + other.x, y + other.y };  
    }
};

// 二元左折叠：((p1 + p2) + p3) + ... + pN
template<typename... Args>
auto sumPoints(const Args&... args) -> decltype((args + ...)){
    return (args + ...); // 使用 '+' 进行左折叠
}

int main() {
    Point p1{1, 2}, p2{3, 4}, p3{5, 6};
    Point result = sumPoints(p1, p2, p3);
    std::cout << "Sum of Points: (" << result.x << ", " << result.y << ")\n"; // 输出：(9, 12)
    return 0;
}
```

# 左折叠与右折叠(什么时候用什么)

大多数时候用左折叠
一般不用区分
有时候字符串拼接,需要区分从左边或者右边开始拼接

在某些复杂场景下，可能需要嵌套使用左折叠和右折叠
```cpp
#include <iostream>

template<typename... Args>
auto complexFold(const Args&... args) {
    // 先左折叠求和，然后右折叠求乘积
    return (args + ...) * (... + args);
}

int main() {
    std::cout << complexFold(1, 2, 3) << std::endl; // (1+2+3) * (1+2+3) = 6 * 6 
    return 0;
}
```

# 示例代码与应用

字符串拼接
```cpp
#include <iostream>
#include <string>

template<typename... Args>
std::string concatenate(const Args&... args) {
    return (std::string{} + ... + args); // 左折叠

    //所以说args在右边的不一定就是右折叠(像上面那个输出的例子也是)
    //就记住怎么用对就好了,左还是右折叠不用记
}

int main() {
    std::string result = concatenate("Hello, ", "world", "!", " Have a nice day.");
    std::cout << result << std::endl; // 输出：Hello, world! Have a nice day.
    return 0;
}
```

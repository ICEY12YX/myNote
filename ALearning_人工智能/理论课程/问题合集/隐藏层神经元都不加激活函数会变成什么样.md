___
如果隐藏层不加激活函数（即使用线性激活），无论堆叠多少层神经元，**整个网络在数学上都会“坍缩（Collapse）”为一个完全等价的普通单层模型**，多层网络将彻底丧失学习任何复杂非线性关系的能力。

通过两层网络的数学推导可以直观看到这一现象：

---

### 1. 数学推导：为什么没有激活函数的多层网络会“坍缩”？

假设有一个包含两个隐藏层和一个输出层的神经网络。如果所有隐藏层**都不加任何激活函数**，神经元只执行线性的加权求和：

* **第 1 层输出**：

$$z^{[1]} = W^{[1]} x + b^{[1]}$$


* **第 2 层输出**（直接将第 1 层的计算结果作为输入）：

$$z^{[2]} = W^{[2]} z^{[1]} + b^{[2]}$$



把第 1 层的公式直接代入展开：

$$z^{[2]} = W^{[2]} \left( W^{[1]} x + b^{[1]} \right) + b^{[2]} = \left( W^{[2]} W^{[1]} \right) x + \left( W^{[2]} b^{[1]} + b^{[2]} \right)$$



因为两个矩阵相乘依然是一个矩阵（令 $W' = W^{[2]} W^{[1]}$），两个偏置组合依然是一个常数向量（令 $b' = W^{[2]} b^{[1]} + b^{[2]}$），于是：


$$z^{[2]} = W' x + b'$$

**如果在最后一个输出神经元套上激活函数（如用于二分类的 Sigmoid $\sigma$）**：


$$\hat{y} = \sigma(z^{[2]}) = \sigma(W' x + b')$$

这个最终表达式与最原始的单层逻辑回归（Logistic Regression）完全一致。
中间堆叠的几十上百个神经元，耗费了大量的参数与算力，但最终等价于直接用一组新的权重矩阵做了一次线性变换，**没有带来任何新的表达能力**。

---

### 2. 激活函数的本质作用：引入“非线性（Non-linearity）”

现实世界中的数据分布（图像分类、自然语言、非线性决策边界）绝大部分都是弯曲复杂的：

* **线性运算只能划出平直的超平面**：纯线性模型只能画直线、平面对数据进行切分，无论堆叠多少层，都无法解决像“异或问题（XOR）”这样的简单非线性关系。
* **激活函数负责“扭曲与折叠”特征空间**：
在每一层加权求和后套上一个非线性激活函数（例如 ReLU $g(z) = \max(0, z)$），相当于赋予了每一层折叠、弯曲坐标轴的能力。
* **深层特征的层级抽象**：
有了非线性激活，浅层神经元可以提取基础边缘/线条，中层神经元可以基于浅层特征组合出局部纹理/部件，深层神经元则能识别完整的高级概念（如人脸、车辆）。这正是万能近似定理（Universal Approximation Theorem）成立的前提。

---

### 3. 各层的职责分工

* **隐藏层神经元（每层都套非线性激活函数，如 ReLU）**：
负责逐层对特征进行非线性映射与空间变换，将原本不可分、极其复杂的特征空间变换为易于区分的表征。
* **输出层神经元（按具体任务套激活函数）**：
仅负责将最后一层提取好的特征映射为符合任务规范的目标格式：
* **回归问题**：通常不加激活函数（输出纯线性实数 $z$）。
* **二分类问题**：套 Sigmoid 函数，将数值压缩到 $[0, 1]$ 之间输出概率。
* **多分类问题**：套 Softmax 函数，输出归一化的多类别概率分布。

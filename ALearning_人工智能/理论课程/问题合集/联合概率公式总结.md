很多初阶的人工智能数学课（尤其是面向编程和应用方向）之所以跳过连续型的微积分推导，是因为实际编写机器学习代码时，计算机底层很少去算纯符号的二重不定积分。但**理解连续型的公式体系，对看懂机器学习论文、生成模型（VAE/扩散模型）以及高斯过程至关重要**。

理解连续型公式最快、最扎实的方法，是掌握一套“离散到连续的翻译规则”：

1. **概率值 $P$** $\longrightarrow$ **概率密度 $f(x, y)$**
2. **离散求和 $\sum$** $\longrightarrow$ **连续定积分 $\int$**
3. **公式骨架完全一致**：你在离散型里怎么算，连续型把符号一对一替换即可。

### 一、 核心公式全景对比表

| 统计量 / 概念            | 离散型（Discrete）公式                                                      | 连续型（Continuous）公式                                                                                                                 | 数学意义（做什么用的）                          |
| ------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| **1. 基础函数**         | 概率质量函数：$P(X=x, Y=y)$                                                 | 概率密度函数：$f(x, y)$                                                                                                                  | 描述两变量在各点同时出现的概率或概率密度                 |
| **2. 全概率归一化**       | $\sum_{x} \sum_{y} P(X=x, Y=y) = 1$                                  | $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$                                                       | 所有可能结果的总概率和必须为 1（三维立体总体积为 1）         |
| **3. 区域概率**         | $P((X,Y) \in A) = \sum_{(x,y) \in A} P(X=x, Y=y)$                    | $P((X,Y) \in A) = \iint_A f(x, y) \, dx \, dy$                                                                                    | 计算落在特定二维范围 $A$ 内的总概率                 |
| **4. 边际分布 (求 $X$)** | $P_X(x) = \sum_{y} P(X=x, Y=y)$                                      | $f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$                                                                                 | **消去 $Y$**：沿 $y$ 方向全累加，只保留 $X$ 的一维分布 |
| **5. 边际分布 (求 $Y$)** | $P_Y(y) = \sum_{x} P(X=x, Y=y)$                                      | $f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$                                                                                 | **消去 $X$**：沿 $x$ 方向全累加，只保留 $Y$ 的一维分布 |
| **6. 条件分布**         | $P(Y=y \mid X=x) = \frac{P(X=x, Y=y)}{P_X(x)}$                       | $f_{Y \mid X}(y \mid x) = \frac{f(x, y)}{f_X(x)}$                                                                                 | **切一刀**：在 $X=x$ 的切面上归一化得到 $Y$ 的一维分布  |
| 💛**7. 独立性判定**      | $P(X=x, Y=y) = P_X(x) \cdot P_Y(y)$                                  | $f(x, y) = f_X(x) \cdot f_Y(y)$                                                                                                   | 联合分布能否直接拆成两个边际分布的乘积                  |
| **8. 单变量期望 $E[X]$** | $\sum_x \sum_y x \cdot P(X=x, Y=y)$   或 $\sum_x x \cdot P_X(x)$ <br> | $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} x \cdot f(x, y) \, dx \, dy$ 或 $\int_{-\infty}^{+\infty} x \cdot f_X(x) \, dx$ | 计算变量 $X$ 的全局加权平均重心                   |
|                     |                                                                      |                                                                                                                                   |                                      |

### 二、 连续型特有的 3 个数学关键点（课件略过的底层逻辑）

#### 1. 连续型单点的概率永远是 0

* **数学事实**：在连续型中，$P(X = 1.0, Y = 2.0) = 0$。
* **原因**：几何上，单点的面积是 $dx \times dy \to 0$。连续型只有在**一个微小区间或区域**内才有非零的概率（即积分面积/体积）。
* **因此**：$f(x, y)$ 的值是**概率密度（Density）**，代表单位面积上的概率聚集强度，它的数值**完全可以大于 1**，只要全空间总积分等于 1 即可。

#### 2. 条件概率 $f(y \mid x)$ 的分母是“降维积分”

离散型的分母直接把这一行（或这一列）的所有可能相加：


$$P_X(x) = \sum_y P(X=x, Y=y)$$


连续型的分母就是边际积分：


$$f_{Y \mid X}(y \mid x) = \frac{f(x, y)}{\int_{-\infty}^{+\infty} f(x, y) \, dy}$$


只要把变量 $y$ 从负无穷积到正无穷，分母就只剩下了关于 $x$ 的表达式。

#### 💛3. 独立变量的乘积性质（连乘性质）

如果两个连续变量 $X$ 和 $Y$ 相互独立，那么不仅它们的联合密度可拆解 $f(x, y) = f_X(x)f_Y(y)$，二重积分也会直接拆成两个一重积分的简单相乘：


$$E[XY] = \int_{-\infty}^{\infty} x f_X(x) \, dx \cdot \int_{-\infty}^{\infty} y f_Y(y) \, dy = E[X] \cdot E[Y]$$


💛💛💛这直接导出了：**两变量若独立，则 $Cov(X, Y) = E[XY] - E[X]E[Y] = 0$**。

### 三、 为什么 AI 课件常省略积分？在算法中怎么用？

很多同学以为学了这些公式必须要动手手算微积分，但在机器学习中，工业界避开手动积分的方式通常有三种：

1. **假设为多元高斯分布（Multivariate Normal Distribution）**：
高斯分布具有极其优美的数学性质，它的边际分布、条件分布**依然是高斯分布**，其期望和协方差矩阵可以直接通过矩阵代数（切片、求逆）解析得到，根本无需算积分。
2. **蒙特卡洛采样（Monte Carlo Integration）**：
当连续积分 $\int g(x)f(x)dx$ 算不出来时，计算机直接从分布 $f(x)$ 中随机生成 $N$ 个数据样本 $x_1, x_2, \dots, x_N$，然后**用样本算术平均值代替连续积分**：

$$\int g(x)f(x) \, dx \approx \frac{1}{N}\sum_{i=1}^{N} g(x_i)$$

这就是把连续微积分又“暴力”转回了简单的离散求和。💛

3. **混合贝叶斯（分类任务中的连续特征）**：
在模式识别中，特征 $X$ 是连续的（比如像素、身高等），标签 $Y$ 是离散的（比如垃圾邮件/正常邮件，或者猫/狗）。此时公式结合为：

$$P(Y = c \mid X = x) = \frac{f(x \mid Y = c) \cdot P(Y = c)}{\sum_{k} f(x \mid Y = k) \cdot P(Y = k)}$$

这就是著名的**高斯朴素贝叶斯（Gaussian Naive Bayes）分类器**的数学原形。

# 2-导数悖论

导数的理解矛盾
很多人通常会说导数测量的是瞬时变化率
这个说法其实自带矛盾
    在不同时间点之间, **变化**才能发生。
    而当你自己限制在一个瞬时点(就是确切的某一时间点)的时候，也就没有变化的余地了(就是变化本身都没了)

想象一辆车从A点出发，先加速再减速，在100米处的B点停下来，整个过程花费了10秒。
![[Pasted image 20260910035531.png]]

画图
我们一般把这样描述距离的函数称作S(t)关于t的S (distance)的函数
![[Pasted image 20260910035650.png]]

考虑每移动1秒, 比前1秒多走了多少距离(这个差,加速的时候在变大)
一开始这个曲线很平缓，因为车发动时速度很慢，第一秒之内车没怎么移动多远。而在接下来的几秒钟，车开始加速，每一秒移动距离都比前一秒长，这对应着图像中越来越**陡**的曲线，而车最后面慢下来的时候，图像曲线又变得**平缓**了
![[Pasted image 20260910035831.png]]

![[Pasted image 20260910040100.png]]

改变了距离时间的函数，也会同时改变速度时间的函数。
我们正是要学习理解这种关系,速度的大小到底如何随着距离时间函数的变化而变化呢？
![[Pasted image 20260910040116.png]]

速度究竟代表着什么？
直觉也告诉我们，当速度越大时，在距离函数上的样子就应当更陡峭。
    因为此时车在单位时间内移动的距离更长,(差更大)

讲一个瞬时的速度其实没有一点点意义
你需要拿出两个时间点来做比较
这才是速度的本体，即单位时间内运动的距离。
![[Pasted image 20260910040537.png]]

回头看之前的速度函数，它只需要单独一个t值,对上去就得到这个时间点的速度,这不合理啊
虽然理想是我们想要给每一个单独的时间点关联上一个速度值，==但计算速度却需要比较两个时间点上的距离。==

所以就是引入dt了
时间差叫做dt，可以想成之前说的0.01秒，再把这段时间差内运动的距离差叫做ds
![[Pasted image 20260910040912.png]]
![[Pasted image 20260910041043.png]]

同理下面
DS除以DT就可以当成是(函数图像上很接近的两点)，随前进上升所连成直线的斜率。
DS除以DT就可以当做t时间点的速度值, 以此画成v(t)图像
![[Pasted image 20260910041201.png]]
![[Pasted image 20260910041400.png]]

我用电脑绘制这个速度函数的山包图的时候，我是这么下指令的。首先我把DT选为一个很小的值，这里就取0.01。接着我让电脑在0和10之间取许多许多段dt，计算s函数在T加DT时的值减去s函数在T时的值。也就是计算时间T和再过0.01秒之后的距离差。然后把这个距离差除以时间的变化量DT我们最后就得到了在每个T点时的速度。
![[Pasted image 20260910041736.png]]


![[Pasted image 20260910042158.png]]
就是dt不取具体值
而是让dt的值无限趋近于0

![[Pasted image 20260910042416.png]]
![[Pasted image 20260910042429.png]]
![[Pasted image 20260910042508.png]]
所以说导数在数学上真正的完全体, 并不是沿图像**两点间**直线的斜率，而是经过图像上**某一点**的切线的斜率。

注意 dt永远都是一个有限小的量，非零只是非常接近于零
不是0,不是无穷小
![[Pasted image 20260910042634.png]]

最好别把求切线看作是求什么某一点瞬时的变化率，而是要把它看作是求**某一点附近**变化率

顺便关于符号这里我觉得有必要提两句
我们一直在用DT表示T的微小变化量，DT是有实际大小的。一直在用DS表示所对应的S的微小变化量，DS也是有实际大小的。
按照微积分的传统，只要你用了符号D就等于你挑明了你想求当时dt逼近于0时的结果。

我们求的导数本质上并不是一个分数，而是求当T的变化量越来越小时，这个分数的比值的**极限**。

导数根本就不是来测量瞬时变化

这个奇怪的过程叫做隐函数求导隐微分

现在我们用一把5米长的梯子斜靠在墙上，梯子的顶端离地4米。由勾股定理可得，此时梯子的底端距离墙角3米。
现在梯子的顶端开始以1米每秒的速度下滑。请问在这一开始的瞬间，梯子底端离开墙角的速度是多少？
这个问题很有意思吧，梯子底端离墙角的距离百分之百是由梯子顶端的离地高度所决定的。
![[Pasted image 20260910080033.png]]
梯子顶端离地的距离我们就标记为函数Y(t)毕竟梯子在运动，这个距离由时间决定。
同理底部离墙的距离我们就标记为函数x(t)个函数
![[Pasted image 20260910080237.png]]
这个等式之所以关键，就在于它时时刻刻都成立。

那上面圆的问题怎么办
没办法用t,因为没有实际含义
导数里的微小变化量DX和DY看上去像悬空的, 并不靠一个共同的时间变量来联系。
![[Pasted image 20260910081807.png]]

我们给表达式X平方加Y平方取个名字，就叫S。S实际上就是取两个变量的函数
![[Pasted image 20260910082013.png]]
![[Pasted image 20260910082107.png]]
它实际上表示你从XY点开始，走了DXDY这一小段距离之后，X平方加Y平方的值相应变化了多少。

而在这个圆上,每走一步, X平方加Y平方的值,就是s,是不变的
我们==要保证每一步都踩在圆上==。条件就是要让表达式2X乘DX加2Y乘DY(就是s的导数)一直等于0。
就是说,对于圆上的点,这个式子天生成立
![[Pasted image 20260910082349.png]]

当然这还是个近似。严格意义上讲这个条件实际上是保证每一步都落在过圆的一条切线上，而不是原本身它迈的步子足够小的话，也就没区别了。当然我们选择分析X平方加Y平方等于5，没啥特别的理由。

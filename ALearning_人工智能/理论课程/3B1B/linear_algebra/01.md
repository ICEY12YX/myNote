# 2-线性组合,张成的空间与基

向量坐标另一种看待方式
就是把这些数字就看成数乘的标量
这些数字 伸缩形成了当前这个向量

单位向量/基向量
![[Pasted image 20260908033156.png]]
这俩, 加上向量坐标的标量,  形成当前这个向量
![[Pasted image 20260908033217.png]]

所以,基向量也可以变
![[Pasted image 20260908033631.png]]
基变了,可能当前向量的坐标/表达方式就不一样了

![[Pasted image 20260908033728.png]]
![[Pasted image 20260908033741.png]]

向量的任意线性组合, 组合成的所有向量,所在的空间,叫张成的空间
下图, 不共线的2个二维向量, 可以张成整个二维空间
共线的2个二维向量,就只能张成一条线了(这条线就是共线的那条线)
2个零向量只能待在原点
![[Pasted image 20260908034041.png]]问张成的空间 其实就在问
![[Pasted image 20260908034440.png]]
![[Pasted image 20260908034448.png]]
![[Pasted image 20260908040049.png]]
![[Pasted image 20260908040107.png]]

因为画很多向量在图上太拥挤(线太多)
所以偷懒点,就把向量画成点
所以可把向量看成点(向量的终点)

三维
两个向量时张成一个平面
缩放第三个向量时，它将前两个向量张成的平面沿它的方向来回异动，从而扫过整个空间。
    另一种思考方式是：利用自由变化的三个标量，从而得到空间中所有的三维向量。
![[Pasted image 20260908040324.png]]
如果第三个向量正好在前两个向量张成的平面,那张成空间还是二维的

一组向量中如果有至少一个是多余的（没有对张成空间做出任何贡献，如二维的共线、三维的共面等），也就是移除那个向量而不减小张成的空间，此时它们是 “**线性相关**” 的。
    另一种表述是，==其中一个向量可以表示为其他向量的线性组合==，因为这个向量已经落在其他向量张成的空间之中。
如果所有向量都给张成的空间增加了新的维度，它们就被称为 “**线性无关**” 的。

# 3-矩阵与线性变换

线性变换中的变换
变换=函数
接受输入并为输出
在这里就是,接受一些向量并吐出另一个向量
变换暗示要用 “运动” 思考。

符合以下性质,才称之为线性的变换 
- 直线在变换后仍然保持为直线
- 原点必须保持固定

如果两个向量列相关，那么这个变换将整个二维空间挤压到它们所在的一条直线上，也就是这两个线性相关向量所张成的一维空间。

    就是A反着变换, 变回去

行列式为零时，A 将空间压缩到更低的维度，
    此时没有逆变换
    因为不能将一条线 “解压缩” 为一个平面,
    因为变过去的时候,不同的向量可能变成同一个向量了
    而变回去的时候,同一个向量变成不同的向量,是不允许的
    因为
    ![[Pasted image 20260908054210.png]]

 即使不存在逆变换，解依然可能存在。比如该变换将空间压缩为一条直线，向量 v 正好处于这条直线上(而不是直接压缩成一个点了)。

秩(Rank)：代表**变换后**空间的维数。

列空间：无论是直线、平面还是空间，所有可能的变换结果的集合被称为矩阵的 “列空间”。
    就是变换后张成的空间,那里面所有的向量
    矩阵的列告诉我们基向量变换后的位置，这些变换后的基向量张成的空间就是所有可能的变换结果。
    A的列空间维数 = 秩
    (注意列空间是指向量的集合, 秩是维数)
![[Pasted image 20260908054503.png]]
(这个不用怎么管)

零向量一定会被包含在列空间中，因为线性变换必须保持原点位置不变。

对于一个满秩变换来说，唯一能在变换后落在原点的就是零向量自身
    满秩就是变化后,张成空间没变

对于一个非满秩的矩阵来说，它将空间压缩到一个更低的维度上，也就是说会有一系列列向量在变换后成为零向量。

零空间：变换后落在原点的向量的集合，被称为矩阵的 “零空间” 或 “核”。
    就是那些被变换,压到零点的可怜向量们,的原来张成的空间

一个三维线性变换将空间压缩到一个平面上，就有一条线上的向量在变换后落在原点
一个三维线性变换将空间压缩到一条直线上，就有一整个平面上的向量在变换后落在原点

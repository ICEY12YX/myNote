## gradients and maxima/minima

#slope 可以找一维函数的最大最小值
那 #gradients 当然也可以找 多维函数的最大最小值

也一样的看 "斜率"为0 水平线/面
![[Pasted image 20261010041012.png]]
面水平, 两条 切线斜率当然也水平
![[Pasted image 20261010041004.png]]

the minimum of the function f on the right happens when **both** ​of the slopes of the tangent lines given by the partial derivatives are 0
当偏导数给出的两条切线的斜率**均为** 0 时，右侧函数 f 取得最小值。
    所以还是求 导数为0 的事情

## optimization using gradient descent in one variable

上面的函数,导数0点都很好求
那肯定有不好求的时候
![[Pasted image 20261010050821.png]]
这个0点根本没法算
![[Pasted image 20261010051228.png]]

那有什么别的方式吗
有的

探路的方式
两边看看,右边小,走右边
![[Pasted image 20261010052507.png]]
再走右边
![[Pasted image 20261010052545.png]]
直到两边走的时候,数值都大了

那这个方法, 更确切一点该怎么表达呢
怎么数学上判断 当前这点要往左还是往右呢(不算周边的函数值)
![[Pasted image 20261010052920.png|398]]
看 #slope 
因为还是要去 斜率为0的地方
斜率负的 就要去斜率大一点的地方
斜率正的 就要去斜率小一点的地方

并且定义 移动的步子 就是斜率
    斜率负时 右走 正好就是 -负数
    斜率正时 左走 正好就是 -正数
![[Pasted image 20261010053148.png]]

应该就是恰好 #slope 的符号合适
那要是 斜率数值很大怎么办
一步太大了
我们想走小小步 (比较谨慎)
那就加个 #scalar 就好了 称为 #learning_rate 学习率
    学习率怎么选择其实是门学问,  好像目前没有好办法
![[Pasted image 20261010053528.png]]
正好
斜率大时 走大步
斜率小时(快要接近导数0点) 走小步
![[Pasted image 20261010053703.png]]

这就是 梯度下降 #gradient_descent 
![[Pasted image 20261010053855.png]]
总结
![[Pasted image 20261010053921.png]]
(当最小值没怎么变的时候,就是找到最小值了)

这个算法的好处是 你永远不用真实的去求 导数为0的点

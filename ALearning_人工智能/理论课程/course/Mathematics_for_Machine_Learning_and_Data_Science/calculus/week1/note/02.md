那有没有更好的硬币呢
列式子
![[Pasted image 20261009221028.png|493]]
算导数为0
可能默认这种初等幂函数 肯定可导吧
p=0或1 排除      所以就是0.7
![[Pasted image 20261009221158.png]]

有没有更简单的做法?
有的 兄弟有的

既然要最大化这个式子 
那套个log (因为也是输入变大 输出跟着变大 就是logx 函数单调递增)
然后算式子的最大值
还是求导数0点
![[Pasted image 20261009223026.png]]
![[Pasted image 20261009223045.png]]

为什么要取负数
因为p是 0到1
此时log函数 小于0
所以Gp 其实是个负数
所以加-号 变正 (但是这并不是说加log的做法求最大值不对)

然后因为本来是求最大值 这个逻辑没问题
求Gp最大(负数大, 那去掉负号,就是小)
所以是求-Gp最小值
但是结果都一样 就是求导数为0的点

我们前面做的事情其实就是给数据 找最合适的模型(找最合适的硬币)

    最小化 #log_loss

    - 电脑来说 导数的 #product_rule 难 #sum_rule 简单
    - 然后log求导以后虽然多了分子分母的运算,但是计算机来说不是事,这个代价值得付出

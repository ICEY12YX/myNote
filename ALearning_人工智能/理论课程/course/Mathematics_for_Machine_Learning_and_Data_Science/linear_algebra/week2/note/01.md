## matrix row reduction

上面解的过程可以直接用矩阵 简化
这个过程也成为高斯消元法 #gaussian_elimination (好像只限于对进行消元)

总之就是把系数矩阵 变啊变 变成 行阶梯形 #row_echelon_form
甚至 E #reduced_row_echelon_form
**行阶梯形（Row Echelon Form）** 是指一个矩阵经过初等行变换后，满足以下条件的形态：
    所有非零行都位于零行上方，
    且每个非零行的首个非零元素（主元）所在的列，都位于上一行主元所在列的右侧。
概括就是 **“非零行在上，主元逐行右移”**
![[Pasted image 20260924172715.png]]
![[Pasted image 20260924172752.png]]

这个特殊情况, 矩阵本身就变不了了
全0 的也可以称为行阶梯形
![[Pasted image 20260924172859.png]]

总之就是要长成这样

## row operations that preserve singularity

经过上面的矩阵行运算 可以说明一件事
经过行运算的矩阵 奇异性不变(就是该无解无解 该无穷解无穷解 该唯一解唯一解)

(从计算行列式的角度 看行运算过后的矩阵 奇异性变了没)

行互换
**==行列式会变号==**(因为可以看到项目顺序变了)
奇异性不变(因为区分奇异性就是看 行列式是不是为0, 项目顺序变了算出来该0还是0)

❤️==**行列式不变**==  (考虑 因为线性变换没变, 只是表示线性变换的矩阵样子变了)

## rank of a matrix

#rank 秩

![[Pasted image 20260929201332.png]]
图像可以看成矩阵
通过奇异值分解 #singular_value_decomposition 简称 #SVD
(可以尽可能少的改变矩阵的同时  降低矩阵的秩)
用这种方法可以压缩图像,减少存储空间
![[Pasted image 20260929201621.png]]

所以矩阵的秩 可以看做 这个矩阵携带了多少(维度)信息

先看看这边的秩 携带多少信息 是怎么看的
![[Pasted image 20260929201841.png]]
![[Pasted image 20260929201850.png]]

再看代表线程方程的矩阵 的秩
s2 因为方程2可以用方程1表示出来 所以算r=2
总之 就看方程组对应的==**系数阵 的行向量**==  看总体==**多少维度**==
    或者说 看看有没有行向量之间 线性依赖 #linear_dependent 的情况
         有没有某个行向量 可以用其他向量线性表示
(0向量不能算一个维度)
![[Pasted image 20260929202120.png]]

再对应到方程组的解空间
![[Pasted image 20260929202352.png]]
所以秩还能这样算
![[Pasted image 20260929202448.png]]
(因为这里矩阵有2行, 所以式子前面写了2)
(满秩是 ==**秩等于行数**== 即携带的信息 和 方程组的数量一样多)
    可以把 矩阵的秩 理解为 这个矩阵是个线性变换
    这个线性变换 会把 某向量 拉到多少维度的空间
    **解空间** 是 多少个维度的向量 会被拉到0点(就是维度消失了)
        因为这里的"解" 是等号那边都是0

非奇异对应  ==**方阵+满秩**==  #full_rank

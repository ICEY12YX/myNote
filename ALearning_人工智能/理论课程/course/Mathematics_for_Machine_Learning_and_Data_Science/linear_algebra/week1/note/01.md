## linear dependence and independence

判断奇异与否的另外一个办法（不求解方程组）
就是判断线性相关性

singular奇异
#linear_dependent 线性相关
就是一个方程依赖于另一个
就是系数是倍数关系
倍数关系也可以理解为**缩放**

nonsingular 非奇异
#linear_independent 线性无关
几个方程系数没有倍数关系
![[Pasted image 20260924122826.png]]



对于更大的矩阵
还可能出现这种情况

两向量相加 是 第三个向量
此时也是 线性相关的 奇异的
（加上c，因为三个方程默认三维，只是第三维方程里没出现）
![[Pasted image 20260924122955.png]]

线相 的时候
两向量相加 是 第三个向量
或者
倍数关系
可能同时出现
![[Pasted image 20260924123634.png]]

或者
两向量相加, 再缩放 = 第三个向量
当然也 算线相
![[Pasted image 20260924123831.png]]


两向量先缩放(可选) ,再相加/相减, 再缩放(可选) -> 第三个向量
就是 线相
总之就是 某行 可以被矩阵里的其他行 **线性表示**  
矩阵就是 #linear_dependent  #singular 
(行也可以称作向量)

线性无关
就没有任何 缩放 或 相加相减得另外一个 
![[Pasted image 20260924123916.png]]

##  the determinant
行列式 #determinant
(也可以用来判断线相)

![[Pasted image 20260924134357.png]]
线相的矩阵 行列式是0
（联想 线相 压缩维度 面积/体积等 就变0了）

线无的矩阵 行列式非0
（联想 线无 线性变换不压缩维度 从一个向量变到唯一一个向量输出  有变换的面积/体积）

![[Pasted image 20260924134345.png]]
公式来看线相的行列式为0
他的推导过程
    线相的定义（系数成比例）
    减一减为0
    (而这个式子正好是行列式公式)
所以行列式为0 即 线相

* 使用 NumPy 线性代数 (Linear Algebra) 软件包，将线性方程组建模为矩阵。
* 计算矩阵的行列式 (Determinant)，并探讨矩阵奇异性 (Singularity) 与线性方程组解的数量之间的联系。

首先导入 NumPy 库以调用其丰富的数学运算功能。此外，还需要导入 matplotlib.pyplot 库，它将帮助我们把方程直观地绘制成图表。

```python
import numpy as np
import matplotlib.pyplot as plt
from utils import plot_lines

```

## 1 - 使用矩阵表示线性方程组

### 1.1 - System of Linear Equations 线性方程组

**线性方程组 (System of Linear Equations**，简称 **Linear System)** 是由一个或多个包含相同变量的线性方程所组成的集合。例如：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1+2x_2=1, \end{cases}\tag{1}$$

这就是一个包含两个未知变量 $x_1$ 与 $x_2$ 的二元一次方程组。所谓**求解**线性方程组，本质上就是寻找一组特定的未知数数值 $x_1$ 和 $x_2$，使得方程组中的每一个等式都能同时成立。

如果一个线性方程组==没有唯一解==，它就被称为**奇异 (Singular)** 方程组；反之，若存在唯一确定的解，则称为**非奇异 (Non-Singular)** 方程组。

### 1.2 - 用矩阵表示线性方程组

在前面的课程中你已经了解到，我们可以把线性方程组抽象并写成矩阵的形式。方程组 $(1)$ 用矩阵表示如下：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

在这个矩阵中，==每一行分别代表方程组中的一个方程==。第一列对应变量 $x_1$ 的系数，第二列对应变量 $x_2$ 的系数，而第三列则代表等号右侧的常数项。

我们还可以更进一步，将方程组 $(1)$ 的系数单独提取为一个==系数矩阵 $A$==：

$$\begin{bmatrix} -1 & 3\\ 3 & 2 \end{bmatrix}$$

并将方程右侧的常数输出表示为一个列向量 (Vector) $b$：

$$\begin{bmatrix} 7 \\ 1 \end{bmatrix}$$

在 NumPy 中，我们可以像下面这样定义矩阵 $A$ 和向量 $b$：
( Ax = b       x,b是向量)
```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("Matrix A:")
print(A)
print("\nArray b:")
print(b)

```

那么，矩阵 $A$ 和向量 $b$ 的维度分别是什么呢？

你可以通过 `shape` 属性来查看 $A$ 和 $b$ 的形状维度（💛使用 `np.shape()` 函数也能达到同样的效果）。

```python
print(f"Shape of A: {A.shape}")
print(f"Shape of b: {b.shape}")

# print(f"Shape of A: {np.shape(A)}")
# print(f"Shape of A: {np.shape(b)}")

```
![[Pasted image 20260924160329.png]]

在课堂上，你曾动手用笔算解开过简单的二元一次方程组。但在计算机科学中，我们需要一套更通用、程序化的方法来解决规模更大的方程组。在本实验中，NumPy 为我们提供了一个非常便捷的求解工具。

NumPy 的线性代数模块提供了一个既快速又可靠的函数💛 `np.linalg.solve(A, b)`，专门用于求解线性方程组。
**linalg** 是 **Linear Algebra**（线性代数）的缩写。
在这里，$A$ 就是前面提到的系数矩阵，每一行对应一个方程，每一列对应对应的未知数变量；$b$ 则是包含常数项的一维数组。如果你想深入了解该函数，可以查阅其官方[说明文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)。

要计算方程组 $(1)$ 的解，我们直接调用 `np.linalg.solve(A, b)`。求解结果将保存在一维数组 $x$ 中，其内部元素分别对应未知数 $x_1$ 和 $x_2$ 的数值：
( Ax = b       x,b是向量)
```python
x = np.linalg.solve(A, b)
print(f"Solution: {x}")

```
![[Pasted image 20260924160800.png]]

输出数组中的第一个元素是 $x_1$ 的解，第二个元素是 $x_2$ 的解。你可以尝试将求得的 $x_1$ 和 $x_2$ 带回原始方程组中，验证等式是否完全吻合。

### 1.3 - 计算矩阵的行列式

对应线性方程组 $(1)$ 的系数矩阵 $A$ 是一个**方阵 (Square Matrix)** —— 它的行数与列数完全相等。==**对于方阵，我们可以计算它的行列式**== —— 这是一个特殊的实数标量，能够揭示矩阵本身的很多核心几何与代数性质。

对于一个包含相同未知数数量与方程数量的线性方程组，它拥有==唯一解的**充要条件**是：其系数矩阵 $A$ 的行列式不为零。==

在本课程中，通过手算行列式有助于我们建立直观的数学理解，但在实际工程与科学计算中，这些繁琐运算都可以轻松交给计算机完成。

现在让我们用 NumPy 的线性代数模块来计算行列式。只需直接调用 `np.linalg.det(A)` 函数即可，更多细节可参阅其官方文档。

```python
d = np.linalg.det(A)
print(f"Determinant of matrix A: {d:.2f}")

```
![[Pasted image 20260924160910.png]]

正如我们所料，计算出的行列式是一个非零数值，这完全符合该方程组具有唯一解的数学规律。

## 2 - 将 2x2 方程组可视化为平面直线

现代计算工具极大地简化了线性方程求解与行列式计算的过程。接下来，我们将像之前的交互练习一样，把包含两个变量的 2x2 方程组转化为几何坐标系中的直线进行直观呈现。

### 2.1 - 方程组的矩阵表示

在绘制方程组 $(1)$ 的图象之前，我们通常需要先将其整理为如下形式的矩阵：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

实现这一点有两种方式：既可以直接新建一个包含这些数值的新矩阵，也可以把前面已经建好的矩阵 $A$ 与向量 $b$ 进行水平拼接。需要特别注意的是，由于向量 $b$ 最初的形状是一维的 `(2,)`，直接拼接会报错，因此在调用 `np.hstack()` 进行横向堆叠时，必须先通过 `.reshape((2, 1))` 将其变形成二维列向量。下面的代码演示了这一操作：

```python
A_system = np.hstack((A, b.reshape((2, 1))))
print(A_system)

```
![[Pasted image 20260924161038.png]]

我们顺便复习一下如何==提取矩阵中的单行数据==，这在后续进行矩阵行变换操作时非常实用。由于 Python 的索引从 0 开始计数，因此要获取矩阵的第二行，我们需要使用下标 `1`：

```python
print(A_system[1])

```
![[Pasted image 20260924161113.png]]

### 2.2 - 解的几何图像表示

包含两个变量（此处为 $x_1$ 与 $x_2$）的==二元一次方程，在几何上可以用二维平面上的一条直线来表示==，这被称为**线性方程的图象 (Graph of the Linear Equation)**。
对于由两个方程组成的方程组，几何平面上就会==对应两条直线，而这两条直线的**交点**，恰恰就是该方程组的解。==

在下面的代码中，我们将调用绘图函数 `plot_lines()` 来渲染这两条直线，从而以几何直观呈现刚才计算出的解。即便目前对该绘图函数的底层实现感到陌生也不必担心，现阶段我们重点理解几何直观即可。

```python
plot_lines(A_system)

```
![[Pasted image 20260924161253.png|421]]

可以清晰地看到，这两条直线恰好相交于点 $(x_1, x_2) = (-1, 2)$，这正是方程组的唯一解。

## 3 - 无解的线性方程组

现在来看另一个线性方程组：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=1, \end{cases}\tag{2}$$

我们先来计算它对应系数矩阵的行列式。

```python
A_2 = np.array([
        [-1, 3],
        [3, -9]
    ], dtype=np.dtype(float))

b_2 = np.array([7, 1], dtype=np.dtype(float))

d_2 = np.linalg.det(A_2)
print(f"Determinant of matrix A_2: {d_2:.2f}")

```
![[Pasted image 20260924161341.png]]

行列式计算结果等于 0，这说明该方程组绝不可能存在唯一确定的解。
==**它要么拥有无穷多组解，要么完全无解。**==
究竟属于哪种情况，==取决于等号右侧的常数项是否自洽（相容性）==。运行下方单元格代码，可以看到 `np.linalg.solve()` 函数会因为矩阵奇异而直接抛出错误提示：

```python
try:
    x_2 = np.linalg.solve(A_2, b_2)
except np.linalg.LinAlgError as err:
    print(err)

```
![[Pasted image 20260924161432.png]]

我们将该方程组拼接成增广矩阵并查看：

```python
A_2_system = np.hstack((A_2, b_2.reshape((2, 1))))
print(A_2_system)

```
![[Pasted image 20260924161630.png]]

```python
plot_lines(A_2_system)

```
![[Pasted image 20260924161826.png]]

正如几何推断的那样，平面上的两条直线彼此平行，永不相交，因此方程组无解。

## 4 - 拥有无穷多解的线性方程组

如果我们对方程组 $(2)$ 等号右侧的常数项稍作改动，就可以让它重新变得自洽相容：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=-21, \end{cases}\tag{3}$$

```python
b_3 = np.array([7, -21], dtype=np.dtype(float))

```

为方程组 $(3)$ 构建新的增广矩阵：

```python
A_3_system = np.hstack((A_2, b_3.reshape((2, 1))))
print(A_3_system)

```
![[Pasted image 20260924161856.png]]

通过行变换化简，对应的等价方程组为：

$$\begin{cases}  -x_1+3x_2=7, \\ 0=0, \end{cases}\tag{4}$$

由此可知，线性方程组 $(3)$ 的全部通解可以表示为：

$$x_1=3x_2-7, \tag{5}$$

其中 $x_2$ 可以是任意实数。
所以就是**无穷解**

如果把该方程组绘制在坐标平面上，你猜能看到几条直线？不妨运行下方代码一探究竟：

```python
plot_lines(A_3_system)

```

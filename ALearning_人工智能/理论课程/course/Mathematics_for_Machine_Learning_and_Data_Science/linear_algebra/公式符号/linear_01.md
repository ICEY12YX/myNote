## 说明

关于这俩

| 符号 / 表示法                                              | 含义与说明                                                            |
| :---------------------------------------------------- | :--------------------------------------------------------------- |
| $\|v\|_1$                                             | 向量的 L1-norm                                                      |

### 2. $\Vert{}v\Vert{}_1$

- **原图表述**：向量的 L1-norm
- **推荐标准表述**：**向量 $v$ 的 1-范数（曼哈顿距离 / 绝对值之和）**
- **数学定义**：
$$\Vert{}v\Vert{}_1 = \sum_{i=1}^n \vert{}x_i\vert{} = \vert{}x_1\vert{} + \vert{}x_2\vert{} + \dots + \vert{}x_n\vert{}$$

- **通俗理解**：
    - **几何意义**：又称**曼哈顿范数**或**出租车距离**。想象在一个网格状的街道中，你只能沿着横轴和纵轴直角拐弯走，从原点走到该向量端点所需要走过的**实际总折线步数**。
    - **计算方式**：把向量中所有分量的**绝对值直接加起来**。
        - _例_：若 $v = [3, -4]^T$，则 $\Vert{}v\Vert{}_1 = \vert{}3\vert{} + \vert{}-4\vert{} = 7$。

### 3. $\Vert{}v\Vert{}_2$ ；$\vert{}v\vert{}$ ；$\Vert{}v\Vert{}$

- **原图表述**：向量的 L2-norm
- **推荐标准表述**：**向量 $v$ 的 2-范数（欧几里得范数 / 模长 / 直线长度）**
- **数学定义**：
$$\Vert{}v\Vert{}_2 = \sqrt{\sum_{i=1}^n x_i^2} = \sqrt{x_1^2 + x_2^2 + \dots + x_n^2}$$

- **通俗理解**：
    - **几何意义**：这就是初高中几何中最直观的**向量长度（模长）**，即从坐标原点拉一条直线直达该向量终点的**直线欧式距离**（基于勾股定理）。
    - **符号习惯**：在线性代数中，2-范数最为常用。当不加下标写为 $\Vert{}v\Vert{}$ 或写成绝对值形式 $\vert{}v\vert{}$ 时，**默认通常指的就是 2-范数**。
    - **计算方式**：分量平方和再开根号。
        - _例_：若 $v = [3, -4]^T$，则 $\Vert{}v\Vert{}_2 = \sqrt{3^2 + (-4)^2} = \sqrt{25} = 5$。

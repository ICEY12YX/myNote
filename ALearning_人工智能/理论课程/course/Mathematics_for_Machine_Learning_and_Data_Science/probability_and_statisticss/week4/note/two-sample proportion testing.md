在之前的视频中，你已经学习了如何检验两个总体的均值是否存在显著差异。在本节阅读材料中，我们将探讨一种类似的统计推断方法，用于比较来自两个不同总体的**比例 (Proportions)**。这种双样本比例检验 (Two-sample Test for Proportions) 在实际业务中最典型、最广泛的应用场景之一，正是 **A/B 测试 (A/B Testing)**。

### 一个实例

设想你想比较芝加哥拥有汽车的家庭比例 (记为总体比例 $p_1$ ) 与纽约拥有汽车的家庭比例 (记为总体比例 $p_2$ ) 。

针对该问题，我们可以建立如下假设：

$$H_0: p_1 = p_2 \quad \text{vs.} \quad H_1: p_1 \neq p_2$$

本次检验设定的显著性水平 (Significance Level) 为 $\alpha = 0.05$ 。

现在，你从芝加哥随机抽取了 $n_1 = 100$ 户家庭，其中有 62 户拥有汽车；同时从纽约随机抽取了 $n_2 = 120$ 户家庭，其中有 58 户拥有汽车。

若定义随机变量 $X =$ “芝加哥样本中拥有汽车的家庭数”，$Y =$ “纽约样本中拥有汽车的家庭数”，则总体比例 $p_1$ 和 $p_2$ 的良好估计量即为各自的样本比例 (Sample Proportions) ：

$$\hat{p}_1 = \frac{X}{100}, \quad \hat{p}_2 = \frac{Y}{120}$$

相应地，两地比例之差 $\Delta = p_1 - p_2$ 的自然估计量为：

$$\hat{\Delta} = \hat{p}_1 - \hat{p}_2$$

为了构建有效的**检验统计量 (Test Statistic)** ，我们需要推导出 $\hat{\Delta}$ 的抽样分布。首先，当样本量 $n_1$ 和 $n_2$ 足够大时 (本例中显然满足) ，根据**中心极限定理 (Central Limit Theorem)** ，各自的样本比例均近似服从正态分布：

$$\hat{p}_1 = \frac{X}{100} \sim N\left(p_1, \frac{p_1(1-p_1)}{100}\right), \quad \hat{p}_2 = \frac{Y}{120} \sim N\left(p_2, \frac{p_2(1-p_2)}{120}\right)$$

由独立正态分布的性质可知，两者之差同样服从正态分布：

$$\hat{\Delta} = \hat{p}_1 - \hat{p}_2 \sim N\left(p_1 - p_2, \frac{p_1(1-p_1)}{100} + \frac{p_2(1-p_2)}{120}\right)$$

==如果原假设 $H_0$ 为真，即两总体真实比例相等 ($p_1 = p_2 = p$) ==，上述分布将大幅简化为：

$$\hat{\Delta} = \hat{p}_1 - \hat{p}_2 \sim N\left(0, \frac{p(1-p)}{100} + \frac{p(1-p)}{120}\right) = N\left(0, p(1-p)\left(\frac{1}{100} + \frac{1}{120}\right)\right)$$

对其进行标准化处理，即可得到标准正态分布：

$$\frac{\frac{X}{100} - \frac{Y}{120} - 0}{\sqrt{p(1-p)\left(\frac{1}{100} + \frac{1}{120}\right)}} \sim N(0, 1)$$

但在实际分析中，即便在原假设成立的前提下，==真实的总体比例 $p$ 依然是未知的==。因此，==我们需要利用合并后的全样本数据来估计该公共比例。==在 $H_0$ 成立时，由于 $X \sim \text{Binomial}(100, p)$ 且 $Y \sim \text{Binomial}(120, p)$ ，将两组样本汇总后可获得 $p$ 的**联合估计量 (Pooled Sample Proportion)** ：

$$\hat{p} = \frac{X + Y}{100 + 120} = \frac{X + Y}{220}$$

用 $\hat{p}$ 替换未知的 $p$ ，最终得到标准化的检验统计量：

$$Z = \frac{\frac{X}{100} - \frac{Y}{120} - 0}{\sqrt{\left(\frac{X+Y}{220}\right)\left(1 - \frac{X+Y}{220}\right)\left(\frac{1}{100} + \frac{1}{120}\right)}} \sim N(0, 1)$$

进一步利用代数化简，注意到 $\left(\frac{1}{100} + \frac{1}{120}\right) = \frac{100+120}{100 \cdot 120} = \frac{220}{100 \cdot 120}$ ，与前面的分式相乘消去分子分母中的 220 ，统计量可精简写为：

$$Z = \frac{\frac{X}{100} - \frac{Y}{120}}{\sqrt{\frac{(X+Y)\left(1 - \frac{X+Y}{220}\right)}{100 \cdot 120}}} \sim N(0, 1)$$

将实际观测数据 ($x = 62, y = 58$) 代入公式中，算得的具体**观测统计量 (Observed Statistic)** 为：

$$z = 2.0271$$

因为我们进行的是双尾检验 (Two-tailed Test) ，因此 $p$ 值即为标准正态变量落在比观测值更极端的区域的概率，即 $Z > 2.0271$ 或 $Z < -2.0271$ 的概率总和：

$$\text{p-value} = P(\vert{}Z\vert{} > 2.0271) = 0.04265$$

**结论**：计算得到的 $p$ 值约为 0.0427 ，小于预设的显著性水平 0.05 ，因此我们有充分的统计学证据拒绝原假设，接受备择假设——即芝加哥与纽约两地的家庭汽车拥有率存在显著差异。

### 一般情况

当需要比较任意两个独立的总体或群组时：

* $p_1 - p_2$：两个群体之间的总体比例之差 (例如：芝加哥与纽约家庭汽车拥有率的真实差值)
* $x$：样本 1 中满足特定属性的观测数量 (例如：芝加哥样本中拥有汽车的家庭数)
* $y$：样本 2 中满足特定属性的观测数量 (例如：纽约样本中拥有汽车的家庭数)
* $n_1$：样本 1 的样本容量 (例如：芝加哥的抽样总户数)
* $n_2$：样本 2 的样本容量 (例如：纽约的抽样总户数)

理论上的检验统计量为：

$$Z = \frac{\frac{X}{n_1} - \frac{Y}{n_2} - 0}{\sqrt{\frac{(X+Y)\left(1 - \frac{X+Y}{n_1+n_2}\right)}{n_1 \cdot n_2}}} \sim N(0, 1)$$

将观测数据代入后算得的具体数值为观测统计量：

$$z = \frac{\frac{x}{n_1} - \frac{y}{n_2}}{\sqrt{\frac{(x+y)\left(1 - \frac{x+y}{n_1+n_2}\right)}{n_1 \cdot n_2}}}$$

根据假设类型的不同，$p$ 值的计算方式分别如下：

* **右尾检验 (Right-tailed Test)**：$H_0: p_1 - p_2 = 0 \quad \text{vs.} \quad H_1: p_1 - p_2 > 0$

$$\text{p-value} = P(Z > z)$$
    ![[two-sample proportion testing-1793012175877.webp]]

* **左尾检验 (Left-tailed Test)**：$H_0: p_1 - p_2 = 0 \quad \text{vs.} \quad H_1: p_1 - p_2 < 0$

$$\text{p-value} = P(Z < z)$$
    ![[two-sample proportion testing-1793012182944.webp]]

* **双尾检验 (Two-tailed Test)**：$H_0: p_1 - p_2 = 0 \quad \text{vs.} \quad H_1: p_1 - p_2 \neq 0$

$$\text{p-value} = P(\vert{}Z\vert{} > \vert{}z\vert{})$$
    ![[two-sample proportion testing-1793012188824.webp]]

### 适用条件

为确保检验推断的科学性与有效性，必须满足以下统计学前提条件：

1. **两组样本必须是相互独立的简单随机样本 (Simple Random Samples)**：样本分别从两个总体中抽取，组内独立且两组之间互不影响。
2. **每个总体的容量至少要达到对应样本容量的 20 倍**：这一条件保证了即使在无放回抽样下，样本个体之间依然可以近似视为独立的。
3. **样本中的个体属性必须是二元的**：即每个个体要么属于该特定类别，要么不属于。
4. **两组的样本量均需满足大样本近似条件 (通常要求各组的“成功”与“失败”观测数均不小于 10)**：以确保在原假设为真时，两项样本比例之差能够很好地通过高斯正态分布来进行近似。

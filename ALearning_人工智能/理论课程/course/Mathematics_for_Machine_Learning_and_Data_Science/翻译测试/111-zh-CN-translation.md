## 1 - 使用矩阵表示线性方程组

### 1.1 - 线性方程组

**线性方程组**（或**线性系统**）是包含相同变量的一个或多个线性方程的集合。例如：

$$
\begin{cases} -x_1+3x_2=7, \\ 3x_1+2x_2=1, \end{cases}\tag{1}
$$

是一个包含两个未知变量 𝑥 的二元线性方程组 1 x 1 ​ 和 𝑥 2 x 2 ​ . \*\*求解\*\*线性方程组意味着找到变量 𝑥 的值 1 x 1 ​ 和 𝑥 2 x 2 ​ 使得其所有方程同时得到满足。

如果一个线性系统没有唯一解，则称其为\*\*奇异的\*\*；否则，称其为\*\*非奇异的\*\*。

### 1.2 - 作为矩阵的线性方程组

在讲座中，你已经看到我们将线性方程组表示为矩阵。表示为矩阵的系统 $(1)$ 如下所示：

$$
\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}
$$

每一行代表系统中的一个方程。第一列代表 𝑥 的系数 1 x 1 ​ 在系统中，第二列代表 $x$ 的系数。 2 x 2 ​ ，第三列表示方程等号右侧的常数值。

我们可以进一步选择将系统 $(1)$ 的系数表示为它自己的矩阵 $A$ ，如下所示：

$$
\begin{bmatrix} -1 & 3\\ 3 & 2 \end{bmatrix}
$$

并将系统的输出表示为向量 $b$ ，如下所示：

$$
\begin{bmatrix} 7 \\ 1 \end{bmatrix}
$$

我们在下方展示了 `NumPy` 中的矩阵 AAA 和向量 bbb ：

```python
A = np.array([
[-1, 3],
[3, 2]
], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("矩阵 A:")
print(A)
print("\n 数组 b:")
print(b)
```

矩阵 $A$ 和向量 $b$ 的维度是多少？

你可以使用 `shape` 属性来确认 AAA 和 bbb 的维度（也可以使用 `np.shape()` 作为替代方法）。

```python
print(f"A 的形状: {A.shape}")
print(f"b 的形状：{b.shape}")

# print(f"A 的形状：{np.shape(A)}")
# print(f"b 的形状：{np.shape(b)}")
```

在讲座中，你已经手动求解了一些包含两个方程的简单线性方程组。然而，你尚未将求解线性方程组的方法形式化。在本实验中，我们将使用一个便捷的函数来求解这些方程。

`NumPy` 线性代数包提供了一种快速且可靠的方法来求解线性方程组，即使用函数 `np.linalg.solve(A, b)`。其中， $A$ 是一个矩阵，正如你之前所见，矩阵的每一行代表方程组中的一个方程，每一列对应变量 𝑥 1 x 1 ​ 和 𝑥 2 x 2 ​ 。 $b$ 是一个包含自由项（右侧）系数的一维数组。有关 `np.linalg.solve()` 函数的更多信息，请参阅[文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)。

为了求出方程组 $(1)$ 的解，我们将直接使用 `np.linalg.solve(A, b)` 函数。结果将保存在一维数组 $x$ 中，其中的元素对应于 𝑥 的值。 1 x 1 ​ 和 𝑥 2 x 2 ​ :

```python
x = np.linalg.solve(A, b)

print(f"Solution: {x}")
```

此输出中的第一列即为变量 𝑥 的解 1 x 1 ​ ，第二列是变量 𝑥 的解 2 x 2 ​ 。通过代入这些 𝑥 值来确认解是否正确 1 x 1 ​ 和 𝑥 2 x 2 ​ 代入原始方程组。

### 1.3 - 计算矩阵的行列式

线性方程组 $(1)$ 对应的矩阵 $A$ 是一个方阵——即它的行数和列数相同。对于方阵，可以计算其行列式——这是一个表征矩阵某些属性的实数。包含两个（或更多）方程且未知数个数相同的线性方程组，当且仅当矩阵 AAA 的行列式不为零时，才会有唯一解。

在本课程中，手动计算行列式等属性有助于培养对计算过程的直觉，但这些计算也可以轻松地通过计算机完成。

让我们使用 `NumPy` 线性代数包来计算行列式。你可以使用 `np.linalg.det(A)` 函数来实现。有关该函数的更多信息，请参阅[官方文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.det.html)。

```python
d = np.linalg.det(A)

print(f"矩阵 A 的行列式: {d:.2f}")
```

请注意，其值不为零，这符合具有唯一解的方程组的预期。

## 2 - 将 2x2 方程组可视化为直线

您可以看到，使用现代软件包来求解线性方程组并计算矩阵行列式等有用属性是多么简单。在本节中，我们将像在未评分插件中看到的那样，将 2x2 方程组可视化为直线。

### 2.1 - 将方程组表示为矩阵

在可视化方程组 $(1)$ 之前，您需要将其表示为以下形式的矩阵：

$$
\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}
$$

为此，您可以创建一个包含这些值的新矩阵，或者水平堆叠您之前创建的 $A$ 和 $b$ 矩阵。请注意，`np.hstack()` 函数要求您在堆叠数组 $b$ 之前对其进行重塑，因为其当前形状为 $(2,)$ 。下面的代码包含了 `.reshape((2, 1))` 命令，以允许完成水平堆叠。

```python
A_system = np.hstack((A, b.reshape((2, 1))))

print(A_system)
```

让我们回顾一下如何提取矩阵的一行，这将有助于稍后对行执行所需的操作。请记住，Python 中的数组索引从零开始，因此要提取矩阵的第二行，您需要使用以下代码：

```python
print(A_system[1])
```

### 2.2 - 解的图形表示

二元线性方程（此处为 𝑥 1 x 1 ​ 和 𝑥 2 x 2 ​ ) 可以在几何上表示为平面上的一条直线。这被称为\*\*线性方程的图像\*\*。对于二元方程组，会有两条分别对应于每个方程的直线，而方程组的解就是这两条直线的交点。

在下面的代码中，你将定义一个函数 \`plot\_lines()\` 来绘制这些直线，并稍后用它来表示你之前求出的解。如果下面的代码看起来不清晰，请不必担心——在现阶段，理解它并不重要。

```python
plot_lines(A_system)
```

请注意这些直线是如何在 $(x_1,x_2) = (-1, 2)$ 处相交的，这就是该方程组的解。

## 3 - 无解的线性方程组

给定另一个线性方程组：

$$
\begin{cases} -x_1+3x_2=7, \\ 3x_1-9x_2=1, \end{cases}\tag{2}
$$

让我们求出对应矩阵的行列式。

```python
A_2 = np.array([
[-1, 3],
[3, -9]
], dtype=np.dtype(float))

b_2 = np.array([7, 1], dtype=np.dtype(float))

d_2 = np.linalg.det(A_2)

print(f"矩阵 A_2 的行列式: {d_2:.2f}")
```

其行列式为零，因此该方程组不可能有唯一解。它要么有无穷多解，要么无解。方程组的相容性取决于自由项（等式右侧的系数）。你可以运行下面单元格中的代码，验证 `np.linalg.solve()` 函数会因矩阵奇异而报错。

```python
try:
x_2 = np.linalg.solve(A_2, b_2)
except np.linalg.LinAlgError as err:
print(err)
```

构建对应于此线性方程组的矩阵：

```python
A_2_system = np.hstack((A_2, b_2.reshape((2, 1))))
print(A_2_system)
```

```python
plot_lines(A_2_system)
```

正如预期的那样，这两个方程的直线是平行的。

## 4 - 具有无穷多解的线性方程组

通过更改方程组 $(2)$ 的自由系数，可以使其变为相容方程组：

$$
\begin{cases} -x_1+3x_2=7, \\ 3x_1-9x_2=-21, \end{cases}\tag{3}
$$

```python
b_3 = np.array([7, -21], dtype=np.dtype(float))
```

准备对应于方程组 $(3)$ 的新矩阵：

```python
A_3_system = np.hstack((A_2, b_3.reshape((2, 1))))
print(A_3_system)
```

因此，根据相应的线性方程组

$$
\begin{cases} -x_1+3x_2=7, \\ 0=0, \end{cases}\tag{4}
$$

线性方程组 $(3)$ 的解为：

$$
x_1=3x_2-7, \tag{5}
$$

其中 𝑥 2 x 2 ​ 是任意实数。

如果你绘制该方程组的方程，你现在预计会在图中看到几条直线？请使用下方的代码进行验证：

```python
plot_lines(A_3_system)
```

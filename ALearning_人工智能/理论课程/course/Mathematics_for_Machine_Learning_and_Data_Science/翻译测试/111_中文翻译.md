## 1 - 使用矩阵表示线性方程组

<a name='1.1'></a>
### 1.1 - 线性方程组

**线性方程组**（或称**线性系统**）是由一个或多个包含相同变量的线性方程组成的集合。例如：


$$
\begin{cases} 
-x_1+3x_2=7, \\ 3x_1+2x_2=1, \end{cases}\tag{1}
$$

这是一个包含两个未知变量 $x_1$ 和 $x_2$ 的二元方程组。**求解**线性方程组，就是找到变量 $x_1$ 和 $x_2$ 的取值，使方程组中的所有方程同时成立。

如果线性方程组没有唯一解，则称其为**奇异（singular）**；否则称为**非奇异（non-singular）**。

<a name='1.2'></a>
### 1.2 - 将线性方程组表示为矩阵
在课程讲解中，你已经看到如何使用矩阵表示线性方程组。方程组 $(1)$ 的矩阵表示如下：

$$
\begin{bmatrix}
-1 & 3 & 7 \\
3 & 2 & 1
\end{bmatrix}
$$ 

每一行代表方程组中的一个方程。第一列表示方程组中 $x_1$ 的系数，第二列表示 $x_2$ 的系数，第三列表示等号右侧的常数项。

我们还可以将方程组 $(1)$ 中的系数单独表示为矩阵 $A$：

$$
\begin{bmatrix}
-1 & 3\\
3 & 2
\end{bmatrix}
$$

并将方程组右侧的结果表示为向量 $b$：

$$
\begin{bmatrix}
7 \\
1
\end{bmatrix}
$$

下面使用 `NumPy` 表示矩阵 $A$ 和向量 $b$：


```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("Matrix A:")
print(A)
print("\nArray b:")
print(b)
```

矩阵 $A$ 和向量 $b$ 的维度分别是多少？

你可以使用 `shape` 属性确认 $A$ 和 $b$ 的维度（也可以使用 `np.shape()` 作为替代方法）。


```python
print(f"Shape of A: {A.shape}")
print(f"Shape of b: {b.shape}")

# print(f"Shape of A: {np.shape(A)}")
# print(f"Shape of A: {np.shape(b)}")
```

在课程中，你已经手动求解过一些简单的二元线性方程组。不过，你还没有正式学习如何系统地求解线性方程组。在本实验中，我们将使用一个方便的函数来求解方程组。

`NumPy` 的线性代数模块提供了一种快速且可靠的线性方程组求解方法，即使用 `np.linalg.solve(A, b)` 函数。这里，$A$ 是前面介绍过的矩阵，其中每一行代表方程组中的一个方程，每一列对应变量 $x_1$ 和 $x_2$。$b$ 是由等号右侧常数项组成的一维数组。关于 `np.linalg.solve()` 函数的更多信息，请参阅[官方文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)。

要找到方程组 $(1)$ 的解，只需使用 `np.linalg.solve(A, b)` 函数。结果将保存在一维数组 $x$ 中，其中各元素分别对应 $x_1$ 和 $x_2$ 的值：


```python
x = np.linalg.solve(A, b)

print(f"Solution: {x}")
```

输出中的第一个元素是变量 $x_1$ 的解，第二个元素是变量 $x_2$ 的解。将得到的 $x_1$ 和 $x_2$ 代回原始方程组，以确认解是否正确。

<a name='1.3'></a>
### 1.3 - 计算矩阵的行列式

与线性方程组 $(1)$ 对应的矩阵 $A$ 是一个**方阵**，也就是说它的行数和列数相同。对于方阵，可以计算其行列式——一个能够刻画矩阵某些性质的实数。对于包含两个（或更多）方程且未知变量数量与方程数量相同的线性方程组，当且仅当矩阵 $A$ 的行列式不为零时，方程组才有唯一解。

在本课程中，通过手算行列式等性质有助于建立对计算过程的直觉；不过，这些计算也可以很容易地交给计算机完成。

下面使用 `NumPy` 的线性代数模块计算行列式。可以使用 `np.linalg.det(A)` 函数完成。更多信息请参阅[官方文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.det.html)。


```python
d = np.linalg.det(A)

print(f"Determinant of matrix A: {d:.2f}")
```

注意，该行列式的值不为零，这与方程组恰好具有一个解的预期一致。

## 2 - 将二元一次方程组可视化为直线

你可以看到，利用现代 Python 库求解线性方程以及计算矩阵行列式等有用性质是多么方便。在本节中，我们将像之前在非评分练习中看到的那样，把二元一次方程组可视化为直线。

<a name='2.1'></a>
### 2.1 - 将方程组表示为矩阵

在将方程组 $(1)$ 可视化之前，需要先将其表示成如下形式的矩阵：

$$
\begin{bmatrix}
-1 & 3 & 7 \\
3 & 2 & 1
\end{bmatrix}
$$

为此，你可以使用这些数值创建一个新矩阵，也可以将之前创建的 $A$ 和 $b$ 水平堆叠起来。注意，由于数组 $b$ 当前的形状为 $(2,)$，在进行堆叠之前，需要先对其进行变形。下面的代码使用 `.reshape((2, 1))` 将 $b$ 转换为适合水平堆叠的形状。


```python
A_system = np.hstack((A, b.reshape((2, 1))))

print(A_system)
```

下面复习如何提取矩阵中的某一行，这将在后续对矩阵行进行操作时派上用场。请记住，Python 中数组的索引从 0 开始，因此要提取矩阵的第二行，需要使用以下代码：


```python
print(A_system[1])
```

<a name='2.2'></a>
### 2.2 - 解的图形表示

含有两个变量（这里是 $x_1$ 和 $x_2$）的线性方程可以在几何上表示为平面中的一条直线，这称为**线性方程的图像**。对于由两个方程组成的方程组，每个方程对应一条直线，而方程组的解就是这两条直线的交点。

在下面的代码中，你将使用 `plot_lines()` 函数绘制直线，并在后面利用它表示之前求得的解。如果下面单元格中的代码目前还不清楚，不必担心——在这个阶段，你不需要理解其中的全部细节。


```python
plot_lines(A_system)
```

注意，两条直线相交于 $(x_1,x_2) = (-1, 2)$，这就是该方程组的解。

## 3 - 无解的线性方程组

Given another system of linear equations:

$$
\begin{cases} 
-x_1+3x_2=7, \\ 3x_1-9x_2=1, \end{cases}\tag{2}
$$

下面计算与该方程组对应的矩阵的行列式。


```python
A_2 = np.array([
        [-1, 3],
        [3, -9]
    ], dtype=np.dtype(float))

b_2 = np.array([7, 1], dtype=np.dtype(float))

d_2 = np.linalg.det(A_2)

print(f"Determinant of matrix A_2: {d_2:.2f}")
```

行列式等于零，因此该方程组不可能具有唯一解。它要么有无穷多个解，要么没有解。具体情况取决于等号右侧的常数项。你可以运行下面单元格中的代码，验证由于矩阵奇异，`np.linalg.solve()` 函数会产生错误。


```python
try:
    x_2 = np.linalg.solve(A_2, b_2)
except np.linalg.LinAlgError as err:
    print(err)
```

构造与该线性方程组对应的矩阵：


```python
A_2_system = np.hstack((A_2, b_2.reshape((2, 1))))
print(A_2_system)
```


```python
plot_lines(A_2_system)
```

正如预期的那样，这两个方程对应的直线彼此平行。

## 4 - 有无穷多个解的线性方程组

通过修改方程组 $(2)$ 等号右侧的常数项，可以使其变得相容：

$$
\begin{cases} 
-x_1+3x_2=7, \\ 3x_1-9x_2=-21, \end{cases}\tag{3}
$$


```python
b_3 = np.array([7, -21], dtype=np.dtype(float))
```

准备与方程组 $(3)$ 对应的新矩阵：


```python
A_3_system = np.hstack((A_2, b_3.reshape((2, 1))))
print(A_3_system)
```

因此，根据对应的线性方程组

$$
\begin{cases} 
-x_1+3x_2=7, \\ 0=0, \end{cases}\tag{4}
$$

线性方程组 $(3)$ 的解为：

$$
x_1=3x_2-7, \tag{5}
$$

其中 $x_2$ 可以取任意实数。

如果将该方程组中的方程绘制出来，你预计现在的图像中会看到几条直线？使用下面的代码进行验证：


```python
plot_lines(A_3_system)
```

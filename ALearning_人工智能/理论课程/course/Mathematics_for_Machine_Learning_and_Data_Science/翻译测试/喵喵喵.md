## 1 - 使用矩阵表示线性方程组



### 1.1 - 线性方程组



**线性方程组**（system of linear equations，或称**线性系统**，linear system）是包含相同变量的一个或多个线性方程的集合。例如：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1+2x_2=1, \end{cases}\tag{1}$$

这是一个包含两个未知变量 $x_1$ 和 $x_2$ 的二元方程组。**求解**（To solve）一个线性方程组意味着找到变量 $x_1$ 和 $x_2$ 的值，使得所有的方程能被同时满足。

如果没有唯一解，则该线性系统被称为**奇异的**（singular）；反之，则被称为**非奇异的**（non-singular）。

### 1.2 - 将线性方程组表示为矩阵



在课程中，你已经看到我们将线性方程组表示为矩阵。方程组 $(1)$ 表示为矩阵的形式如下：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

每一行代表方程组中的一个方程。第一列代表方程组中 $x_1$ 的系数（coefficients），第二列代表 $x_2$ 的系数，第三列代表方程等号右侧的常数值。

我们可以进一步选择将方程组 $(1)$ 的系数单独表示为一个矩阵 $A$，如下所示：

$$\begin{bmatrix} -1 & 3\\ 3 & 2 \end{bmatrix}$$

并将该方程组的输出（即常数项）表示为一个向量（vector） $b$，如下所示：

$$\begin{bmatrix} 7 \\ 1 \end{bmatrix}$$

我们在下面展示如何在 `NumPy` 中表示矩阵 $A$ 和向量 $b$：

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("Matrix A:")
print(A)
print("\nArray b:")
print(b)

```

矩阵 $A$ 和向量 $b$ 的维度（dimensions）是多少？

你可以使用 `shape` 属性来确认 $A$ 和 $b$ 的维度（你也可以使用 `np.shape()` 作为替代方法）。

```python
print(f"Shape of A: {A.shape}")
print(f"Shape of b: {b.shape}")

# print(f"Shape of A: {np.shape(A)}")
# print(f"Shape of A: {np.shape(b)}")

```

在之前的课程中，你手动求解过一些简单的二元线性方程组。然而，你还没有将求解线性方程组的方法形式化。在本实验中，我们将使用一个非常便捷的函数来求解方程。

`NumPy` 的线性代数包提供了一种快速可靠的方法，可以通过 `np.linalg.solve(A, b)` 函数来求解线性方程组。这里的 $A$ 是你之前见过的矩阵，其中每一行代表方程组中的一个方程，每一列对应变量 $x_1$ 和 $x_2$。$b$ 是一个包含自由系数（即等式右侧数值）的一维数组（1-D array）。关于 `np.linalg.solve()` 函数的更多信息，可以在[官方文档](https://www.google.com/search?q=https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)中找到。

为了求解方程组 $(1)$，我们只需使用 `np.linalg.solve(A, b)` 函数。结果将保存在一维数组 $x$ 中，其中的元素分别对应 $x_1$ 和 $x_2$ 的值：

```python
x = np.linalg.solve(A, b)

print(f"Solution: {x}")

```

该输出中的第一项是变量 $x_1$ 的解，第二项是变量 $x_2$ 的解 *（注：原文表述为第一列和第二列，但在 NumPy 1-D 数组中代表第一个和第二个元素）*。你可以通过将这些 $x_1$ 和 $x_2$ 的值代入原方程组来验证该解是否正确。

### 1.3 - 计算矩阵的行列式



对应于线性系统 $(1)$ 的矩阵 $A$ 是一个**方阵**（square matrix）——它的行数和列数相等。对于方阵，我们可以计算它的行列式（determinant）——这是一个实数，可以描述矩阵的某些性质。当且仅当矩阵 $A$ 的行列式非零时，一个包含两个（或多个）方程且未知变量数量相等的线性系统才会具有唯一解。

在本课程中，手动计算诸如行列式之类的属性，有助于培养对其计算方式的直觉，但这些计算也很容易由计算机完成。

让我们使用 `NumPy` 的线性代数包来计算行列式。你可以通过 `np.linalg.det(A)` 函数来实现。关于它的更多信息可以在[官方文档](https://www.google.com/search?q=https://numpy.org/doc/stable/reference/generated/numpy.linalg.det.html)中找到。

```python
d = np.linalg.det(A)

print(f"Determinant of matrix A: {d:.2f}")

```

请注意，它的值是非零的，这与一个具有唯一解的系统的预期相符。

## 2 - 将 2x2 方程组可视化为图线



你可以看到，使用现代的软件包来求解线性方程组以及计算诸如行列式等有用的矩阵属性是多么简单。在本节中，我们将像你在未计分插件（ungraded plugin）中看到的那样，将一个 2x2 的系统可视化为图线。

### 2.1 - 将方程组表示为矩阵



在可视化系统 $(1)$ 之前，你需要将该系统表示为如下形式的矩阵：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

为此，你可以用这些数值创建一个新矩阵，或者将之前创建的 $A$ 和 $b$ 矩阵水平堆叠（horizontally stack）起来。请注意，在使用 `np.hstack()` 函数进行堆叠之前，你需要重塑（reshape）数组 $b$ 的形状，因为其当前的形状为 $(2,)$。下方的代码包含 `.reshape((2, 1))` 命令，以便完成水平堆叠。

```python
A_system = np.hstack((A, b.reshape((2, 1))))

print(A_system)

```

让我们回顾一下如何提取矩阵的某一行，这将有助于稍后对行执行所需的操作。记住，Python 中数组的索引（indexing）是从零开始的，所以要提取矩阵的第二行，你需要使用以下代码：

```python
print(A_system[1])

```

### 2.2 - 解的图形化表示



包含两个变量（在此为 $x_1$ 和 $x_2$）的线性方程在几何上可以表示为平面内的一条直线。这被称为**线性方程的图**（graph of the linear equation）。在包含两个方程的系统中，会有两条直线分别对应每一个方程，而解（solution）就是这两条直线的交点（intersection point）。

在接下来的代码中，你将定义一个 `plot_lines()` 函数来绘制直线，并在稍后用它来展示你之前求得的解。如果以下单元格中的代码不够清晰，请不要担心——现阶段不需要去理解它。

```python
plot_lines(A_system)

```

请注意这些直线是如何相交于 $(x_1,x_2) = (-1, 2)$ 的，这正是该方程组的解。

## 3 - 无解的线性方程组



给定另一个线性方程组：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=1, \end{cases}\tag{2}$$

让我们来计算对应矩阵的行列式。

```python
A_2 = np.array([
        [-1, 3],
        [3, -9]
    ], dtype=np.dtype(float))

b_2 = np.array([7, 1], dtype=np.dtype(float))

d_2 = np.linalg.det(A_2)

print(f"Determinant of matrix A_2: {d_2:.2f}")

```

它等于零，因此该系统不可能有唯一解。它要么有无限多解，要么无解。其一致性（consistency）将取决于自由系数（即等号右侧的系数）。你可以运行下面单元格中的代码，来验证 `np.linalg.solve()` 函数会由于矩阵的奇异性而报错。

```python
try:
    x_2 = np.linalg.solve(A_2, b_2)
except np.linalg.LinAlgError as err:
    print(err)

```

构建对应于该线性系统的矩阵：

```python
A_2_system = np.hstack((A_2, b_2.reshape((2, 1))))
print(A_2_system)

```

```python
plot_lines(A_2_system)

```

正如预期的那样，这两个方程的图线是平行的。

## 4 - 有无限多解的线性方程组



通过改变方程组 $(2)$ 的自由系数，你可以使其具有一致性（即变得有解）：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=-21, \end{cases}\tag{3}$$

```python
b_3 = np.array([7, -21], dtype=np.dtype(float))

```

准备对应于系统 $(3)$ 的新矩阵：

```python
A_3_system = np.hstack((A_2, b_3.reshape((2, 1))))
print(A_3_system)

```

因此，从相应的线性系统

$$\begin{cases}  -x_1+3x_2=7, \\ 0=0, \end{cases}\tag{4}$$

可以得出线性系统 $(3)$ 的解为：

$$x_1=3x_2-7, \tag{5}$$

其中 $x_2$ 是任意实数（real number）。

如果你绘制该系统的方程，你预期现在能在图中看到多少条线？ 使用下面的代码检查一下：

```python
plot_lines(A_3_system)

```

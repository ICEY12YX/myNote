## 1 - 使用矩阵表示线性方程组



### 1.1 - 什么是线性方程组



所谓 **线性方程组 (system of linear equations)** (或者简称为 **线性系统 (linear system)** ) ，是指包含一个或多个含有相同变量的线性方程的集合。举个例子：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1+2x_2=1, \end{cases}\tag{1}$$

这就是一个包含两个方程以及两个未知变量 $x_1$ 和 $x_2$ 的系统。**求解 (To solve)** 一个线性方程组，意味着我们要找出变量 $x_1$ 和 $x_2$ 的具体数值，使得该系统里的所有方程都能同时成立。

如果一个线性系统没有唯一的解，我们就称它是 **奇异的 (singular)** ；反之，如果存在唯一解，它就是 **非奇异的 (non-singular)**。

### 1.2 - 用矩阵表示线性方程组



在之前的课程中，你已经了解到我们可以用矩阵来表示线性方程组。将上面的系统 $(1)$ 转换为矩阵形式，看起来会是这样的：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

在这里，每一行代表系统中的一个方程。第一列对应着 $x_1$ 的系数，第二列对应着 $x_2$ 的系数，而第三列则是等式右边的常数值。

我们还可以进一步将系统 $(1)$ 的系数单独提取出来，组成一个独立的矩阵 $A$：

$$\begin{bmatrix} -1 & 3\\ 3 & 2 \end{bmatrix}$$

同时，将系统的输出部分表示为一个向量 $b$：

$$\begin{bmatrix} 7 \\ 1 \end{bmatrix}$$

下面，我们来看看如何在 `NumPy` 中定义这个矩阵 $A$ 和向量 $b$：

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("Matrix A:")
print(A)
print("\nArray b:")
print(b)

```

矩阵 $A$ 和向量 $b$ 的维度分别是多少呢？

你可以使用 `shape` 属性来轻松确认 $A$ 和 $b$ 的维度 (当然，使用 `np.shape()` 也是一个不错的替代方案)。

```python
print(f"Shape of A: {A.shape}")
print(f"Shape of b: {b.shape}")

# print(f"Shape of A: {np.shape(A)}")
# print(f"Shape of A: {np.shape(b)}")

```

在课堂上，你可能已经尝试过手工求解一些简单的二元线性方程组。不过，我们还没有正式将求解方法系统化。在本次实验中，我们将借助一个非常方便的函数来代替手工计算。

`NumPy` 的线性代数工具包提供了一种快速且可靠的方法，那就是 `np.linalg.solve(A, b)` 函数。正如你之前看到的，这里的 $A$ 是一个矩阵，每一行代表系统里的一个方程，每一列对应着变量 $x_1$ 和 $x_2$；而 $b$ 则是一个包含等号右侧自由系数的一维数组。如果想了解更多关于 `np.linalg.solve()` 函数的细节，可以查阅 [官方文档](https://www.google.com/search?q=https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)。

为了找到系统 $(1)$ 的解，我们只需简单地调用 `np.linalg.solve(A, b)` 即可。计算结果会被保存在一维数组 $x$ 中，其中的元素就分别对应着 $x_1$ 和 $x_2$ 的值：

```python
x = np.linalg.solve(A, b)

print(f"Solution: {x}")

```

在输出结果中，第一列是变量 $x_1$ 的解，第二列则是变量 $x_2$ 的解。你可以尝试将求得的 $x_1$ 和 $x_2$ 的值代入原始方程组中，亲自验证一下这个解是否正确。

### 1.3 - 计算矩阵的行列式



与线性系统 $(1)$ 相对应的矩阵 $A$ 是一个 **方阵 (square matrix)** ——这意味着它的行数和列数是相等的。对于方阵来说，我们可以计算它的行列式，这是一个能够刻画矩阵诸多重要特性的实数。如果一个线性系统包含两个 (或更多) 方程，并且未知变量的数量与方程数量相等，那么当且仅当矩阵 $A$ 的行列式不为零时，该系统才会存在唯一解。

在学习阶段，手动计算行列式能够帮你建立起对运算过程的直观认知，但到了实际操作中，把这些繁杂的计算丢给计算机显然更为高效。

让我们用 `NumPy` 的线性代数包来算一算行列式吧。你可以使用 `np.linalg.det(A)` 函数来完成这项工作。想要深入了解的话，可以参考 [官方文档](https://www.google.com/search?q=https://numpy.org/doc/stable/reference/generated/numpy.linalg.det.html)。

```python
d = np.linalg.det(A)

print(f"Determinant of matrix A: {d:.2f}")

```

注意观察，它的值并不是零，这完全符合我们对这个拥有唯一解系统的预期。

## 2 - 将 2x2 方程组可视化为直线图



你已经见识到使用现代代码包来求解线性方程及计算行列式等矩阵属性是多么轻而易举了。在这一部分，我们要将一个 2x2 的方程组具象化为直观的图表，就像你在之前的插件练习里看到的那样。

### 2.1 - 将系统表示为矩阵



在对系统 $(1)$ 进行可视化之前，你需要先将整个系统整合为下面这种增广矩阵的形式：

$$\begin{bmatrix} -1 & 3 & 7 \\ 3 & 2 & 1 \end{bmatrix}$$

要做到这一点，你可以直接用这些数值创建一个新矩阵，或者将之前创建的 $A$ 矩阵和 $b$ 矩阵在水平方向上拼接起来。需要特别注意的是，`np.hstack()` 函数要求你在拼接前必须先 重塑 (reshape)  数组 $b$ 的形状，因为它目前的形状是 $(2,)$。下面的代码利用了 `.reshape((2, 1))` 指令，成功地让这两个组件实现了水平对接。

```python
A_system = np.hstack((A, b.reshape((2, 1))))

print(A_system)

```

顺便复习一下如何提取矩阵中的某一行吧，这在稍后处理矩阵行操作时会大有帮助。别忘了，Python 中的数组索引是从零开始的；所以，要提取矩阵的第二行，你需要写出如下代码：

```python
print(A_system[1])

```

### 2.2 - 解的图形化表示



一个包含两个变量 (在本例中是 $x_1$ 和 $x_2$) 的线性方程，在几何学上可以被描绘为平面上的一条直线。这就叫作 **线性方程的图像 (graph of the linear equation)**。对于包含两个方程的系统，自然会有对应于每个方程的两条直线，而这个系统的“解”，正是这两条直线的交点。

在接下来的代码里，你将定义一个名为 `plot_lines()` 的函数来绘制直线，并用它来直观地呈现你刚才算出的解。如果下面单元格里的代码看起来有点晦涩，不要紧——在这个阶段你并不需要完全看懂它的每一行细节。

```python
plot_lines(A_system)

```

仔细瞧，这两条直线恰好在 $(x_1,x_2) = (-1, 2)$ 这个坐标点相交，而这也就是该方程组的解。

## 3 - 无解的线性方程组



假设我们遇到另一个不同的线性方程组：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=1, \end{cases}\tag{2}$$

我们先来查一查对应矩阵的行列式。

```python
A_2 = np.array([
        [-1, 3],
        [3, -9]
    ], dtype=np.dtype(float))

b_2 = np.array([7, 1], dtype=np.dtype(float))

d_2 = np.linalg.det(A_2)

print(f"Determinant of matrix A_2: {d_2:.2f}")

```

行列式竟然等于零！这意味着该系统不可能存在唯一解。它要么有无数个解，要么一个解都没有。系统的相容性 (是否有解) 将完全取决于等号右侧的自由系数。你可以运行下面单元格的代码来验证一下：由于矩阵的奇异性，`np.linalg.solve()` 函数会直接抛出一个报错。

```python
try:
    x_2 = np.linalg.solve(A_2, b_2)
except np.linalg.LinAlgError as err:
    print(err)

```

像以前一样，构造出对应这个线性系统的矩阵：

```python
A_2_system = np.hstack((A_2, b_2.reshape((2, 1))))
print(A_2_system)

```

```python
plot_lines(A_2_system)

```

果然如我们所料，这两个方程对应的直线完全是平行的，它们永远不可能相交。

## 4 - 具有无穷多解的线性方程组



通过微调系统 $(2)$ 中的自由系数，我们可以让它重获相容性：

$$\begin{cases}  -x_1+3x_2=7, \\ 3x_1-9x_2=-21, \end{cases}\tag{3}$$

```python
b_3 = np.array([7, -21], dtype=np.dtype(float))

```

为这个新的系统 $(3)$ 准备好相应的矩阵：

```python
A_3_system = np.hstack((A_2, b_3.reshape((2, 1))))
print(A_3_system)

```

因此，从与之对应的等价线性系统可以看出：

$$\begin{cases}  -x_1+3x_2=7, \\ 0=0, \end{cases}\tag{4}$$

这就意味着，线性系统 $(3)$ 的解其实可以表达为：

$$x_1=3x_2-7, \tag{5}$$

在这里，$x_2$ 可以是任何实数。

如果你现在把这个方程组用图像展示出来，你觉得在图上会看到几条直线呢？用下面的代码来揭晓答案吧：

```python
plot_lines(A_3_system)

```

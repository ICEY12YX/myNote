# Advice for applying machine learning
## deciding what to try next
#machine_learning_diagnostic #diagnostic 机器学习诊断（诊断测试）
用大白话来说，当你写好了一个机器学习模型（比如预测房价），结果发现它算出来的预测误差大得离谱时，你面前会摆着七八种改进方案（比如再去苦哈哈地收集几个月数据、加减特征、加高次项、调正则化参数 $\lambda$）。如果你靠“拍脑袋”随便挑一个方向埋头苦干，很可能会白白浪费好几个月时间却毫无效果；而“诊断（diagnostic）”就是一套专门给模型做体检的测试方法：在动手大改之前先跑一下测试，搞清楚你的算法到底哪里出了毛病、哪种药才对症，从而精准决定“下一步该干什么（what to do next）”，帮你省下几个月做无用功的时间！

## motivation

#classification 分类问题 
    用大白话来说，以前的线性回归是用来“猜一个具体的数字”（比如房价是多少万），输出可以是无穷多个数字里的任意一个；而“分类”就是做选择题，输出变量 $y$ 只能从屈指可数的几个类别（classes/categories）里挑一个（比如判断邮件“是不是”垃圾邮件、肿瘤“是不是”恶性的）。

#binary_classification 二分类问题 
    最常见的一种分类问题，也就是“二选一”的分类任务：要预测的结果 $y$ 只有两个可能的类别（比如“否/是”、“假/真”，或者在写代码时最常用的数字 $0$ 和 $1$），
    其中 $0$ 通常叫负类（negative class，代表某样东西不存在），$1$ 通常叫正类（positive class，代表我们要找的那样东西存在）。

#decision_boundary 决策边界（分界线） 
    在分类模型里用来“一刀切”的分割线
    比如设定阈值为 $0.5$，在这条分界线左边的样本统统被预测为类别 $0$（如良性肿瘤），在分界线右边的样本统统被预测为类别 $1$（如恶性肿瘤）。

分类问题的例子
- **垃圾邮件识别（Spam classification）**：判断一封电子邮件是不是垃圾邮件，你要输出的答案只能是“否（no）”或者“是（yes）”。
- **在线金融交易反欺诈（Financial fraud detection）**：给定一笔在线金融交易，让算法判断这笔交易是否存在欺诈（比如信用卡是不是被盗刷了）。
- **肿瘤良恶性诊断（Tumor classification）**：判断一个肿瘤是恶性的（malignant）还是非恶性的（良性 benign）。

上面这些都属于 #binary_classification  二分类问题
    最终分成2类
    分类的结果的表达可以是no / yes   **false / true**   0/1
#negative_class 负类  #negative_example 负样本
#positive_class 正类  #positive_example  正样本

对于第一个垃圾邮件问题
    一封**不是**垃圾邮件的正常邮件会被称为**负样本**，因为对于“它是垃圾邮件吗？”这个问题，答案是 no 或 $0$；
    相反，一封**是**垃圾邮件的邮件则被称为**正样本**，因为答案是 yes、true 或 $1$。
![[01-1793557566081.webp]]
**重要澄清（正/负 $\neq$ 好/坏）**：
    这里的“负（negative）”和“正（positive）”**绝不是指“坏 vs 好”**！
    纯粹是用来表达你要寻找的某种特征或属性“不存在（absence / $0$ / false）”还是“存在（presence / $1$ / true）”
        比如是否是垃圾邮件  是1/否0
**0 和 1 的指定带有一点主观随意性（Arbitrary）**：换个工程师可能会反过来, 所以0,1具体指哪一类比较随便


为什么不能直接拿“线性回归”来做分类？

问题假设
判断肿瘤是恶性（malignant，类别 $1$ / 正类 / yes）还是良性（benign，类别 $0$ / 负类）的训练集。
    横轴（horizontal axis）画上肿瘤的大小（tumor size），
    纵轴（vertical axis）画上是答案 $y$（取值为 $0$ 或 $1$）。

- **尝试硬套线性回归 + 阈值 $0.5$**：
    - 如果你试着用学过的线性回归去拟合这些数据点，会画出一条直线 $f(x)$。
    - **遇到问题**：线性回归预测出来的可不只是 $0$ 和 $1$，而是会输出 $0$ 到 $1$ 之间的所有小数，甚至还会输出小于 $0$ 或大于 $1$ 的数字。
    
    怎么办呢
    - **设定阈值（Threshold）切一刀**：为了预测出具体的类别，你可以选一个**阈值（threshold）**，比如 **$0.5$**：
        - 如果模型输出的值 **小于 $0.5$（$< 0.5$）**，就预测 $\hat{y} = 0$（良性，非恶性）；
        - 如果模型输出的值 **大于或等于 $0.5$（$\ge 0.5$）**，就预测 $\hat{y} = 1$（恶性）。
            这是在原本模型fx基础上,再搞一条线
            可以想成这样![[01-1793558851195.webp]]
    - **看似合理的分界线**：注意看，水平阈值 $0.5$ 跟最佳拟合直线相交于一点，从这个交点画一条垂直的竖线下来——竖线**左边**的所有点最终都被预测为 $y = 0$，竖线**右边**的所有点都被预测为 $y = 1$。单看目前这组数据，线性回归表现得好像还挺合理。
        
- **致命翻车现场：往最右边多加一个大肿瘤样本**：
    - 现在假设我们延长横轴，在数据集的**极右侧新增加一个巨型恶性肿瘤的训练样本**。
        
    - **按常理来说**：新加的这个样本明明一眼就是恶性，它根本不应该改变我们对原有数据点的分类标准——刚才画的那条垂直分界线依然完全合理（比它小的肿瘤判为 $0$，比它大的判为 $1$）。

    - **线性回归的崩坏结果**：但一旦你在最右边加上这个额外样本，线性回归为了迎合这个很远的点，**最佳拟合直线会被硬生生往右下方拽偏**！
    - 此时如果你继续用 $0.5$ 作为阈值，交点画下来的那条垂直分割线 **决策边界** #decision_boundary  就会**大幅往右偏移**——导致原本好几个明显是恶性的较大肿瘤（落在新竖线左边），现在居然全被错误地预测成了 $y = 0$（良性）！
![[01-1793558204209.webp]]
所以 会用到后面学的 #logistic_regression 
    尽管它的名字里带有“回归（regression）”这个词（这是出于历史原因起的名字），但它**实际上是一个分类算法**

## logistic regression

#logistic_regression 逻辑回归 
    当今世界上最流行、使用最广泛的分类算法之一。能保证预测出来的输出值永远落在 $0$ 到 $1$ 之间。
    用一条两头平缓、中间陡峭的 **S 形曲线（S-shaped curve）** 去拟合数据，并且它算出来的数字（比如 $0.7$）直接代表“这个样本属于正类 $y=1$ 的概率有多大（即 $70\%$ 的概率是恶性肿瘤）”。
    #链接 

#sigmoid_function #logistic_function Sigmoid 函数（也叫逻辑函数）
    逻辑回归背后的核心数学“压缩器”，公式为 $g(z) = \frac{1}{1 + e^{-z}}$。不管你往里面塞多大的正数或负数 $z$，它都能像个弹簧夹一样，把输出结果稳稳地压缩在 **$0$ 到 $1$ 之间**，在图像上画出一条完美的 S 形曲线（当 $z=0$ 时，输出刚好是正中间的 $0.5$）。

    **$e$** 是一个数学常数，数值大约等于 **$2.7$**（更精确一点是 $2.718\dots$），

一些数学直觉, 这个图为什么合理
- **当 $z$ 是一个很大的正数时（比如 $z = 100$）**： 此时 $e^{-z} = e^{-100}$，这是一个极其微小的数字（几乎等于 $0$）。于是整个分式就变成了 $\frac{1}{1 + \text{极小数}}$，分母基本上无限接近 $1$，所以当 $z$ 很大时，**$g(z)$ 的值就会非常接近 $1$**。
- **当 $z$ 是一个绝对值很大的负数时（比如 $z = -100$）**： 反过来你可以自己验证，此时 $e^{-z}$ 会变成一个天文数字（giant number），于是 $g(z)$ 变成了 $\frac{1}{\text{巨大无比的数}}$，所以当 $z$ 是很大的负数时，**$g(z)$ 就会非常接近 $0$**。 
- **当 $z$ 刚好等于 $0$ 时（$z = 0$）**： 此时 $e^{-z} = e^{-0} = 1$，所以 $g(z) = \frac{1}{1 + 1} = 0.5$

- z作为 #sigmoid_function 的自变量  (就是线性回归的结果再塞入sigmoid, 把输出压到  0-1)

如何解读逻辑回归的输出？
看作是在给定某个输入特征 $\vec{x}$ 的条件下，==**模型预测类别标签 $y$ 等于 $1$ 的概率**==
    如果一位病人来检查，她的肿瘤大小是 $x$，模型根据这个 $x$ 算出来的输出是 **$0.7$**，那就意味着：**模型预测（或者说模型认为）这位病人的真实标签 $y$ 等于 $1$ 的可能性是 $70\%$**——换句话说，模型告诉我们这位病人的肿瘤有 **$70\%$ 的概率是恶性的**
    那 $y=0$ 的概率是30%  因为两个事件是互斥的

## decision boundary

从决策边界 反推 fx  ,看看fx输出实际上是什么情况

什么时候 **$g(z) \ge 0.5$**
    此时 $z \ge 0$
    所以此时 $\vec{w} \cdot \vec{x} + b \ge 0$
所以
- 只要 **$\vec{w} \cdot \vec{x} + b \ge 0$**，模型就会预测 **$\hat{y} = 1$**；
- 反过来，只要 **$\vec{w} \cdot \vec{x} + b < 0$**，模型就会预测 **$\hat{y} = 0$**。
![[01-1793560868634.webp]]

知道上面的结论, 看看分类问题实际画出来的fx线长什么样

看看不同的数据
    下面的图都有多个维度输入, y输出0,1用圆圈和叉代替了, 和上面几个例子有明显的不同

情况一
假设fx是$z = w_1 x_1 + w_2 x_2 + b$
假设参数的具体数值就是：**$w_1 = 1, \; w_2 = 1, \; b = -3$**。
算出决策边界 就是z=0的时候
    那就是$$x_1 + x_2 = 3$$
    此时画x1-x2图正好长下面那样
    想象一个三维的图  此时这条线实际是个面斜着插在那里
        为什么斜着,因为线性回归嘛,搞出来的线不一般也是斜着的

如果一个样本的特征点 $(x_1, x_2)$ 落在这条线的 **右上方（满足 $x_1 + x_2 - 3 \ge 0$）**，逻辑回归就会预测 **$\hat{y} = 1$**；
![[01-1793561627603.webp]]

情况二
此时假设 fx是$$z = w_1 x_1^2 + w_2 x_2^2 + b$$
    但是我觉得这个是通过 决策边界 反推出来比较合理
假设参数是 **$w_1 = 1, \; w_2 = 1, \; b = -1$**
算出决策边界 就是z=0的时候
    $$x_1^2 + x_2^2 = 1$$是个圆
    三维里, 想象成一个碗
当 $x_1^2 + x_2^2 \ge 1$ 时，对应的是**圆圈外面的区域**，模型在这里统统预测 **$\hat{y} = 1$**；
![[01-1793561696976.webp]]

只需要往 $z$ 里面塞入更高阶的多项式项, 就可以画出更复杂的 决策边界
![[01-1793561744304.webp]]
但如果你**不加入任何高阶多项式**（也就是只用最原始的一次方特征 $x_1, x_2, x_3, \dots$），那么逻辑回归的决策边界就**永远只能是线性的（永远是一条直线或平面）**。

线大于0,小于0 我怎么知道是线外面还是里面
    答: 代入特殊值  比如(0,0)

**重要性质：决策边界由谁决定？** 
    决策边界只取决于 **$z = \vec{w} \cdot \vec{x} + b = 0$**——这意味着**一旦参数 $\vec{w}$ 和 $b$ 确定了，决策边界的位置和形状就 100% 锁死了**！
所以我们分类问题训练模型 还是用输入数据帮我们找w,b,  目标是找到最合适的决策边界线/面

# Overfitting

## The problem of overfitting

#overfitting #high_variance 过拟合（也叫高方差） 
    用大白话来说，就是模型在学习时“用力过猛、死记硬背”：因为你塞给它的高阶多项式特征太多太复杂（比如 $x^4$），它为了讨好训练集里的每一个点，把拟合曲线或决策边界拧成了九曲十八弯的麻花，虽然在旧数据上误差为 $0$（完美穿过每一个点），但一旦遇到没见过的新数据就会预测得一塌糊涂（缺乏举一反三的泛化能力）。
    之所以又叫“高方差（high variance）”，是因为只要训练集里某一个点稍微挪动一丁点，拧出来的整条曲线就会发生天翻地覆的变化。

#underfitting #high_bias 欠拟合（也叫高偏差）
    与“过拟合”刚好相反，指的是模型太死板、特征太少（比如非要用一条笔直的直线去拟合明明变平缓的弯曲房价数据），连眼皮子底下的训练数据都没拟合好，抓不住数据里明显存在的规律。
    之所以又叫“高偏差（high bias）”，就像模型脑子里带着极强的“刻板印象/偏见（preconception）”，不管数据实际长什么样，都固执地认为房价和面积只能是直线关系。

#generalization 泛化（泛化能力）
    指机器学习模型不仅能在训练数据上表现好，还能“举一反三”，在以前从未见过的全新样本上也做出准确预测的能力。

    如果让两个机器学习工程师在稍微有一点点差异的数据集上分别拟合这个四次多项式，他们会得出截然不同、剧烈变化（highly variable）的预测结果

## addressing overfitting

#regularization 正则化 
    解决 #overfitting 的问题
    允许你**保留所有的特征**，同时鼓励算法把权重参数 $w_1, w_2, \dots, w_n$ 的数值**往小里压缩（shrink the values of the parameters）**，防止某几个高次方特征起太大作用把曲线带偏，从而画出一条既保留全部信息又平滑合理的拟合曲线

解决 #overfitting 问题的3个方法

收集更多训练数据
    当训练集数据点更多时，哪怕你依然继续拟合同一个高阶多项式（或者包含大量特征的复杂函数），只要训练样本足够多，学习算法就会学出一条不再那么扭来扭去（less wiggly）的平滑曲线，表现依然会很好。
**现实局限性**：
    比如某个地段总共就只卖出去过这么几套房子，根本没有更多的数据可以收集了。
![[01-1793629743880.webp]]

减少特征数量 / 特征选择
问题假设
    假设你手头有高达 $100$ 个不同的房屋特征用来预测房价——从面积、卧室数、楼层数、房龄，到周边社区平均收入、甚至离最近咖啡店的距离等等。
    如果你有这么多特征，但手里又没有足够的训练数据(把第一种解决办法扼杀掉)，学习算法同样会对训练集发生过拟合。
那就挑一下特征嘛, 不要全部都用, 这个就是 #feature_selection 特征选择
    你可以凭自己的直觉去挑
    或后面会学一种办法  **自动挑选最合适特征子集**。
**特征选择的致命缺点（丢弃了有用信息）**： 
    因为只用了一小部分特征，算法实际上**把你手里关于房子的其他信息直接扔掉了**！万一那 $100$ 个特征其实全都对预测房价多多少少有一点用处呢
![[01-1793630596653.webp]]

正则化 #regularization 
发现 导致线弯弯绕绕的元凶是 高幂次维度的数据, 想办法处理他们就好了
- 如果你像刚才方法二那样直接删掉某个特征（比如删掉 $x^4$），在数学上就等价于**强行把对应的参数 $w_4$ 设为 $0$**（即 $0 \cdot x^4$） 那就和 #feature_selection 一样了,所以不这样做
- 正则化 是鼓励学习算法把参数 $w_1, w_2, w_3, w_4$ 的数值缩小(尤其是一些高幂次维度的数据)
- 它允许你**保留所有的特征**，但同时**防止某些特征产生过大的影响**，从而避免过拟合。
![[01-1793630942299.webp]]
**工程惯例细节：只对 $w_j$ 正则化，不用管参数 $b$**： 
    按照惯例，我们在做正则化时，通常**只缩小权重参数 $w_j$（即 $w_1$ 到 $w_n$）的大小**，而不去强制让截距参数 $b$ 变小。
    在实际应用中，到底对不对 $b$ 做正则化几乎没有任何区别，你想对 $b$ 正则化也行，不管它也完全没问题，老师自己平时通常不对 $b$ 做正则化。

## cost function with regularization

#regularization_parameter #lambda 正则化参数 ($\lambda$) 
    控制“惩罚参数 $w_j$ 力度有多狠”的调节旋钮
    如果 $\lambda = 0$ 就是完全不罚款（照常过拟合）；
    如果 $\lambda$ 设得太大（比如 $10^{10}$），罚款重得离谱，模型为了不交罚款会把所有 $w_j$ 全压成 $0$，只剩下一条水平直线 $f(x)=b$（直接变成欠拟合）；
    只有选一个不小不大的 $\lambda$，才能既拟合好数据又防住过拟合。

正则化的直觉
在上一节视频中我们看到，用二次函数拟合房价数据效果很好，但如果拟合一个四次高阶多项式，画出来的曲线就会扭来扭去、发生过拟合。

假设我们不再单纯最小化原本的线性回归平方误差代价函数，而是对代价函数做一点修改
    ——在它屁股后面加上 **$1000 \cdot w_3^2 + 1000 \cdot w_4^2$**（这里选 $1000$ 只是随便挑的一个大数字，换成任何其他很大的数都行）
此时想最小化代价函数, 就是让w3,w4变很小. 变得非常非常小（接近 $0$）
    可能因为此时后面这两项实在太大了, 前面那项变小,压不过后面两项
所以当最小化这个新函数时，最终学出来的 $w_3 \approx 0$ 且 $w_4 \approx 0$，这就相当于**几乎抵消掉了 $x^3$ 和 $x^4$ 这两个高次方特征的影响**
    （因为不是完全让w3,4变成0. 所以还是保留了它们极其微小的贡献）
![[01-1793637258412.webp]]

所以这个就是 #regularization 的核心思想
    把参数变小，效果就像是拥有了一个更简单的模型（好比特征更少的模型），因此也就更不容易发生过拟合。

上面我们是对w3,4做了额外的处理
 但在实际应用中，如果你有海量特征（比如每套房子有 $n = 100$ 个特征，对应参数 $w_1 \sim w_{100}$ 以及第 $101$ 个参数 $b$），你事先根本不可能知道到底哪些特征最重要、哪些特征不重要该去惩罚。

所以标准做法是
    对所有参数 $w_j$ 统统加以惩罚
像下面那样
    **保留全部 $100$ 个特征，同时把所有的权重参数 $w_j$（从 $j=1$ 到 $n$）全都惩罚一点点、全都往小里缩一缩**——在代价函数后面统一加上 $\lambda \sum_{j=1}^{n} w_j^2$，
![[01-1793637660748.webp]]
**公式里的 3 个重要细节（工程惯例）**：
1. **正则化参数 $\lambda$** #regularization_parameter  ：公式里的希腊字母 **$\lambda$（读作 lambda）** 跟挑选学习率 $\alpha$ 一样，你也需要为 $\lambda$ 挑选一个合适的数值。
    
2. **为什么要除以 $2m$（写成 $\frac{\lambda}{2m}$）？** 
    按惯例，我们不光写 $\lambda \sum w_j^2$，还会把它也除以 $2m$，让前后两项都统一按 $\frac{1}{2m}$ 的比例缩放。
    这样做的好处是**更容易挑出合适的 $\lambda$ 值**——特别是当你的训练集规模扩大（比如收集了更多样本，导致样本总数 $m$ 变大）时，有了分母上这个 $2m$ 的同步缩放，你之前挑好的那个 $\lambda$ 数值大概率依然能继续正常工作，不用重新调参！
    (其实也是为了简化导数运算, 和之前 #squared_error_cost_function 里为了简化导数运算的/2m一样, 最后有解释 )
    
3. 按惯例，**一般只对参数 $\vec{w}$ 做正则化，不对 $b$ 做正则化**。但是有些地方可能也对b惩罚,也行

总结
$$J(\vec{w}, b) = \underbrace{\frac{1}{2m} \sum_{i=1}^{m} \left(f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)}\right)^2}_{\text{第一项：原始均方误差代价}} + \underbrace{\frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2}_{\text{第二项：正则化项 (Regularization term)}}$$
现在这个代价函数我们要怎么处理呢
1. **最小化第一项（均方误差项）**：鼓励算法通过减小预测值与真实值的平方差，去**把训练数据拟合好**；
2. **最小化第二项（正则化项）**：鼓励算法**让参数 $w_j$ 保持尽量小**，从而避免过拟合；
![[01-1793638070440.webp]]

$\lambda$ 数值怎么选择?
- **极端一：当 $\lambda = 0$ 时 $\rightarrow$ 过拟合 (Overfit)** 
    相当于你**完全没有使用正则化**，最终就会拟合出那条极度扭曲复杂的曲线，发生**过拟合**。
- **极端二：当 $\lambda$ 极其巨大时（比如 $\lambda = 10^{10}$） $\rightarrow$ 欠拟合 (Underfit)** 
    如果你把 $\lambda$ 设成一个天文数字（如 $10^{10}$），此时想要让总代价最小，唯一的办法就是让所有的 $w$ 都无限接近 $0$。结果算法会把 $w_1, w_2, w_3, w_4$ 统统选成几乎等于 $0$，导致模型直接退化成 **$f(x) \approx b$**——在图上画出一条**水平的直线**，彻底陷入**欠拟合**！
![[01-1793638145686.webp]]

上面有个细节没讲
💡  **为什么正则化项要用“平方 $w_j^2$”而不是直接加“$w_j$”？** 
    因为权重参数 $w_j$ 是有正有负的（比如 $w_1 = +1000, \; w_2 = -1000$）！如果不加平方直接相加，正负一抵消就变成 $0$ 了，根本起不到惩罚作用；
    而加上平方 $w_j^2$ 后，无论正负全都会变成正数（这种加平方和的正则化在机器学习里有个大名鼎鼎的专有名字，叫 **L2 正则化 / 岭回归 Ridge**），而且平方求导后刚好会掉下来一个 $2$，正好能跟分母上的 $\frac{\lambda}{\mathbf{2}m}$ 完美约掉！

深度分析一下  为什么这个公式是在“把 $w_j$ 往小里缩”？
    因为我们上面假设了w平方前面的系数是1000  所以默认要减小w
    这里怎么理解呢?

数学推导
* **把含 $w_j$ 的两项合并到最前面**：
    我们把上面 $w_j$ 的更新公式稍微移项改写一下——把中括号末尾的 $-\alpha \frac{\lambda}{m} w_j$ 移到最前面，跟原来的 $1 \cdot w_j$ 合并同类项
![[01-1793639224869.webp|464]]

* **右边第二项**：就是之前学的**无正则化线性回归的常规梯度下降更新项**。

* **左边第一项的系数 $\left(1 - \alpha \frac{\lambda}{m}\right)$ 到底是个什么数？**
    * 学习率 $\alpha$ 是一个很小的正数，比如 **$\alpha = 0.01$**；
    * 正则化参数 $\lambda$ 通常是个不大的正数（比如 $1$ 或 $10$），这里假设 **$\lambda = 1$**；
    * 训练集样本总数 $m$，假设 **$m = 50$**。
        * 把它们乘起来：$\alpha \frac{\lambda}{m} = \frac{0.01 \times 1}{50} = 0.0002$（一个极小的正数）；
* 因此，括号里的 **$1 - \alpha \frac{\lambda}{m} = 1 - 0.0002 = 0.9998$**——这是一个**比 $1$ 稍微小那么一丁点的数字**！

这说明在梯度下降的每一次迭代中，正则化干的事情就是：**先拿起你的 $w_j$ 乘上 $0.9998$（即乘上一个比 $1$ 略小的数，让 $w_j$ 的数值先自动缩水一丁点），然后再去执行常规的梯度下降更新**！
这从另一个视角完美解释了为什么正则化能在每一步迭代中把参数 $w_j$ 往小里压缩。

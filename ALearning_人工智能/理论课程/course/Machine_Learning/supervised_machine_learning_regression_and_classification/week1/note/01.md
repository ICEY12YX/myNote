# supervised vs. unsupervised machine learning

## what is machine learning?

#machine_learning #ML 机器学习
- Arthur Samuel 将其定义为“在没有显式编程的情况下，赋予计算机**学习能力**的研究领域（Field of study that gives computers the ability to learn without being explicitly programmed）”。它主要解决那些规则过于繁琐、人类无法逐行手工编写逻辑，需要程序通过数据或经验==自主总结规律==的任务。
- **通俗说**：传统编程是程序员一步步手把手教电脑“第一步做什么、第二步做什么”；而机器学习是给电脑海量练习机会和评价标准，让它自己“悟出”怎么做最好。

## supervised learning

#supervised_learning 监督学习
- **给算法看带有“标准答案”的历史数据（即同时给出输入 $x$ 和对应的正确结果标签 $y$）**，让它摸清输入是怎么变到输出的。等它学成之后，你只给它一个新的输入 $x$（不给答案），它也能自己猜出靠谱的结果 $y$。
    
#regression 回归
- **监督学习里专门用来“预测一个具体数字”的方法**。比如预测房价是多少钱，结果可能是 15 万、7 万或 18.3 万等任意连续的数值（说白了就是从无数个可能的数字里猜出一个数，而不是做“是/否”的选择题）。


什么是 #supervised_learning 
就是让算法学会**从输入 $x$ 到输出 $y$ 的映射关系**
    learn x to y or input to output mappings

训练算法时，
喂给它的学习样本里必须包含“标准答案”（也就是针对每个输入 $x$，都明确标好了正确的输出标签 $y$，correct label $y$）
机器慢慢就摸清了输入输出的规律；
等训练好之后，你**只丢给它一个全新的、没见过的输入 $x$（不再提供答案标签），它也能自己给出一个八九不离十的预测结果 $y$**
![[01-1793091592823.webp]]

监督学习的例子
下面3个是
- **在线广告点击预测（Online advertising）——目前最赚钱的应用**：
    - 大型广告平台的算法会把“某条广告的信息 + 你个人的相关信息”作为输入 $x$，去预测输出 $y$——**你到底会不会点击这条广告**。
    - 因为对平台来说，用户每点一次就是一笔真金白银的收入，哪怕只是把展示给你的广告点击率稍微提高一点点，都能带来巨额营收。
    
- **自动驾驶（Self-driving car）**：输入 $x$ 是车载摄像头拍到的画面加上雷达等传感器的数据，输出 $y$ 是周围其他车辆的位置，从而让自动驾驶汽车安全避让。
    
- **工业视觉质检（Visual inspection in manufacturing）**：输入 $x$ 是刚下生产线的产品照片（比如一部新造好的手机），输出 $y$ 是判断产品表面有没有划痕、凹陷或其他瑕疵，帮工厂减少次品。
![[01-1793091879083.webp]]

问题假设
想根据房子的面积来预测房价
- **横轴（Horizontal axis）**：房子的面积，单位是平方英尺（square feet，美国常用面积单位）。
- **纵轴（Vertical axis）**：房子的价格，单位是千美元（thousands of dollars）。
现在你有个朋友想卖一套 **750 平方英尺**的房子，问你能卖多少钱？
    你就要预测这个事情

- **方法一（画直线）**：算法可以在这些数据点之间拟合出一条直线（也就是找一条最贴近这些数据点的直线来代表房价规律）。
- **方法二（画曲线）**：画直线并不是唯一的办法。算法也可以拟合一条稍微复杂点的曲线
![[01-1793092231911.webp]]
像这种预测房价的任务，在监督学习里专门叫做**回归** #regression 
    指我们的目标是**从无数个可能的连续数字里，预测出一个具体的数值**（_predict a number from infinitely many possible numbers_），比如房价可能是 150,000、70,000、183,000 或者中间的任何一个数字。
___

#classification 分类
- **监督学习的第二大核心方法，专门用来做“选择题”（即预测结果属于哪一个类别，而不是预测一个连续变化的具体数字）**。它的输出只有有限的几个选项（比如判断肿瘤是“良性”还是“恶性”，或者判断图片是“猫”还是“狗”）。即便输出结果用数字 0、1、2 来代指，这些数字也只是代表不同的类别代号，绝不会出现 0.5 或 1.7 这种中间值。

#class #category 类别 / 分类标签
- 在分类问题中，**输出的结果选项就叫 Class 或 Category（这两个词在机器学习里是一个意思，经常混着用）**。


问题假设
你在帮医生开发一个诊断乳腺癌的机器学习工具
系统要根据病人的病历，判断病人体内的肿瘤（肿块，lump）到底是**恶性的（Malignant）**，还是**良性的（Benign）**
用 **0 代表良性（Benign）**，用 **1 代表恶性（Malignant）**

- **第一版画法（二维坐标图）**：。
    - 横轴（Horizontal axis）表示肿瘤的大小（size of the tumor），纵轴（Vertical axis）只有两个取值：**0 或 1**。
        
- **第二版画法（用符号画在同一条横轴上）**：
    - 既然只有两类结果，我们干脆直接把数据画在一条直线上（横轴依然是肿瘤大小），改用**两种不同的符号来代表类别**：用**圆圈 `O` 代表良性样本**，用**叉号 `X` 代表恶性样本**。
![[01-1793092604812.webp]]

- 算法还可以进一步细分是“癌症 1 型（Type 1）”还是“癌症 2 型（Type 2）”。这样一来，系统就有 **3 种可能的输出类别**（良性、癌症 1 型、癌症 2 型）。

    - **顺带提个术语习惯**： #class #category  在分类问题里，输出类别（output classes）**和**输出分类（output categories）这两个词完全是一个意思，平时经常换着用。
        
- **分类结果的呈现形式（文字或数字代号）**：
    - **可以是非数字（Non-numeric）**：比如直接预测图片是“猫”还是“狗”，或者肿瘤是“良性”还是“恶性”。
    - **也可以是数字（Numbers）**：比如用 `0, 1` 或者 `0, 1, 2` 来表示。
        
    - 哪怕分类输出的是数字，它和回归也有本质区别——分类预测的是一组数量有限的离散类别（比如只可能是 0、1、2 这几个固定选项），**绝不会预测出像 0.5 或 1.7 这种夹在中间的小数**
![[01-1793092969283.webp]]

前面的例子只用了 1 个输入值（肿瘤大小），但实际中完全可以**同时使用多个输入值来预测输出**
比如除了“肿瘤大小”，我们还知道每个病人的 “年龄（Age）”。
面对这种数据，学习算法会**寻找一条分界线**
只要看新病人的数据点落在这条分界线的哪一侧, 就能做出肿瘤事恶性还是良性的判断
    图上的预测点 落在了圆圈 `O` 这一侧，所以更可能是良性
![[01-1793093278094.webp]]
在真实的乳腺癌检测项目中，工程师们会喂给算法更多输入特征，比如肿块的厚度（thickness of the tumor clump）、细胞大小的均匀度（uniformity of the cell size）、细胞形状的均匀度（uniformity of the cell shape）等等。

## unsupervised learning

#unsupervised_learning 无监督学习
- **只给算法一堆没有“标准答案”（即没有输出标签 $y$）的原始数据**，不教它哪个是对的、哪个是错的，而是让算法自己去数据里摸索规律、结构或好玩的共性。

#clustering 聚类（聚类算法）
- **无监督学习里最常见的一种方法，专门用来把没有标签的数据“自动分群/归类”**。算法自己看哪些数据长得像、有共同点，就把它们抱成一团，分到同一个组（Cluster / 簇）里。

上一节的肿瘤判断 到 #unsupervised_learning 里就会变成这样
我们拿到的数据**没有任何输出标签 $y$**
    同样给你病人的“肿瘤大小”和“年龄”数据，但**根本没告诉你谁是良性、谁是恶性**，画在右边图上就全是一样的点（没有任何 `O` 或 `X` 的区分）。
现在任务变成  让算法自己去数据里找某种结构、规律，或者发现一些有意思的东西
![[01-1793093607591.webp]]
#clustering 聚类
面对刚才那堆没有标签的数据点，无监督学习算法可能会发现：**这些数据点可以被划分成两个不同的簇** #cluster


聚类应用: 谷歌新闻
    把讲同一件事的相关报道自动归拢到一起

头条新闻标题是：《大熊猫在日本最古老的动物园诞下罕见双胞胎幼崽》
在这条新闻下面紧跟着好几篇相关报道。
    观察这 5 篇报道的标题会发现：它们全都高频出现了 **`panda`（熊猫）**、**`twin`（双胞胎）** 和 **`zoo`（动物园）** 这几个词。

聚类算法在当天全网几十万篇新闻里，发现这几篇文章提到了相似的词汇，就把它们自动聚成了一组
完全是**算法在没有任何人工监督的情况下，自己摸索出今天有哪些新闻可以归为一类**
![[01-1793093924232.webp]]

聚类应用: 基因 / DNA 微阵列数据分析
- 图上**每一竖列（Column）代表一个人的 DNA 数据**；**每一横行（Row）代表某一个特定的基因**（比如某一行代表决定眼睛颜色的基因，另一行代表影响身高的基因，甚至还有决定人讨不讨厌吃西蓝花、芦笋等蔬菜的基因）。
- 表格里的红、绿、灰等不同颜色，代表**某个特定基因在这个人身上被激活（表达）的程度有多高**。
可以运行聚类算法，根据基因激活度的相似性，**把这些人自动归类成不同的群体/类型**——比如分成“第 1 类人（Type 1）”、“第 2 类人（Type 2）”、“第 3 类人（Type 3）”
    哪些人被分到一起,是计算机自己找的
![[01-1793094111666.webp]]


聚类应用: 客户分群 / 市场细分
    很多公司手里有庞大的客户资料库，希望能**自动把客户划分成不同的细分市场群体（Market segments），从而针对不同人群提供更有效的服务**。

DeepLearning.AI 团队为了搞清楚大家为什么要来上课、订阅周刊或参加活动，对社区用户做了一次聚类（即市场细分），结果算法自动找出了**几类动机截然不同的学习者群体**：
    1. **第一群人**：动机是**学知识、提升个人技术能力**。
    2. **第二群人**：动机是**为了职业发展**。
    3. **第三群人**：希望能**紧跟行业动态，了解 AI 是如何影响自己所在行业的*。
    
- 团队正是利用这种无监督聚类，摸清了社区里主要有哪几大类学习者，从而更好地服务大家。

# regression model

## linear regression model

#linear_regression_model 线性回归模型
- **直接往数据里画一条最贴合的直线来预测具体数值的模型**（_fitting a straight line to your data_）。它是目前全世界应用最广泛的机器学习算法，掌握了它，里面的核心概念都能直接套用到后续更复杂的模型上。

#training_set 训练集
- **专门拿来喂给模型、供模型学习的“历史题库”**（即包含已知输入和对应“标准答案”的数据集）。注意：你真正想去预测的那个新问题（比如客户还没卖掉的房子）并不在训练集里。

#feature #input_variable 特征 / 输入变量 ($x$)
- **用来做预测的已知线索或条件**，标准符号用小写字母 $x$ 表示（比如用“房屋面积”去猜房价，那“房屋面积”就是特征 $x$）。

#target_variable #output_variable 目标变量 / 输出变量 ($y$)
- **你最终想让模型预测出来的那个结果（即标准答案）**，标准符号用小写字母 $y$ 表示（比如房屋的真实成交价）。


问题假设
想根据房子的面积来预测房价
- **横轴（Horizontal axis）**：房屋面积，单位是平方英尺（square feet）。
- **纵轴（Vertical axis）**：房屋价格，单位是千美元（thousands of dollars）。
图上的每一个小叉号（cross）都代表一套房子，记录了它的面积和最近一次卖出去的真实成交价。
有个客户想卖房，问你她的房子能卖多少钱, 她的房子面积是 **1250 平方英尺**。
先用历史数据 训练模型, 训练出一个线性回归模型（即在数据点中间画出一条最贴合的直线，_best fit line_）
顺着横轴的 **1250** 往上找, 出来的数字大概是 **22 万美元（$220,000）**——这就是模型帮客户算出来的估价。
![[01-1793189656854.webp]]
这个属于 #supervised_learning 
这是一种 #regression_model 
    因为它预测的输出结果是一个**具体的数字**（比如 220,000、1.5 或 -33.2 这种连续数值）。
    **回归**可以输出无穷多个可能的数字  #continuous 
上面这种也叫 #linear_regression_model 
    是解决回归问题的一种模型, 当然 回归模型不止这一种

老师还顺带复习了一下 分类
ps, 不要忘记还有另一类 监督学习的分支  #classification 
    输出只有有限的几个固定选项, 离散的 #discrete 
    比如识别图片是“猫（2种可能）”还是“狗”，或者判断病人患了 10 种特定疾病里的哪一种。

几个常用的术语
训练集 #training_set 
    就是刚才看到的、专门用来喂给模型学习的整个数据集。（注：你客户那套 1250 平方英尺的房子因为还没卖掉、没人知道价格，所以**不在**这个训练集里。或者说应该属于 #testing_set 测试集）

熟悉符号:
- **$x$ —— 输入变量 / 特征**（ #input_variable / #feature  ）：
    - 用小写字母 $x$ 表示输入。比如训练集里的第一套房子，$x$ 就是房屋面积，即 $x = 2104$。

- **$y$ —— 输出变量 / 目标变量**（ #output_variable / #target_variable ）：
    - 用小写字母 $y$ 表示你要预测的目标结果。比如第一套房子的价格，即 $y = 400$。
        
- **$m$ —— 训练样本总数（Total number of training examples）**：
    - 表格里每一行代表一套房，也就是一个独立的**训练样本（Training example）**。用小写字母 $m$ 代表总共有多少行样本，在这个例子里 $m = 47$。
        
- **$(x, y)$ —— 单个训练样本（Single training example）**：
    - 用一对括号 $(x, y)$ 表示某一个具体的训练样本。比如第一个样本就是 $(2104, 400)$。
        
- **$(x^{(i)}, y^{(i)})$ —— 第 $i$ 个训练样本（The $i$-th training example）**：
    - 因为我们有 47 个样本，为了指明说的是表格里的第几行，我们在右上角加一个带括号的上标 $(i)$。
        
    - 这里的 **$i$ 只是一个行号索引（inde）**。
    - 比如当 $i = 1$（指表格第 1 行）时，$x^{(1)} = 2104$，$y^{(1)} = 400$。
        
    - **⚠️ 千万注意避坑**：上标带括号的 $x^{(2)}$ **绝对不是 $x$ 的平方（not exponentiation / not $x$ squared）**！它纯粹只是代表“表格里第 2 行的那个训练样本”。

#model #function 模型 / 函数 ($f$)
- **监督学习算法吃进训练集后，最终训练出来的那个“预测公式”**，用小写字母 $f$ 表示。（在早期机器学习文献里它也常被称为 Hypothesis“假设”，现在直接叫函数 $f$ 或模型即可。）它的作用就是接收一个新的输入 $x$，算出一个预测值 $\hat{y}$。


y_hat 预测值 ($\hat{y}$)
- **在字母 $y$ 头顶加个小尖帽（读作 y-hat），专门用来表示模型算出来的“估计值 / 预测值”**。注意把它和真正的标准答案 $y$（Target，真实值）区分开：$\hat{y}$ 只是模型猜的数，不一定等于真实值 $y$。

#parameters #coefficients #weights 参数 / 系数 / 权重 ($w, b$)
- **模型里那些可以通过不断调整，来让模型变得更准的变量**（在线性回归公式 $f_{w,b}(x) = wx + b$ 里，指的就是 $w$ 和 $b$）。在机器学习中，大家也经常把参数 $w$ 和 $b$ 叫做系数（coefficients）或权重（weights）。


#slope 斜率 ($w$)
- **直线有多陡（倾斜程度）**，由参数 $w$ 的数值直接决定（即 $x$ 每往右走 1 格，直线高度往上爬多少格）。


#y_intercept $y$ 轴截距 ($b$)

#cost_function  代价函数 
- **专门用来打分、衡量你画的那条直线“预测得有多差（总误差有多大）”的数学公式**, 我们需要想办法调 $w$ 和 $b$，让这个代价越小越好（误差越小，说明模型越准）。

#squared_error_cost_function  平方误差代价函数 ($J(w,b)$)

- **第 2 步：对误差求平方（Squared error）**：

- **第 3 步：把整个训练集所有样本的误差加起来（Sum over all examples）**：

- **第 4 步：除以样本总数 $m$ 求平均（Compute the average）**：
    - 如果只求和，一旦训练集变大（样本数 $m$ 变多），加出来的总误差就会自动变大。

# Train the model with gradient descent
## gradient descent

#gradient_descent 梯度下降
- **求函数最小值的一种方式**
- 可以用来自动寻找最佳参数（比如 $w$ 和 $b$），从而让某个函数（比如代价函数 $J$）达到最小值的核心算法。
- 它的工作方式就像蒙着眼睛下山：先随便选个起点，然后每次在原地转一圈，找脚下最陡的下坡方向迈出一小步，一步步走到谷底。

#local_minimun 局部最小值
- **当代价函数不是简单的单个汤碗形状，而是像高低起伏的高尔夫球场一样有好几个山谷时，每个山谷的谷底就叫一个“局部最小值”**。
[[ALearning_人工智能/理论课程/course/Mathematics_for_Machine_Learning_and_Data_Science/calculus/week2/note/01|01]] 建议整篇看看,也不多, 重点关注梯度是啥

上节课我们靠肉眼在代价函数图上试不同的 $w$ 和 $b$，现在我们需要一套**更系统的方法，自动找出能让代价 $J(w,b)$ 达到最小值的参数 $w$ 和 $b$**

用梯度下降
- 这个算法就是用来求函数最小值(或者准确的说是 #local_minimun )的,  不是求代价函数最小的专属  (当然这条是针对小白而言的笔记)
        (废话) 比如遇到一个包含很多个参数的模型，代价函数是 $J(w_1, w_2, \dots, w_n, b)$，你的目标是挑出一组 $w_1$ 到 $w_n$ 以及 $b$ 的值让 $J$ 最小（$\underset{w_1, \dots, w_n, b}{\text{minimize }} J(w_1, w_2, \dots, w_n, b)$），同样可以直接用梯度下降来解决。

大概工作框架
- **第 1 步：随便选个初始猜测值（Initial guesses）**：
    - 先给参数 $w$ 和 $b$ 随便定一个初始值。在线性回归里，初始值设成多少关系不大，所以**最常见的做法就是直接把它们都设成 0（即设 $w = 0, b = 0$）**。
        
- **第 2 步：每次微调一点点，直到停在最低点 （或非常接近最小值的位置）**
![[01-1793281978254.webp]]

有些函数最小值不止一个位置
    比如下面这张图
        这里顺便说了, 这张图通常不是 #linear_regression 和 #squared_error_cost_function 所能得到的代价函数图
        线性回归+平方误差 一般都是得到碗装的 代价函数-参数 图

可以把这张图想象成 高低起伏的户外公园或高尔夫球场, 现在我们要下山
梯度下降是怎么带你下山的？
- **选一个起点**：想象你正站在这座山丘的某一个高点上（这就对应你一开始给 $w$ 和 $b$ 选的初始值），你的目标是**尽可能高效地走到某一个山谷的谷底**。

- **原地转 360 度找最陡下坡路**：你原地旋转 360 度环顾四周，问自己：“如果我现在只迈出**极小的一步（a tiny little baby step）**，并且想尽可能快地往山下走，我该朝哪个方向迈这一小步？”
- **迈出第一步（最陡下降方向）**：你看了一圈，选定了那个下坡最快的方向迈出了一小步。在数学上，这个方向就叫做**最陡下降方向（Direction of steepest descent）**——意思是同样迈出一小步，朝这个方向走能让你比朝任何其他方向下降得都快。

- **不断重复直到谷底**：迈完第一步到达新位置后，你**再次原地转 360 度**，找到当前位置下坡最快的方向，再迈出一小步……如此一步步重复下去，直到你最终走到这个山谷的谷底——也就是图上的这个**局部最小值（Local minimum）**。
![[01-1793283624407.webp]]

起点不同，可能会走进不同的 局部最小值 #local_minimun

## implementing gradient descent

#learning_rate 学习率 ($\alpha$ / Alpha)
- **控制梯度下降每次往山下迈出的“步子有多大”的数字**，用希腊字母 $\alpha$ 表示（通常是一个 0 到 1 之间的小正数，比如 $0.01$）。如果 $\alpha$ 设得很大，就相当于迈着大步子激进地往山下冲；如果 $\alpha$ 设得很小，就是迈着小碎步一点点往下挪。

#derivative 导数 / #partial_derivative  偏导数项 ($\frac{\partial}{\partial w} J(w,b)$)
- **微积分里的一个概念，在梯度下降里专门用来告诉你“下一步该朝哪个方向迈步”**，并且它和学习率 $\alpha$ 配合起来，共同决定了这一步实际迈出去的距离有多大（哪怕你完全不懂微积分也没关系，后面会直接给现成的计算规律）。

#converge 收敛
- **指梯度下降一步步走到山谷谷底（局部最小值）后“停稳了”的状态**——到了这个位置，哪怕再继续往下走，参数 $w$ 和 $b$ 的数值也基本不再发生什么变化了。
[[ALearning_人工智能/理论课程/course/Mathematics_for_Machine_Learning_and_Data_Science/calculus/week2/note/01|01]]    ## optimization using gradient descent in one variable


梯度下降 每次要往最陡的地方下山, 那是哪个方向呢? 每次更新参数的公式是什么呢?
![[01-1793289618832.webp|333]]
(b的公式同理, 后面偏导变成b的偏导数就好了)

公式解读
- **学习率 ($\alpha$)** #learning_rate ：
    - 通常是 $0$ 到 $1$ 之间的一个小正数（比如 $0.01$）。
    - **作用**：控制你往山下走时每一步迈多大。
    - 如果 $\alpha$ 非常大，梯度下降就会非常激进（`aggressive`），每次往山下跨出一大步；如果 $\alpha$ 非常小，就会迈着小碎步（`small baby steps`）慢慢往下挪。
        
- **导数项 ($\frac{d}{dw}J(w, b)$)** #partial_derivative ：
    - 决定迈步的方向。
        - 之前数学课学的, 梯度方向(就是偏导方向)就是函数变大速度最快的方向

**重复迭代直到收敛 (`repeat until convergence`)**：
- 在梯度下降算法中，我们要不断重复执行 $w$ 和 $b$ 的这两个更新步骤，直到算法**收敛 (`converges`)**。
- **什么是收敛**：就是走到了局部最低点 #local_minimun ，此时每多走一步，参数 $w$ 和 $b$ 的数值都不再发生多大变化了。

人们提到“梯度下降”时，永远指的都是**同步更新**版本（而且写代码时同步更新其实更自然）。
虽然不小心写成了非同步更新，程序大概率也能凑合跑出差不多的结果，但它严格来说已经不是真正的梯度下降了，而是变成了另一种性质不同的其他算法——所以写代码时一定要坚持左边的**正确同步更新**写法。

💡 **避坑/重难点补充**： 
初学者写 Python 代码时最容易直接连写两行, 这也是不对的：
    `w = w - alpha * dj_dw`
    `b = b - alpha * dj_db`
    这种写法和上面右边的写法没有区别
注意：
    **如果你在写这两行之前，已经提前用旧的 `w` 和 `b` 把数值 `dj_dw` 和 `dj_db` 算好存进变量了**，那么直接连写这两行就是标准的同步更新；
    但如果你是在第二行里**边算 `dj_db(w, b)` 边赋值**，那就会踩中老师说的“把刚更新的新 `w` 塞进 `b` 的导数里”的坑！

## gradient descent intuition

下面老师为了简化解释, 先把b去掉了
    这样就能直接看平面二维图像 J(w)

w的更新公式变这样
$$w = w - \alpha \frac{d}{dw}J(w)$$
后面那项求导的, 不管是求导数还是偏导  老师都简称为导数 #derivative 

(下面这部分 数学课也解释过了   [[ALearning_人工智能/理论课程/course/Mathematics_for_Machine_Learning_and_Data_Science/calculus/week2/note/01|01]]    ## optimization using gradient descent in one variable)

 **如何直观理解导数（画切线看斜率）**：求这一点处的导数 $\frac{d}{dw}J(w)$，等价于在该点画一条**切线**  #tangent_line 。这条切线的 **斜率** #slope  就是函数 $J$ 在该点的导数。
 
 **怎么算斜率**：在切线上画一个小直角三角形(任何地方画都可以, 反正比值出来都一样)，用**高度除以宽度** #rise / #run  就是斜率。

起点在碗的右侧（切线斜率为正）
- **斜率符号判断**：在右侧这个点，切线是朝右上方倾斜的，所以斜率是正数，即**导数大于 $0$（正数）**。
    
- **参数 $w$ 怎么变**：$$w = w - (\text{学习率 }\alpha \times \text{正数})$$
    因为学习率 $\alpha$ 永远是正数，所以相当于拿 $w$ 减去一个正数，结果得到的新 $w$ 会**变小**。
    
- **图像上的实际效果**：$w$ 变小意味着在横轴上**往左移动**。

起点在碗的左侧（切线斜率为负）
- **参数 $w$ 怎么变**：$$w = w - (\text{学习率 }\alpha \times \text{负数})$$
    减去一个负数，就等于**加上一个正数**（负负得正），所以更新后的 $w$ 会**变大**。
    
- **图像上的实际效果**：$w$ 变大意味着在横轴上**往右移动**。。

==所以无论你把起点扔在碗的左边还是右边，这个减号配合导数的正负号，都能自动把 $w$ 往谷底推。==

## running gradient descent

#batch_gradient_descent 批量梯度下降 
    用大白话来说，批量梯度下降就是我们刚才学的这种“最老实、最全面”的梯度下降：每次迈出一步更新参数 $w$ 和 $b$ 之前，都要把手里所有的训练样本（即一整个批次 `entire batch`，从第 $1$ 个到第 $m$ 个）全都看一遍、算一遍总账，而不是只挑其中一小部分数据来算。

#batch_gradient_descent 批量梯度下降
    在梯度下降的**每一步**中，我们都要计算导数里的求和项 $\sum_{i=1}^{m}$ ，即察看**所有的训练样本**

虽然看起来每次都考察全部训练样本很麻烦, 但是实际上只用算一次就好了?
    解释
    
![[01-1793305695964.webp]]

机器学习里其实还有其他版本的梯度下降，它们在每一步更新时不看完整的训练集, 不过在线性回归里，用的基本都是标准的**批量梯度下降**。
补充:
    以后你在学深度学习时还会听到另外两个高频词：**随机梯度下降 (`Stochastic Gradient Descent, SGD`)** 和 **小批量梯度下降 (`Mini-batch Gradient Descent`)**。它们的唯一区别就是每次算导数时看多少个样本：

- **批量 (`Batch`)**：每次更新看**全部 $m$ 个**样本（就是本节课学的这种，数据量不大时最稳）；
    
- **小批量 (`Mini-batch`)** / **随机 (`SGD`)**：当数据有几百万条时，每次全算一遍太慢了，所以每次只抽一小撮（比如 $32$ 或 $64$ 个样本，或者 $1$ 个样本）来算导数迈一步。先把 `Batch` 代表“全看一遍”记牢，后面学到时就能秒懂！

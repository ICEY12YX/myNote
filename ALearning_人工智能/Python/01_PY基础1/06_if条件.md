### 模块 1：基础判断与链式比较

```python
x = 1
y = 2
z = 3
if x < y:
    print("x is less than y")

if x < y < z:
    print("x is less than y, and y is less than z")

if x <= y:
    print("x is less than or equal to y")

```

* **解释**：
    利用 `if` 和冒号开启条件判断。如果条件为真（True），就执行下方缩进的代码。这与你在 Java 或 C 中写 `if (x < y) { ... }` 逻辑完全一致，**只是去掉了括号和花括号**。
* **对比经验 (超强语法)**：
    ⭐请重点看 `if x < y < z:` 这一行！
    在你熟悉的 Java、C++ 或 JS 中，如果你想表达这个逻辑，必须使用逻辑与符号拼接，写成 `x < y && y < z`。
    但在 Python 中，它原生支持像数学公式一样的**链式比较**，极其直观优雅！这在未来处理数据边界值时非常实用。

### 模块 2：等于号与多重分支结构

```python
if x == 1:  # 不能写x=1,一个等号是赋值语句
    print("x is equal to 1") 

x = 1
y = 2
z = 3

if x > 1:
    print("x is greater than 1")
elif x < 1:  # 就是else if
    print("x is less than 1")
else:
    print("x is equal to 1")
print("finish running")

```

* **避坑指南 (等于号的陷阱)**：
    一个等号 `=` 是**赋值**（把 1 塞进 x 里），两个等号 `==` 才是**判断相等**。
    (这与你之前学过的所有强类型语言规则是一模一样的。)

* **⭐关键字缩写 (Elif)**：
    Python 为了追求极致的简洁和对齐，把其他语言里的 `else if` 直接缩写成了 **`elif`**。
* **❗️ 缩进的魔力**：
    注意最后那行 `print("finish running")`，因为它**没有缩进**，它已经脱离了 `if-elif-else` 的控制范围。无论前面的条件怎么跳转，这行代码最终都一定会被执行。

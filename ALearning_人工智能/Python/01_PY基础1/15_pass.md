注意到了 `continue` 和 `break`（这两个家伙在 Python 里的用法和你熟悉的 C 语言、Java 完全一模一样，就是跳过当前循环和砸碎整个循环），还精准地抓住了 Python 特有的“占位符”——`pass`。

---
#### 模块 1：揭秘独有的 `pass` 关键字

```python
a = True
while a:
    b = input("type something")
    if b == "1":
        a = False
    else:
        pass  # 这啥意思
    print("still in while")
print("finish")
```

* **疑问解答 (这啥意思？)**：
    `pass` 就是中文里“略过”**的意思。它在代码里什么实质性工作都不做，就是一个**纯纯的“占位符”。
* **为什么 Python 必须要发明 `pass`？**
    * 在你熟悉的 C 语言或 Java 里，如果你写了一个 `else` 但暂时不想在里面写任何逻辑，你完全可以留一对空的大括号 `{}`，编译器不会有任何意见。
    * 但是，**Python 去掉了大括号**，它是极其严格依赖缩进（空格）来划分代码块的！
    * 所以，当你需要保持代码的结构完整，但又暂时不想写具体逻辑时，就可以填一个 `pass` 进去，告诉系统：“我知道这里应该有缩进的代码，我只是暂时挂个空挡，请你不要报错。”

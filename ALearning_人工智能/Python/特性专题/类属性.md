#类属性
___
Python 的两条核心潜规则：**“查找规则”**和**“赋值规则”**。

### 1. 查找规则：先找自己，再找类

当你在代码里写下 `calculator.name` 去获取值的时候，Python 会按顺序执行两步检查：

* **第一步**：在这个对象（`calculator`）自己身上找，看它有没有一个专属的 `name`。如果有，直接拿来用。
* **第二步**：如果对象自己身上没有，Python 就会去它的“老家”（也就是 `Calculator` 类）里找类属性 `name`。

### 2. 赋值规则：用对象赋值，只改自己

当你在代码里写下 `calculator.name = "某某"` 进行赋值的时候，**Python 绝对不会去修改类里面的属性**。它只会在这个具体的对象身上，新建或修改一个只属于它自己的属性。

---

### 用这两条规则来拆解你的代码

我们一步步来看你的代码运行过程：

#### 第一阶段：共享类属性

```python
class Calculator:
    name = "Good Calculator"  # 这是类属性，属于公共资源

calculator = Calculator()
calculator1 = Calculator()

print(calculator.name)   # 输出 Good Calculator
print(calculator1.name)  # 输出 Good Calculator

```

**发生了什么：** `calculator` 和 `calculator1` 自己身上都没有 `name`。根据**查找规则**，它们都去类里面找，于是都找到了公共的 `"Good Calculator"`。

#### 第二阶段：修改类属性

```python
Calculator.name = "Bad Calculator"

```

**发生了什么：** 你直接通过类名 `Calculator` 修改了公共资源。现在类属性变成了 `"Bad Calculator"`。

#### 第三阶段：用对象赋值（关键转折点）

```python
calculator.name = "sss Calculator"

```

**发生了什么：** 根据**赋值规则**，这一步**并没有**修改公共的类属性！Python 其实是在 `calculator` 这个具体的对象身上，**偷偷新建了一个只属于它自己的实例属性**，名字也叫 `name`。
⭐️（注意：这个时候，`calculator1` 身上依然什么都没有。）

#### 第四阶段：最终打印

```python
print(calculator.name)   # 输出 sss Calculator
print(calculator1.name)  # 输出 Bad Calculator

```

**发生了什么：**
* 对于 `calculator`：根据**查找规则**，它先在自己身上找，发现自己刚刚新建了一个专属的 `name`（"sss Calculator"），于是直接输出。它不再去类里找了，公共的属性被“遮蔽”了。
* 对于 `calculator1`：根据**查找规则**，它在自己身上没找到 `name`，于是去类里面找。此时类属性在第二阶段被改成了 `"Bad Calculator"`，于是它输出了 `"Bad Calculator"`。

所以说,只看上面的代码
打印属性name,是一个查找的过程
并且, 注意到, 只在类里写`name = "xxx"` 这仍然是类属性
创建出来的对象里,实际上是没有name属性的,就是没被创建出来
所以要用到 #init函数
[[init函数]]

### 总结

* **类属性**（写在类里面，方法外面）：所有对象共享。通过 `类名.属性` 来修改，会影响所有还没有专属属性的对象。
* **实例属性**：对象私有。只要你写了 `对象.属性 = 值`，就是在给这个特定的对象开小灶，它以后就用自己的，不再看类的公共属性了。

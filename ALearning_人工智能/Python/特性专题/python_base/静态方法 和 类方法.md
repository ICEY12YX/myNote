## 静态方法

如果你想在类里面放一个普通的函数，完全不需要用到 `self`，你需要使用 Python 提供的一个专属标记：**`@staticmethod`（静态方法）**。

你只需要在定义函数的前一行加上 `@staticmethod`，这就等于明确地告诉 Python：“请把这个函数当成一个普通的独立函数对待，调用的时候千万不要偷偷给我塞入对象本身。”

让我们把你之前的 `Calculator` 代码用静态方法改写一下：
```python
class Calculator:
    
    @staticmethod
    def add(a, b):
        # 这里不需要写 self，完全像普通函数一样接收参数
        result = a + b
        return result

# 调用方式一：用类名直接调用（这是最推荐的写法）
print(Calculator.add(1, 2))  # 输出: 3

# 调用方式二：用实例对象调用（这样写也能跑通，Python同样不会偷偷传 self）
calculator = Calculator()
print(calculator.add(1, 2))  # 输出: 3

```

### 关于静态方法的三个关键点

* ⭐️**完全独立**：带有 `@staticmethod` 的函数，完全不知道自己属于哪个对象，它**无法访问对象的任何数据或属性**。它就是一个纯粹的、只依赖传入参数来干活的函数。
* **逻辑分组**：既然它是普通函数，为什么不直接写在类外面呢？把它放在类里面，主要是为了**代码归类**。比如 `add`（加法）功能在逻辑上天然属于 `Calculator`（计算器），把它们放在一起，代码的条理会更清晰。
* **推荐调用法**：虽然你可以用对象（如 `calculator`）去调用静态方法，但在 Python 中，大家通常**更习惯直接用类名去调用**（也就是 `Calculator.add(1, 2)`）。这样别人读你的代码时，一眼就能看出来这是一个通用的、不需要依赖具体对象的功能。

## 类方法
`@classmethod` 叫作**类方法**。顾名思义，它是专门给“类”这个整体去使用的方法，而不是给某一个具体的“对象”使用的。

### `cls` 参数是干什么用的？

上一节我们讲到，普通方法的第一个参数是 `self`，Python 会把**对象自己**传给它。
而在带有 `@classmethod` 的方法中，规则变了：**Python 会自动把“类本身”传给第一个参数**。

为了和 `self` 区分开，我们习惯性地把这个参数命名为 **`cls`**（也就是 class 的缩写）。

简而言之：
* **`self`** 拿到的是具体的**对象**（比如 `calculator1`）。
* **`cls`** 拿到的是**类本身**（比如 `Calculator` 这个图纸）。

---

### 代码演示：用类方法修改类属性

还记得你上一个问题里，用 `Calculator.name = "Bad Calculator"` 来修改公共的类属性吗？在实际开发中，如果我们想规范地管理公共属性，通常会专门写一个 `@classmethod` 来做这件事：

```python
class Calculator:
    # 这是一个类属性（公共资源）
    name = "Good Calculator"
    
    @classmethod
    def change_name(cls, new_name):
        # 这里的 cls 就是 Calculator 类本身
        # cls.name 就等同于 Calculator.name
        cls.name = new_name
        print(f"公共名字已经统一改成了: {cls.name}")

# 我们不需要创建任何对象，直接用类名来调用类方法
Calculator.change_name("Super Calculator")

# 验证一下
calculator1 = Calculator()
calculator2 = Calculator()

print(calculator1.name)  # 输出: Super Calculator
print(calculator2.name)  # 输出: Super Calculator

```

### 什么时候必须用 `@classmethod`？

当你写的一个方法，完全不需要关心任何具体的对象（不需要用到 `self`），但它的逻辑需要操作或者读取公共的“类属性”时，这就是 `@classmethod` 发挥作用的最佳时机。

* **@staticmethod（静态方法）**：既不需要对象（self），也不需要类（cls），纯纯的独立工具人。
* **@classmethod（类方法）**：不需要对象（self），但需要类（cls）来操作公共资源。
* **普通方法**：必须依赖具体的对象（self）来干活。

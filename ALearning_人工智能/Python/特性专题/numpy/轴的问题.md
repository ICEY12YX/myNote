`axes` 和 `axis` 是同一个词的单复数关系（单数是 **axis**，复数是 **axes**），但在代码中它们的使用语境不同。同时，你记忆中“`axis[0]` 指列”其实是一个在初学阶段非常容易混淆的经典概念偏差。

---

### 一、什么是 `axes`？

在 Pandas 的 `DataFrame` 中，**`df.axes` 是一个属性，返回包含所有轴标签的列表**：

$$\text{df.axes} = [\text{行索引 (index)}, \text{列索引 (columns)}]$$

因此它是一个长度为 2 的 Python 列表：

* **`df.axes[0]`**：表示第 0 轴的标签对象，即**行索引（Row Index）**。
* **`df.axes[1]`**：表示第 1 轴的标签对象，即**列索引（Column Index / 列名）**。

在上一段代码中：

```python
len(X.axes[1])

```

就是取出列索引（所有列名）的长度，也就是**数据表一共有多少列（特征数量 $n_x$）**。

> **更推荐的等价写法**：
> 在实际工程中，获取列数通常有更直观的写法，不需要绕道 `axes`：
> * `X.shape[1]`（NumPy / Pandas 通用，推荐）
> * `len(X.columns)`（Pandas 专属，语义最明确）

### 二、辨析：`axis=0` 到底指行还是指列？

从底层维度定义来看：

* **`axis=0`（第 0 轴）严格指代“行”（纵向/垂直方向）**。
* **`axis=1`（第 1 轴）严格指代“列”（横向/水平方向）**。

无论是数组的形状 `shape`，还是索引 `axes`，都遵循这个顺序：


$$\text{Shape} = (\text{行数, 列数}) = (\text{axis 0 长度}, \text{axis 1 长度})$$

#### 为什么你会觉得“`axis 0` 是列”？
    (其实这个理解也没毛病 行方向 就是一列嘛)

这种混淆源于 Pandas/NumPy 中**聚合函数（如 `mean`, `sum`, `std`）的操作逻辑**：

当你执行求均值操作时：

```python
# 沿着 axis=0（垂直纵向，跨越所有行）压缩数据
df.mean(axis=0)

```

* **计算机的实际行为**：指针沿着第 0 轴（自上而下穿过每一行）把数字加起来求平均，最终把这一列的所有行“压扁”成一个值。
* **人的直观感受**：输出的结果是“TV 列的均值”、“Radio 列的均值”……看上去像是在“算每一列”，因此初学者极易误认为 `axis=0` 代表列。

**记忆法则**：

* **结构定义（静态）**：`axis=0` 是行，`axis=1` 是列（对应矩阵的第 0 维和第 1 维）。
* **函数参数（动态）**：`axis=k` 意味着**沿着该轴的方向把数据压缩坍缩掉**。沿着行方向（`axis=0`）自上而下计算，留下的就是各列的统计值。

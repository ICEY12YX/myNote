#继承
___
在 Python 里，继承（Inheritance）的核心逻辑就四个字：**“直接复用”**。

如果你已经写好了一个类，现在想写一个新类，并且新类刚好需要用到老类里的功能。你不需要把老代码重新抄一遍，只要让新类“继承”老类，新类瞬间就能拥有老类的所有属性和方法。

被继承的类叫**父类**，继承的类叫**子类**。

### 1. 基础语法：如何继承？

继承的语法非常简单，只需要在定义新类时，**在类名后面的括号里写上父类的名字**。

我们继续用 `Calculator` 举例。假设我们现在要造一个“智能计算器”，它不仅能做加法，还能语音播报。

```python
# 这是父类（老一代计算器）
class Calculator:
    def __init__(self, brand):
        self.brand = brand
        
    def add(self, a, b):
        return a + b

# 这是子类（新一代智能计算器）
# 括号里写上 Calculator，表示继承它
class SmartCalculator(Calculator):
    # 那老类的方法不用再写一遍了
    
    # 子类可以自己增加全新的方法
    def voice_broadcast(self, result):
        print(f"正在语音播报：计算结果是 {result}")

# 我们来用一下这个子类
smart_calc = SmartCalculator("智能卡西欧")

# 虽然子类里没有写 add 和 __init__，但它继承了父类的能力，直接就能用！
result = smart_calc.add(10, 20) 
print(f"品牌: {smart_calc.brand}")
smart_calc.voice_broadcast(result)

```

### 2. 方法重写（Override）：青出于蓝而胜于蓝

如果父类里有一个方法，子类觉得它不够好，或者想要换一种方式实现，怎么办？
答案是：**直接在子类里写一个同名的方法**。这就叫“重写”。

当 Python 调用方法时，它会**先在子类自己身上找**。只要找到了，就会直接运行子类的代码，父类的同名方法就被“覆盖”了。
<mark style="background: #FF5582A6;">没有任何关键词需要新增</mark>

```python
class SmartCalculator(Calculator):
    # 重写父类的 add 方法
    def add(self, a, b):
        result = a + b
        print("【智能提示】执行了一次加法运算！")
        return result

smart_calc = SmartCalculator("智能得力")
print(smart_calc.add(2, 3)) 
# 输出: 
# 【智能提示】执行了一次加法运算！
# 5

```

### 3. 最关键的难点：`super()` 的用法

在使用继承时，最容易让人卡住的地方是：**如果我重写了父类的 `__init__` 方法，但我又想保留父类原本的初始化逻辑，该怎么办？**

比如，智能计算器不仅需要 `brand`（品牌），还需要新增一个专属属性 `battery_life`（续航时间）。如果你直接写一个全新的 `__init__`，父类处理 `brand` 的代码就丢失了。
就是,<mark style="background: #FF5582A6;">复用父类函数的一部分功能,而不想全用</mark>

这时候就要请出 `super()` 函数了。**`super()` 的作用就是帮你一键呼叫父类的方法。**

```python
class SmartCalculator(Calculator):
    
    def __init__(self, brand, battery_life):
        # 步骤一：呼叫父类的 __init__，让它去处理品牌（brand）
        # 注意：这里调用 super().__init__ 时，Python会自动把 self 传过去，你不需要写 self！
        super().__init__(brand)
        
        # 步骤二：处理子类自己独有的属性
        self.battery_life = battery_life

smart_calc = SmartCalculator("高端卡西欧", "100小时")

print(smart_calc.brand)         # 这是父类帮忙初始化的
print(smart_calc.battery_life)  # 这是子类自己初始化的

```

# 其他一些用法

你已经掌握了列表中最核心的插入、删除指定值、查询和切片操作！这些确实是非常高频使用的功能。

除了之前学的那些，Python 的列表还有几个极其常用、必须掌握的“压箱底”方法。我把它们分为**追加**、**弹出**和**翻转**三大类：

### 1. 元素追加：`append()` 和 `extend()`

你之前用了 `insert()` 在指定位置插队。但通常情况下，我们最常做的是在列表的**最末尾**加东西。

* **`append(元素)`**：把一个元素硬塞到列表的**最后面**。
* **`extend(列表)`**：把另一个列表里的所有元素，**拆开后**挨个拼接到当前列表的最后面。

```python
c_list = [1, 2, 3]

# append: 每次只能在末尾加一个整体
c_list.append(99)
print(c_list)  # 输出: [1, 2, 3, 99]

# extend: 批量拼接
c_list.extend([4, 5])
print(c_list)  # 输出: [1, 2, 3, 99, 4, 5]

# !!!!!!!-----------------------------------
# 对比一下如果你用 append 加一个列表会怎样：
# c_list.append([4, 5]) 
# 结果会变成 [1, 2, 3, 99, [4, 5]]，列表里套了个列表

```

### 2. 元素弹出：`pop()` 和 `clear()`

你之前用了 `remove(值)` 来根据“长相”删元素。但如果我们想根据“位置”删元素，并且**还想把删掉的元素拿出来用**，就要用 `pop()`。

* **`pop()`**：像拔萝卜一样，把元素从列表里拔出来。默认拔**最后一个**，你也可以指定位置。
* **`clear()`**：一键清空列表。

```python
c_list = [10, 20, 30, 40, 50]

# 默认拔掉最后一个元素，并且可以把它存到一个变量里
last_item = c_list.pop()
print(last_item)  # 输出: 50
print(c_list)     # 输出: [10, 20, 30, 40]

# 拔掉索引为 1 的元素（也就是 20）
item = c_list.pop(1)
print(item)       # 输出: 20
print(c_list)     # 输出: [10, 30, 40]

```

### 3. 原地翻转：`reverse()`

你之前用了 `sort(reverse=True)`，那是先给元素**比大小排序**，然后再倒序。
但有时候我们不关心大小，只想单纯地把队伍**首尾颠倒**，这时候就用 `reverse()`。

```python
c_list = [3, 1, 4, 2]

# 不比大小，直接首尾翻转
c_list.reverse()
print(c_list)  # 输出: [2, 4, 1, 3]

```

### 总结一下你现在的“武器库”：

* **增**：`append()` (末尾增), `insert()` (中间增), `extend()` (批量增)
* **删**：`remove()` (按值删), `pop()` (按位置拔), `clear()` (全删)
* **查**：`index()` (找位置), `count()` (数个数), 切片 `[起:止]` (批量查)
* **改/排**：`sort()` (排序), `reverse()` (纯翻转)

# 列表推导式
列表推导式（List Comprehension）可以说是 Python 里最优雅、最能体现 Python 极简哲学的设计之一。

它的核心作用就是：**把原本需要写好几行的 `for` 循环和 `if` 判断，浓缩成短短的一行代码，并且直接生成一个新的列表。**

### ⭐️只要记住一个核心公式

列表推导式的语法看起来像是一句话，你可以用这个公式来套用它：

`[ 【你要的结果】 for 【拿出来的元素】 in 【原来的列表】 if 【过滤条件】 ]`

注意:
1. ⭐️最外面用`[]` 因为是列表
2. 返回一个新列表
3. 它是相当于拿对应元素 然后append到新列表

*注：其中 `if 【过滤条件】` 是可选的，不需要过滤时可以不写。*

---

### 场景一：极简生成（代替传统的循环 + append）

假设我们现在有一个需求：把 1 到 5 的数字，全都乘以 10，放进一个新列表里。

**以前笨重的写法（需要 4 行）：**

```python
old_list = [1, 2, 3, 4, 5]
new_list = []
for num in old_list:
    new_list.append(num * 10)
print(new_list)  # 输出: [10, 20, 30, 40, 50]

```

**一行代码的“推导式”写法：**

```python
old_list = [1, 2, 3, 4, 5]

# 解读：【把 num*10 作为结果】 for 【每次拿出 num】 in 【old_list】
new_list = [num * 10 for num in old_list]

print(new_list)  # 输出: [10, 20, 30, 40, 50]

```

### 场景二：极简过滤（加入 if 判断）

假设需求变了：我有一个数字列表，我**只想要里面的偶数**，把它们挑出来放进新列表。

**推导式写法（带 `if`）：**

```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

# 解读：【把 num 作为结果】 for 【每次拿出 num】 in 【numbers】 if 【num 除以2余数为0】
even_numbers = [num for num in numbers if num % 2 == 0]

print(even_numbers)  # 输出: [2, 4, 6, 8]

```

你看，Python 就像读英语句子一样自然：*“给我 num，对于 numbers 里的每一个 num，前提是 num 是偶数。”*

### 场景三：边过滤边加工（终极形态）

我们把前两个场景结合起来：我想要挑出原来的列表里的**偶数**，并且把这些挑出来的偶数**乘以 100**。

**推导式写法（全公式形态）：**

```python
numbers = [1, 2, 3, 4, 5, 6]

# 严格按照公式排兵布阵：
# [【加工逻辑】 for 【变量】 in 【列表】 if 【过滤条件】]
result = [num * 100 for num in numbers if num % 2 == 0]

print(result)  # 输出: [200, 400, 600]

```

# 处理方式补充

### 1. 拼接与重复：`+` 和 `*` 

在列表里，你可以用加号和乘号来**生成全新的列表**，原来的列表不会被改变。

```python
list1 = [1, 2]
list2 = [3, 4]

# 生成一个新列表
list3 = list1 + list2 
print(list3)  # 输出: [1, 2, 3, 4]

# 复制元素生成新列表
list4 = list1 * 3
print(list4)  # 输出: [1, 2, 1, 2, 1, 2]

```

### 2. 遍历读取

就是用for...in循环

**列表常用的进阶玩法（强烈推荐）：`enumerate()`**
我们在处理列表时，经常不仅需要里面的**值**，还需要知道它的**位置（索引）**。这时候 Python 提供了一个超级好用的内置工具 `enumerate()`：

```python
my_list = ["苹果", "香蕉", "橘子"]
# enumerate 会同时给你两个东西：位置编号(index) 和 具体的值(fruit)
for index, fruit in enumerate(my_list):
    print(f"第 {index} 个水果是 {fruit}")
# 输出:
# 第 0 个水果是 苹果
# 第 1 个水果是 香蕉
# 第 2 个水果是 橘子

```

### ⭐️ 3. 解包（Unpacking）：完全适用

解包绝不是元组的专利，列表同样可以完美解包！

```python
my_list = [10, 20, 30]

# 直接把列表里的3个元素拆出来，分给a,b,c
a, b, c = my_list
print(a)  # 输出: 10

```

---

### 🚨 绝对不适用的场景（核心区别）

虽然上面的操作列表都能做，但我们在讲元组时提到的“三大使用场景”**，有两项是列表**绝对不能代替的：

1. **不能做字典的键（Key）**：
字典的标签必须是死死固定、不能变化的。元组可以，但列表因为随时能被修改（比如被 `append`），如果你拿列表去当字典的 Key，Python 会直接抛出报错。
2.⭐️ **函数默认返回多个值，依然是元组**：
如果你在函数里写 `return 1, 2`，Python 后台打包出来的依然是**元组** `(1, 2)`，而不是列表 `[1, 2]`。除非你硬性规定 `return [1, 2]`。

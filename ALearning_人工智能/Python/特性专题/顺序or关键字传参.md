```python
# ---------------------------------------------------
def functionB(x, y):  # 函数可以有参数, 也可以没有参数
    z = x + y
    print("the z is", z)  # 这个输出可以注意到,is后面自己带了空格
    print("the z is " + str(z))  # 注意两种print写法
    
functionB(1, 2)  # 顺序传参
functionB(x=4, y=7)  # 关键字传参
# functionB(a=1, b=2)  # 参数名不对, 会报错
```
* **顺序传参 (C 语言的老朋友)：**
    `functionB(1, 2)` 的底层逻辑和你熟悉的 C 语言完全一样。Python 会严格按照位置，把 `1` 塞给第一个参数 `x`，把 `2` 塞给第二个参数 `y`。
* **关键字传参 (Python 独门秘籍)：**
    #关键字传参。 
    `functionB(x=4, y=7)` 是指名道姓地告诉系统：“我要把 4 赋值给 x，把 7 赋值给 y”。
* **⭐最大优势：** 
    一旦使用了关键字，**参数的顺序就不重要了**！
    你完全可以写成 `functionB(y=7, x=4)`，依然能完美运行。

* **错误示范与报错原因：**
    `functionB(a=1, b=2)` 会直接报错（`TypeError`）。因为在定义 `functionB` 时，**系统只注册了 `x` 和 `y` 两个名字**。你突然给它传 `a` 和 `b`，Python 会因为找不到匹配的“接收人”而拒绝执行。
___
### 为什么 AI 开发极其依赖关键字传参？

在未来使用 PyTorch 搭建神经网络时，一个函数或网络层经常会有十几个甚至几十个参数（比如神经元数量、学习率、丢弃率等）。如果全靠“顺序传参”，你根本不可能记住第 8 个参数代表什么，极其容易因为传错位置导致代码跑通但模型学不到东西。而使用“关键字传参”，代码不仅一目了然，还能完美防止这种“幽灵 Bug”。

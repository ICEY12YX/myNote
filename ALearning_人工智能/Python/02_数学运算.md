#### 模块 2：乘方与“异或”陷阱

```python
print(2 ^ 2)
print(2**2)
print(2**3)
print(2**4)
```
* **解释与避坑**：
    这是新手从数学思维转到编程思维时最容易踩的坑。在数学笔记里，我们习惯用 `^` 表示乘方（比如 2^2）。
    **但**在 Python（以及你熟悉的 Java/C++）中，`^` 是**按位异或 (Bitwise XOR)** 符号，属于底层的二进制位运算。
    因此，`print(2 ^ 2)` 的结果是 0，而不是 4。

* **正确写法**：
    在 Python 中，**乘方运算必须连续使用两个星号 `**` 来表示**。
    `2**3` (2 的 3 次方) 输出 8，`2**4` 输出 16。
    这是未来深度学习中计算矩阵维度、调整网络层数时常用的符号。

#### 模块 3：取余与整除 (Python 特色)

```python
print(8 % 2)
print(9 // 4)
```

- **解释**:
    * **取余 (`%`)**：俗称“模运算”，计算除法后的余数。
    * **整除 (`//`)**：这是 Python 独有的“向下取整”除法符号。
        9 除以 4 结果是 2.25，使用双斜杠 `//` 会直接砍掉小数部分，输出整数 2。

* **对比经验 (划重点)**：
    在 C++ 或 Java 里，纯整数相除（如 9 / 4）系统会自动忽略小数，得到整数 2。
    **但在现代 Python 3 中，单个斜杠 `/` 永远是精确除法**  !!!!!!!!!!!!  
    `9 / 4` 会直接输出浮点数 2.25。
    所以在 Python 里，如果你确定只需要整数结果，请务必使用双斜杠 `//`。

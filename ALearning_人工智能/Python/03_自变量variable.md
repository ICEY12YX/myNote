#### 模块 1：最基础的变量定义

```python
fan = 1
print(fan)
```

* **解释**：
    我们在内存里开辟了一个小空间，给它起名叫 `fan`，
    然后把数字 1 放了进去。
    最后把 `fan` 里面的内容打印出来。
* **对比经验 (划重点)**：
    在你熟悉的 Java 或 C++ 中，定义变量必须先声明类型，比如 `int fan = 1;`。
    但在 Python 中，**变量是“动态类型”的**。你不需要告诉系统它是整数还是文本，你直接把值赋给它（甚至不需要像 JavaScript 那样写 `let` 或 `var`），Python 在底层会自动判断类型并分配空间。

#### 模块 2：变量的更新与多项打印

```python
fan = 2
yuan = 3
xie = 4
print(fan, yuan, xie)
```
* **大白话解释**：
    1. `fan = 2`：变量的值是可以随时被替换的。现在 `fan` 里面的数字变成了 2。
    2. `print(fan, yuan, xie)`：`print()` 函数非常强大，如果你想一次性打印多个变量，只需要用**逗号** `,` 把它们**隔开**即可。
* **运行注意**：
    输出 `2 3 4`。
    Python 在用逗号打印多个项时，**默认会在中间加上一个空格**，(不像C, 输出严格按照你要求的格式), 省去了你手动拼接空格的麻烦。

#### 模块 3：多变量同时赋值 (Python 独门秘籍)

```python
fan, yuan, xie = 5, 6, 7
print(fan, yuan, xie)
```

* **解释**：
    这是 Python 特有的一步到位的赋值语法（专业术语叫“ #元组解包 ”）。
    等号左边写几个变量，右边对应写几个值，用逗号隔开。Python 会按顺序，把 5 给 `fan`，6 给 `yuan`，7 给 `xie`。
* **现代 AI 代码应用**：
    这种写法在深度学习中**极其高频**。
    比如未来在使用 PyTorch 训练模型时，经常会遇到一个函数同时返回“预测结果”和“损失值”，我们就可以直接用 `pred, loss = model(data)` 这种极其优雅的语法来同时接收两个值。
    而在 Java 或 C++ 中，实现这个通常需要构建复杂的类或结构体。

#### 模块 4：变量之间的互相计算

```python
fan = 8
yuan = fan * 2
print(yuan)
```

* **解释**：
    变量不仅可以直接被赋值为数字，还可以根据其他变量计算得出。

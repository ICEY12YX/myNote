#### 模块 1：基础的条件循环 (While)

```python
condition = 1
while condition < 10:
    print(condition)
    condition = condition + 1

```

* **解释**：
    只要 `condition` 变量的值小于 10，就一直执行里面包含的代码（打印数字，并让数字加 1）。
    没啥好解释的, python更简洁

* **核心语法差异 (划重点)**：
1. **没有括号和花括号**：
    Python 的 `while` 后面不需要加圆括号 `()`，也没有表示代码块的花括号 `{}`。
2. **冒号与缩进**：
    Python 依靠语句末尾的 冒号 `:`   来开启一个代码块
    并**严格依赖缩进**（通常是 4 个空格或 1 个 Tab）来判断哪些代码属于这个循环。一旦缩进结束，循环也就结束了。

#### 模块 2：死循环 (无限循环)

```python
while True:
    print("I'm True")

```

* **解释**：
    因为条件永远是真实的（`True`），所以这段代码会无休止地疯狂打印 "I'm True"，直到电脑断电或你强行终止它。
* **对比经验**：
    在你学过的前端或 Java 里，布尔值通常是小写的 `true`。
    但在 Python 中，布尔值必须**首字母大写**，即 `True` 和 `False`。

* **🚨 真实环境运行警告 (极其重要)**：
     如果你在 Jupyter Notebook 里直接运行这行代码，你的这个代码块会一直处于 `In [*]`（星号表示正在运行）的状态，并且浏览器页面可能会卡死。
* **自救指南**：
    遇到死循环时，不要慌。在 Jupyter 顶部的菜单栏里，点击那个黑色的**正方形停止按钮 (Interrupt the kernel)**，就能强行打断它，并报出一个 `KeyboardInterrupt` 错误（这是正常的强行中止提示）。

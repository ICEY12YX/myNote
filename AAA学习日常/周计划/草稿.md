#entropy 熵（信息熵 / 不纯度指标） 用大白话来说，“熵（记作 $H(p_1)$）”就是决策树里专门用来给一堆样本的 **“混乱掺杂程度（不纯度 impurity）”打分的尺子**：分数最低是 **$0$ 分**（代表这堆样本里清一色全是猫、或者清一色全是狗，一点杂质都没有，纯度最高）；分数最高是 **$1$ 分**（代表猫和狗正好五五开各占一半，最混杂、最难猜，不纯度封顶）；如果猫狗比例介于全纯和五五开之间（比如 5 猫 1 狗），算出来的熵就会落在 $0$ 到 $1$ 之间——越靠近五五开，熵就越接近 $1$。

#gini_criteria 基尼准则（基尼不纯度） 在开源机器学习工具包（如 Scikit-learn）里经常看到的另一种衡量节点“不纯度”的打分函数。它的函数曲线长相和作用跟“熵（Entropy）”几乎一模一样（也是在全纯时为 $0$，五五开时冲到最高点再回落到 $0$），用来建决策树的效果同样很好。

---

### 1. 为什么要引入“熵（Entropy）”？——量化“半纯不纯”的数据集

* **核心问题**：在上一节中我们知道，如果一堆样本全都是猫（单一类别），那它非常纯净；如果全都不是猫，也非常纯净；但如果猫狗比例介于两者之间，我们该如何用具体的数字来量化这组样本到底有多纯呢？


* **引入“熵”的定义**：为此我们引入 **熵（entropy）**，它是衡量一组数据 **不纯度（impurity）** 的数学指标。


* **定义正例占比 $p_1$ 与熵函数图像 $H(p_1)$**：
* 假设手里有 $6$ 个样本（包含 $3$ 只猫和 $3$ 只狗），我们定义 **$p_1$ 为样本中属于猫的比例（即标签为 $1$ 的正例占比，下标 $1$ 就代表标签 $1$）**，在这个例子里 $p_1 = \frac{3}{6} = 0.5$。


* 按惯例，熵函数用大写字母 **$H(p_1)$** 表示。画出它的函数曲线（横轴是猫的占比 $p_1$，纵轴是熵的值）：


* 当猫狗 **五五开（50-50，$p_1 = 0.5$）** 时，曲线达到最高峰，此时数据最不纯，**熵（不纯度）达到最大值 $1$**；


* 相反，当样本 **全是猫（$p_1 = 1$）** 或 **全不是猫（$p_1 = 0$）** 时，曲线落在最底端，**熵等于 $0$**。







---

### 2. 看图找直觉：5 组猫狗样本的“熵值”演练（每组共 6 只动物）

为了彻底摸透熵的变化规律，老师带着我们在 $H(p_1)$ 曲线上连续测了不同比例的样本组合（数值保留两位有效数字）：

1. **组合一（3 猫 3 狗 $\rightarrow$ 最混杂）**：$p_1 = \frac{3}{6} = 0.5$，查图得 **$H(p_1) = 1$**（不纯度最高）。


2. **组合二（5 猫 1 狗 $\rightarrow$ 比较纯）**：正例占比 $p_1 = \frac{5}{6} \approx 0.83$，在横轴 $0.83$ 处读出对应的熵值约为 **$H(p_1) \approx 0.65$**。


3. **组合三（6 猫 0 狗 $\rightarrow$ 完全纯净）**：$p_1 = \frac{6}{6} = 1$，落在曲线最右端，**$H(p_1) = 0$**。对比可见：当猫的比例从 $\frac{3}{6}$ 变成 $\frac{6}{6}$（从五五开变成清一色全是猫）时，不纯度从 $1$ 一路降到了 $0$（换句话说，纯度一路上升）。


4. **组合四（2 猫 4 狗 $\rightarrow$ 偏混杂）**：$p_1 = \frac{2}{6} = \frac{1}{3} \approx 0.33$，查图读出熵值约为 **$H(p_1) \approx 0.92$**。注意它比刚才“5 猫 1 狗（$0.65$）”更不纯，因为 $\frac{2}{6}$ 比 $\frac{5}{6}$ **更接近五五开（50-50 mix）**，所以算出来的不纯度高达 $0.92$。


5. **组合五（0 猫 6 狗 $\rightarrow$ 完全纯净）**：$p_1 = 0$，落在曲线最左端，**$H(p_1) = 0$**（零不纯度，即清一色全是狗的完全纯净集合）。

### 3. 熵的数学公式拆解与两个关键计算细节

* **引入负例占比 $p_0$ 与完整公式**：
* 既然 $p_1$ 是猫的比例，那么如果样本里有 $\frac{2}{3}$ 是猫，就必然有 $\frac{1}{3}$ 不是猫；于是我们定义“不是猫”的样本比例为 **$p_0 = 1 - p_1$**。


* 熵函数 $H(p_1)$ 的精确数学公式定义为：



$$H(p_1) = -p_1 \log_2(p_1) - p_0 \log_2(p_0) = -p_1 \log_2(p_1) - (1 - p_1)\log_2(1 - p_1)$$


* 如果你在电脑里把这个公式画出来，得到的就分毫不差是刚才看到的那条拱形曲线。




* **细节一：为什么对数要以 $2$ 为底（$\log_2$），而不是自然对数（$\log_e$）？**
* 按惯例计算熵时取以 $2$ 为底的对数，纯粹是为了 **让曲线最高峰的峰值刚好凑成漂亮的整数 $1$**！


* 如果你换成以 $e$ 为底的自然对数（$\log_e$），其实只是把整条曲线在竖直方向上缩放了一下（vertically scales this function），用它来建决策树照样能正常工作；只不过曲线最高点不再是整整齐齐的 $1$，数字读起来没那么直观好懂而已。




* **细节二：遇到 $p_1 = 0$ 或 $p_0 = 0$ 时，$\log(0)$ 没意义怎么办？**
* 当全部样本都是同一类（$p_1 = 0$ 或 $p_0 = 0$）时，公式里会出现 **$0 \log_2(0)$** 这样的式子；严格从数学上讲，$\log(0)$ 是未定义的（实际上等于负无穷大 $-\infty$）。


* 但在计算熵时，按数学惯例我们直接规定 **$0 \log_2(0) = 0$**，这样就能顺理成章地算出 $H(0) = 0$ 和 $H(1) = 0$。




* **彩蛋联想（神似“逻辑回归损失函数”）**：
* 如果你觉得熵的公式看起来跟上一门课学的 **逻辑损失（logistic loss）** 非常像，你的直觉很准！这两条公式长得如此相似背后确实有深刻的数学渊源，不过在本课程中无需深究，直接套用这条熵公式去建决策树就完全够用了。

### 4. 本节小结、开源库里的“基尼准则（Gini）”与下节预告

* **熵的核心特征回顾**：熵函数是衡量数据集不纯度的指标——随着样本中正例占比 $p_1$ 从 $0$ 变到 $1$，它从 $0$ 出发，爬升到最高点 $1$，然后再回落到 $0$。


* **拓展视野——基尼准则（Gini Criteria）**：
* 除了熵之外，还有其他同样遵循“从 $0$ 升上去再降回 $0$”规律的函数；比如你以后用开源工具包时，可能会听到一个叫 **基尼准则（Gini criteria）** 的指标，它的曲线长相跟熵函数非常相似，用来构建决策树效果也很好。

> 1. **写 Python 作业代码时的头号报错雷区（如何优雅避开 `log2(0)` 报错）**：
> 虽然数学上我们口头约定 $0 \log_2(0) = 0$，但在本周的 Python 编程作业里，如果你直接对 $p_1 = 0$ 或 $p_1 = 1$ 调用 `np.log2(p1)`，NumPy 会立刻算出 `-inf`（负无穷），再乘以 `0` 就会吐出致命的 `nan`（Not a Number）导致整个函数报错！所以在写 `compute_entropy(y)` 函数时，一定要先加一句判断：**如果 `p1 == 0` 或 `p1 == 1`，直接 `return 0**`，只有当 $0 < p_1 < 1$ 时才去跑那条对数公式！

> 2. **利用“左右对称性”一秒验算题目**：
> 注意公式里 $p_1$（猫占比）和 $p_0$（狗占比）的地位是完全对称的！这意味着 **“5 猫 1 狗（$p_1 = \frac{5}{6}$）”和“1 猫 5 狗（$p_1 = \frac{1}{6}$）”的熵是 100% 相等的（都是约 $0.65$）**；同理，“4 猫 2 狗”和“2 猫 4 狗”的熵也完全相等（都是约 $0.92$）——做测验题时只看“两派比例离五五开有多近”，就能瞬间比出谁的熵更大！

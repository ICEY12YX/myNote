### 2. 变量命名约定与第 1 层（3 个神经元）的逐个硬编码实现

我们继续使用之前的**咖啡豆烘焙模型（Coffee Roasting Model）**，看看如何接收输入特征向量 `x`，一步步跑完前向传播算出最终输出 `a2`：

* **重返一维数组（单层方括号 `[200, 17]`）**：
因为这次是我们自己用纯 Python + NumPy 写底层实现（不用迎合 TensorFlow 的二维矩阵要求），所以这里直接用**一维数组（1D arrays）**来表示所有的向量和参数——注意代码里只有**单层方括号** `x = np.array([200, 17])`，而不是之前 TensorFlow 里的双层方括号二维矩阵。


* **代码里的变量名怎么对应数学角标？（`w1_1` 代表 $\vec{w}_1^{[1]}$）**：
在 Python 代码里没法直接打上标和下标，所以本页幻灯片采用如下命名规矩：


* **紧跟在字母后面的数字**：代表**方括号上标（即第几层）**；
* **下划线 `_` 后面的数字**：代表**下标（即该层的第几个神经元）**。


* 例如：数学里的 $\vec{w}_1^{[2]}$（第 2 层第 1 个神经元的权重），在代码里就写成变量名 **`w2_1`**；同理，$a_1^{[1]}$ 就写成 **`a1_1`**。




* **逐个神经元写出第 1 层的计算代码（共 3 个神经元）**：
1. **算第 1 层第 1 个神经元 `a1_1`（对应 $a_1^{[1]} = g(\vec{w}_1^{[1]} \cdot \vec{x} + b_1^{[1]})$）**：
```python
x = np.array([200, 17])
w1_1 = np.array([1, 2])
b1_1 = np.array([-1])
z1_1 = np.dot(w1_1, x) + b1_1
a1_1 = g(z1_1)

```


给定参数 `w1_1`（比如 `[1, 2]`）和 `b1_1`（比如 `[-1]`），先用 `np.dot(w1_1, x) + b1_1` 算出点积加偏置 `z1_1`，最后把 Sigmoid 函数 `g` 作用在 `z1_1` 上，就得到了第一个激活值 `a1_1`。


2. **算第 1 层第 2 个神经元 `a1_2`（对应 $a_2^{[1]}$）**：
```python
w1_2 = np.array([-3, 4])
b1_2 = np.array([1])
z1_2 = np.dot(w1_2, x) + b1_2
a1_2 = g(z1_2)

```


完全同理：给定参数 `w1_2`（比如 `[-3, 4]`）和 `b1_2`，先算中间的 `z1_2`，再套上 Sigmoid 函数 `g`，得到 `a1_2`。


3. **算第 1 层第 3 个神经元 `a1_3`（对应 $a_3^{[1]}$）**：
```python
w1_3 = np.array([5, -6])
b1_3 = np.array([2])
z1_3 = np.dot(w1_3, x) + b1_3
a1_3 = g(z1_3)

```


用一模一样的步骤算出第三个激活值 `a1_3`。




* **把 3 个输出打包组合成第 1 层的输出向量 `a1**`：
算出了 `a1_1`、`a1_2` 和 `a1_3` 这三个数字后，用 `np.array` 把它们打包组合进同一个数组里，就得到了第 1 层的最终输出向量 `a1`：


```python
a1 = np.array([a1_1, a1_2, a1_3])

```



---

### 3. 继续手写第 2 层（输出层）并引出下节的“通用循环优化”

* **计算第 2 层（输出层 `a2_1`）**：
拿到第 1 层的输出 `a1` 后，接着用同样的方式实现第 2 层（对应公式 $a_1^{[2]} = g(\vec{w}_1^{[2]} \cdot \vec{a}^{[1]} + b_1^{[2]})$）：


```python
w2_1 = np.array([-7, 8, 9])
b2_1 = np.array([3])
z2_1 = np.dot(w2_1, a1) + b2_1
a2_1 = g(z2_1)

```


设定好第 2 层的参数 `w2_1` 和 `b2_1`，用 `np.dot(w2_1, a1) + b2_1` 算出 `z2_1`（注意这里是拿 `w2_1` 和刚刚打包好的 `a1` 做点积），最后套上 Sigmoid 函数 `g` 得到最终输出 `a2_1`——这就是纯靠 Python 和 NumPy 实现前向传播的全部过程了！


* **发现痛点与下节预告（告别“逐个神经元硬编码 Hard-coding”）**：
* 看着这一整页密密麻麻的代码表达式，你肯定发现了：刚才我们是为每一个神经元单独硬编码（hard coding it for every single neuron）写三四行代码的（有 3 个神经元就手抄 3 遍 `w1_1, w1_2, w1_3`）！


* 如果一层里有 100 个神经元，总不能手抄 100 遍吧？因此在下一节视频中，我们将看看如何**把这段代码大幅简化（用矩阵和循环封装成一个通用的 `dense` 层函数）**，从而优雅地实现任意通用神经网络的前向传播！





> 💡 **避坑/重难点补充**：
> **为什么这节课的代码里突然又变回“单层方括号 `[200, 17]`”了？（别跟上节课混了！）**：
> 很多同学刚在倒数第二节课背熟了“必须写双层方括号 `[[200, 17]]`”，看到这页 PPT 写成 `x = np.array([200, 17])` 一下子又懵了。记住一个最清晰的区分界限：
> 
> 
> * **只要你调的是 `TensorFlow` 的函数**（比如 `layer_1(x)` 或 `model.predict(x)`），就必须遵守 TensorFlow 的规矩，用**双层方括号 `[[...]]`（二维矩阵）**；
> 
> 
> * **只要你是在纯 `NumPy` 里自己手写 `np.dot(w, x)**`（不调用 TensorFlow），那就跟第一门课写线性回归/逻辑回归完全一样，直接用最省事的**单层方括号 `[...]`（一维向量）**就能直接做点积！

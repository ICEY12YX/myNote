总的边缘检测原理
- 边缘是灰度值不连续的结果，这种不连续常可利用求导数方便地检测到。
- 将检测出的边缘点连接成曲线或封闭轮廓

Canny步骤
![[Pasted image 20260106172616.webp]]

1. **高斯平滑（去噪）**
    使用一个高斯滤波器与原始图像进行卷积。
    防止噪声在后续梯度计算中被误判为边缘
2. **计算梯度幅值与方向**
    可以用一阶微分算子sobel,roberts,Prewitt, 或二阶算子拉普拉斯
    计算每个像素点在**水平(Gx)** 和 **垂直(Gy)** 方向上的梯度。再计算得到**梯度幅值**和梯度方向
    将方向归类到四个基本角度之一：**0°（水平）、45°、90°（垂直）、135°**。
3. **非极大值抑制**
    **细化边缘**，将宽边缘“瘦身”为单像素宽边缘
    第2步计算出的**梯度方向**，检查当前像素的梯度幅值**M**是否是该方向上的局部最大值。
        如果是，则保留该点为候选边缘点。
        不是，则将该点幅值**抑制为零**（即不是边缘）。
4. **双阈值检测**
    **去除伪边缘**
    设定两个阈值：**高阈值T_high** 和 **低阈值T_low**
        **强边缘**：任何梯度幅值 > T_high 的点，被标记为**确定的强边缘点**
        **弱边缘**：任何梯度幅值在 T_low 和 T_high 之间的点，被标记为**候选弱边缘点**。
        **抑制**：任何梯度幅值 < T_low 的点，被直接丢弃。
5. **滞后边界跟踪**
    连接真的边缘
    检查每一个**弱边缘点**，如果它在**8邻域内**与任何一个**强边缘点**相连，则认为它是真实边缘的一部分，并保留。否则，将其丢弃。
    (因为弱边缘点可能是噪声引起的,而噪声引起的边缘点不会和强边缘点联通)

应用场景
1. **计算机视觉与模式识别**：如人脸轮廓提取、车辆检测。
2. **医学图像分析**：用于**器官分割、病灶边缘勾勒**。
3. **遥感与地理信息系统**：**提取道路、河流、建筑物**等人工或自然区域的边界。

# Hough变换

意义
    Canny算法得到了一张边缘点图, 边缘点如何连接成轮廓线就用**Hough变换**, **就是一个“投票选举”系统**，专门在散乱的点中，**找出隐藏的直线、圆等规则形状**。
    **对噪声和不连续性的鲁棒性**
        即使边缘点有缺失（断线），只要还有足够多的点分布在一条线上，Hough变换就能把这条线找出来。

原理理解
![[Pasted image 20260106180022.webp]]

原理
- 图像空间中，一条直线表示为：**y = kx + b**
- Hough空间（参数空间）中，我们**把k和b当作坐标轴**。
- **图像空间中的一个点(x₀, y₀)**，对应了**无数条可能经过它的直线**（这些直线的k和b满足 y₀ = kx₀ + b）。在Hough空间里，这**无数条直线**就表现为**一条直线**：**b = -x₀k + y₀**。
- 如果图像空间中有多个点 **共线**，那么它们在Hough空间中对应的多条直线会**相交于同一个点(k', b')**。这个交点(k', b')就代表了图像空间中那条真实直线的斜率和截距。
- 因为k可能无穷大，我们采用另一种方程：**极坐标方程**。![[Pasted image 20260106180252.webp]]

# 图像压缩算法

压缩意义
- **减少存储容量**：原始数字图像数据量巨大,不压缩,硬盘闪存很快就满了
- **提高传输效率**：在有限的信道带宽下，较小的数据文件意味着**更快的传输速度和更低的通信延迟**
- **降低系统成本**: 图像的存储和传输成本降低

压缩分类:
无损压缩
- 压缩后的图像数据能够**完全重构回原始图像**
- 主要消除图像的**数据冗余**（如空间冗余、编码冗余），不涉及任何量化过程。
- 适用于**对图像质量要求极其苛刻，不允许有任何失真的场合**
    医学诊断图像
    遥感图像等
- **游程编码**(RLE)  **哈夫曼编码**  算术编码

有损压缩
- 压缩行为不可逆, 压缩过程中**会丢失部分图像信息**，重构图像与原始图像存在一定差异
- 在消除数据冗余的基础上，**充分利用人眼的视觉冗余**，通过量化等手段，有选择地舍弃对视觉效果影响较小的次要信息。
- 适用于图像质量要求不高的场合
    互联网图像(JPEG)
    流媒体视频
(核心算法流程(JPEG) **“变换+量化+熵编码”**)

行程编码
- 利用**空间冗余**的无损压缩编码
- 将连续的重复 数据值 序列，用一个`（数据值，重复次数）` 的对来表示

哈夫曼编码
- **变长编码**  基于**前缀码**
- 核心思想是：**出现概率高的符号，分配一个短的二进制码；出现概率低的符号，再分配一个长的二进制码**。使整体数据的平均编码长度就最短。

# 视频编解码

概念
(和图像编解码的不同)
- 即对视频压缩,并转换为比特流(码流)的过程
- 视频就是**在一个时间序列上的 一连串的图片**, 如果对每一帧都像压缩JPEG照片一样单独压缩，数据量依然巨大
- 所以它还多出"预测编码"这一流程, **利用单帧画面内的相似性 和 前后帧画面的相似性**   去除空间冗余和**时间冗余**

流程(编码过程)
**帧内/帧间预测**
- **帧内预测**：**利用同一帧内部**已编码部分的空间相关性，来预测当前待编码块。
- **帧间预测**：**利用相邻帧之间**的相关性，来预测当前帧。
**计算残差**
- 用当前在编码的原始图像块，减去上一步得到的**预测块**，得到**残差块**
- (之后就编码残差块了 因为残差数据量通常远小于原始数据)
**变换与量化**
- 将残差块从空间域变换到频域, 目的是**能量集中**
- 对变换系数进行**有损的量化**。对高频系数,采用较大的量化步长,大幅度压缩
**熵编码**
- 对**量化后的系数**、**运动矢量**、**预测模式**等所有信息,进行CABAC上下文自适应的熵编码
- 最终成为输出码流

![[Pasted image 20260107111123.webp]]

运动
运动估计
- 在当前帧中待编码的块，在已编码的参考帧中，**寻找一个内容最相似的匹配块**，并计算出描述两者位置差异的**运动矢量**
    - **运动矢量**：一个`(dx, dy)`的向量，告诉你 **“参考帧里的那个匹配块，相对于当前位置，在水平和垂直方向移动了多少距离”**。
- 同时输出当前块和匹配块的像素差异,就是残差
运动补偿 
- 利用运动估计得到的**运动矢量** 从参考帧中**取出对应的匹配块**，作为当前块的**预测值**。
- 编码端用原始块减去此预测值得到**残差**
- 解码端则将此预测值与解码出的残差相加，以**重建当前块**。

# 作业1

**实验原理**:
- 哈夫曼编码实现无损压缩，使高频符号用短码、低频符号用长码，从而最小化平均码长
- 压缩的本质是用变长码替代固定长码（8 bit，若平均码长 < 8，则实现压缩

**实验步骤**:
1. 读取灰度图像：使用 `cv2.imread(..., cv2.IMREAD_GRAYSCALE)` 加载图像并转为灰度格式；
2. 统计灰度频率：调用 `np.bincount(...)` 计算各灰度值的出现次数；
3. 构建哈夫曼树：通过 `build_huffman_tree()` 按频率自底向上合并节点，生成最优二叉树；
4. 生成哈夫曼编码：利用 `generate_huffman_codes()` 遍历哈夫曼树，为每个灰度值分配唯一变长码；
5. 计算压缩后大小：在 `huffman_compress()` 中累加各灰度频次 × 码长，得到总比特数并转为字节；
6. 计算压缩比：压缩比 = 原始字节数（=像素总数） ÷ 压缩后字节数；
7. 可视化结果：调用 `plot_results()` 输出原图、灰度直方图和编码长度分布图。

# 作业2

**实验原理:**
实验基于**离散余弦变换（DCT）** 实现有损图像压缩
- DCT 能将图像从空域转换到频域，能量集中于低频（即左上角系数），人眼对高频细节（如纹理、噪声）不敏感，为了压缩，所以可舍弃部分高频系数
- 通过量化，达到置零部分 DCT 系数（即舍弃高频系数），再逆变换重建图像，实现压缩

**实验步骤:**
1. 读取灰度图像，并确保尺寸为 8 的倍数（不足则补零）；  
    使用 `cv2.imread(..., cv2.IMREAD_GRAYSCALE)` 读图，再通过 `np.pad(...)` 补零至 8 的倍数；
2. 将图像分块为 8×8 子块，对每块进行 DCT 变换；  
    遍历所有 8×8 块，调用 `dct_2d(block)`（即 `cv2.dct(np.float32(block))`）完成变换；
3. 实施三组操作：  
      ① 保留 50% 幅度最大的 DCT 系数，其余置零；  
       调用 `quantize_by_threshold(dct_block, keep_ratio=0.5)`；  
      ② 保留 25% 幅度最大的 DCT 系数，其余置零；  
       调用 `quantize_by_threshold(dct_block, keep_ratio=0.25)`；  
      ③ 保留全部系数，但将直流分量（DC，即 `[0,0]` 处系数）清零；  
       直接执行 `dct_block[0, 0] = 0`；
4. 对处理后的系数块进行 IDCT 重建，得到三幅压缩图像；  
    分别对三类量化后系数调用 `idct_2d(...)`（即 `cv2.idct(...)`）重建子块，拼合为完整图像；
5. 计算每种方式的压缩比（总系数数 / 非零系数数）和 PSNR；  
    非零系数数通过 `np.count_nonzero(...)` 统计；  
    PSNR 由自定义函数 `calc_psnr(orig, recon)` 按标准公式计算；
6. 可视化对比原图与重建结果；  
    调用 `matplotlib.pyplot.imshow(...)` 绘制四图对比（原图 + 三种重建结果），并输出数值指标表格。

**实验结果：**

第一组图例：**单个 8×8 块的 DCT 分析**

- **左3图**：仅保留 50% 最大幅值系数后的频谱（其余为 0），高频被大量舍弃；
- **左4图**：DC 分量（左上角）被置零后的频谱，整体亮度信息丢失。

**结果分析：**
- 保留 50% 系数，系数减半，压缩比为2.00x，同时PSNR高达48db，即重建图像质量极佳，人眼几乎无法察觉失真，效果较好
- 保留 25% 系数，系数降至 1/4，存储需求显著降低，仍属高质量重建，可能存在轻微模糊或块效应，但因为其4倍的压缩率，实用性较高
- 仅清零 DC 分量，几乎未压缩，但PSNR极低，因为DC 在感知质量中起决定性作用，DC 分量承载图像平均亮度信息，缺失后虽保留细节结构，但全局明暗失准，视觉效果极差

```python
# 设置颜色匹配的容差  
tolerance = 15  
# 创建总掩码，记录所有需要处理的像素  
total_mask = np.zeros(img.shape[:2], dtype=np.uint8)  
  
# 对每个灰度等级进行颜色替换  
for i, gray_level in enumerate(gray_levels):  
    # 创建当前灰度等级的掩码（考虑容差）  
    lower_bound = np.maximum(gray_level - tolerance, 0)  
    upper_bound = np.minimum(gray_level + tolerance, 255)  
  
    mask = cv2.inRange(img, lower_bound, upper_bound)  
  
    # 将匹配的区域替换为目标颜色  
    color_img[mask > 0] = target_colors[i]  
    total_mask = cv2.bitwise_or(total_mask, mask)  
  
    print(f"等级{i + 1}: 匹配像素数 = {np.sum(mask > 0)}")
```

对于灰度等级 `[34, 32, 30]` 和容差15：
- **匹配的像素范围**：
    - B通道：34±15 → [19, 49]
    - G通道：32±15 → [17, 47]
    - R通道：30±15 → [15, 45]
- **匹配条件**：像素的B、G、R三个通道值**同时**在各自范围内

这样就能找到所有颜色接近 `[34, 32, 30]` 的像素点，允许有一定的颜色偏差（容差）

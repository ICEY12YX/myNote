# 作业1

**实验原理**:  (几种算子的特点)
Sobel算子
  - 使用 3×3 可分离梯度核，中心行/列权重为 2，水平/垂直方向因权重集中，响应强
Prewitt 算子
  - 结构与Sobel相似，但是无中心加权，所以平滑能力应该弱于Sobel算子
Roberts 算子
  - 结构为2×2 对角差分，无任何平滑，仅用相邻对角点，定位精度高（亚像素级），但稳定性差
LoG算子
  - 步骤为先高斯低通滤波，再拉普拉斯。LoG 核是旋转对称的，本质是带通滤波器，通过 σ 控制通带中心频率

**结果分析：**

| 算子          | 边缘粗细  | 连续性   | 抗噪性   | 45° 敏感度 | 主要机制       |
| ----------- | ----- | ----- | ----- | ------- | ---------- |
| **Sobel**   | 中粗    | 较好    | 中     | 中低      | 加权一阶导 + 平滑 |
| **Prewitt** | 中     | 中     | 中弱    | 中低      | 均匀一阶导      |
| **Roberts** | 极细    | 差     | 差     | **高**   | 对角一阶差分     |
| **LoG**     | **粗** | **好** | **强** | 中（各向同性） | 高斯平滑 + 二阶导 |
结论：
1. 抗噪性最好：LoG算子
    - 算子内置高斯平滑，先对图像进行**高斯低通滤波**（抑制高频噪声），再应用拉普拉斯算子检测边缘。高斯核的平滑作用能显著削弱随机高斯噪声的影响。
    - 通过调节 σ（高斯标准差），可控制平滑程度和边缘定位精度——σ 越大，抗噪能力越强（但边缘定位越模糊）；在噪声较强时，适当增大 σ 可保持边缘连续性。
    - LoG 核呈旋转对称（“墨西哥帽”形状），对任意方向边缘响应一致，不易因方向性增强噪声。
2. 对 45° 方向边缘最敏感：Roberts 算子
    - 算子的卷积核结构直接对角采样
    - 仅使用相邻对角像素，无水平/垂直邻域加权平均，因此对对角突变最“敏锐”

# 作业2

**实验原理及步骤:**
- Hough 变换: 核心思想是“投票机制” + “参数空间转换”。
    - 任意直线可表示为**ρ = x·cosθ + y·sinθ**
    - 变换的过程是，对每个边缘点 (x, y)，遍历所有可能的 θ（如 0°~179°），计算对应的 ρ。在 (ρ, θ) 参数空间中，对该 (ρ, θ) 位置“投一票”。若多个边缘点共线 → 它们会在同一组 (ρ, θ) 处集中投票。最后提取投票数 > `threshold` 的 (ρ, θ) 对，即为检测到的直线。
- 步骤：
    - 将图像转为转灰度图
    - 运用5×5 核的高斯模糊，降噪，避免边缘检测受噪声干扰
    - Canny 边缘检测，设置阈值为50-150，提取图像中的强边缘点
    - 进行Hough 变换，将边缘点映射到参数空间，检测共线点形成的直线
    - 筛选线，按斜率剔除水平/垂直线 ，按位置保留下半区域。最后绘制车道线

# 1.伪彩色变换

**参考图**:
    ![[Pasted image 20251116164508.webp]]

**原理及核心代码:**
伪彩色处理即将灰度图像中特定的灰度范围映射到预定义的颜色，实现"灰度转彩色"的效果
实验步骤即根据原图6个灰度等级和目标颜色(参考上图彩色降水量图), 定义映射关系,再进行颜色替换,完成伪彩色处理
同时为了美观,保持纯白(255,255,255)和纯黑(0,0,0)背景保持不变

```cpp
# 设置颜色匹配的容差  
tolerance = 15  
# 创建总掩码，记录所有需要处理的像素  
total_mask = np.zeros(img.shape[:2], dtype=np.uint8)  
  
# 对每个灰度等级进行颜色替换  
for i, gray_level in enumerate(gray_levels):  
    # 创建当前灰度等级的掩码（考虑容差）  
    lower_bound = np.maximum(gray_level - tolerance, 0)  
    upper_bound = np.minimum(gray_level + tolerance, 255)  
  
    mask = cv2.inRange(img, lower_bound, upper_bound)  
  
    # 将匹配的区域替换为目标颜色  
    color_img[mask > 0] = target_colors[i]  
    # 将当前等级的掩码合并到总掩码中，记录所有被处理过的像素  
    total_mask = cv2.bitwise_or(total_mask, mask)  
  
    print(f"等级{i + 1}已处理: 匹配像素数 = {np.sum(mask > 0)}")
```
-	核心是做颜色替换时,注意为每个灰度等级设置容差,即一定范围内都算这个灰度等级
如:对于灰度等级 [34, 32, 30] 和容差15
匹配的像素范围：
    - B通道：34±15 → [19, 49]
    - G通道：32±15 → [17, 47]
    - R通道：30±15 → [15, 45]
- 匹配条件：像素的B、G、R三个通道值同时在各自范围内
- 利用mask表示与当前灰度等级匹配的像素位置
mask的含义：
- 值为255的位置：表示原图中对应像素的颜色在 [lower_bound, upper_bound] 范围内
- 值为0的位置：表示原图中对应像素的颜色不在范围内

# 2.彩色图像的去噪

**原理及核心代码:**
```cpp
    # 方法1：均值滤波 
    def mean_filter(image, kernel_size=5):
        return cv2.blur(image, (kernel_size, kernel_size))

    # 方法2：高斯滤波 
    def gaussian_filter(image, kernel_size=5, sigma=1.0):
        return cv2.GaussianBlur(image, (kernel_size, kernel_size), sigma)

    # 方法3：中值滤波 
    def median_filter(image, kernel_size=5):
        return cv2.medianBlur(image, kernel_size)
```
- 均值滤波:
    对每个窗口内所有像素求算术平均值，作为中心像素的新值
    即选一个小方块（比如3×3），把9个像素直接算平均数代替中间的像素
- 高斯滤波:
    和均值类似，但不同位置像素加上了权值, 离中心越近的像素，权重越大；越远权重指数衰减
- 中值滤波:
    对窗口内所有像素值**排序**，取**中位数**作为输出

- 参数:
- kernel_size:
    滑动窗口的边长（必须是**奇数**，如 3, 5, 7…）
    - 调整效果: (三种滤波一样)
        kernel_size越大,滤波效果越强,去噪效果越强,但是看上去越模糊
        过小(比如1),看不出滤波效果,几乎和原图一样

- sigma (高斯滤波独有):
    **高斯函数的标准差**，控制权重分布的“陡峭程度”
    - 调整效果: 
        sigma越大,权重分布更“平坦” , 更接近均值滤波 , **模糊更强**(但是模糊程度的变换不大,也看不出大的区别)

- **结论:**
- 均值滤波:
    - 优点:
        简单快速，适合高斯噪声
    - 缺点:
        容易造成**边缘模糊**（因未区分中心/边缘像素权重）
        无法有效去除**椒盐噪声**（单点极值会拉高平均值）
- 高斯滤波:
    - 优点:
        比均值滤波**更自然**的平滑（因权重连续衰减）
        更好保留**边缘过渡**
- 中值滤波:
    - 优点:
        **极强抑制椒盐噪声**（单点噪声会被排序“挤”到两端，中位数不受影响）
        **较好保留边缘**（因不依赖邻域平均，而是取典型值）
    - 缺点:
        对高斯噪声效果不如高斯/均值滤波
        计算开销稍大（需排序）

但是,以上滤波方法对运动模糊效果一般, 甚至只能让图片更模糊

# 3. 图像锐化

**原理及核心代码:**
```cpp
    # 方法1：拉普拉斯锐化
    def laplacian_sharpen(image, strength=0.8):
        # 应用拉普拉斯算子
        laplacian = cv2.Laplacian(image, cv2.CV_64F)

        # 将锐化效果应用到原图
        sharpened = image - strength * laplacian
        # 防止溢出+转格式
        sharpened = np.clip(sharpened, 0, 255).astype(np.uint8)

        return sharpened

    # 方法2：Sobel边缘增强
    def sobel_sharpen(image, strength=0.3):
        # 计算Sobel梯度
        sobelx = cv2.Sobel(image, cv2.CV_64F, 1, 0, ksize=3)
        sobely = cv2.Sobel(image, cv2.CV_64F, 0, 1, ksize=3)

        # 合并梯度
        sobel_combined = cv2.magnitude(sobelx, sobely)

        # 将边缘信息加到原图
        sharpened = image + strength * sobel_combined
        sharpened = np.clip(sharpened, 0, 255).astype(np.uint8)

        return sharpened
```

- 拉普拉斯锐化:
    二阶微分算子，检测图像中**灰度突变（零交叉点）**。对各向同性边缘响应强，不依赖方向。
- sobel锐化:
    一阶微分近似，分别计算水平与垂直方向梯度。本质是**带平滑的梯度算子**

他们在实际处理上步骤比较类似
- 拉普拉斯锐化:
    先用选取的拉普拉斯核对图像做卷积, 计算拉普拉斯响应值 L
    利用锐化公式   锐化 = 原图 + α × 拉普拉斯结果  计算新像素值
        OpenCV 的`cv2.Laplacian`实现中，核中心为 -4，所以代码里用减来抵消这个负号
    对新像素值做后处理(防溢出+转类型)
- sobel锐化:
    同样做卷积, 计算 Sobel-X 和 Sobel-Y, 
    Sobel-X 和 Sobel-Y"合并", 计算边缘强度
    利用锐化公式   锐化 = 原图 + α × 边缘强度  计算新像素值
    对新像素值做后处理(防溢出+转类型)

- 参数:
- `strength`:
    控制**边缘亮化的强度**,一般取值范围**0.1 ~ 0.6**
拉普拉斯锐化中,分别调节`strength`为0.3 0.6 0.9  图片肉眼可见细节增多,但是越高,图片颗粒感变重,不适合调过高

- **结论:**
- 拉普拉斯锐化:
    锐化效果较好
    - 优点:
        各向同性、适合全局细节增强
    - 缺点:
        对噪声极度敏感（噪声也表现为高频突变），易产生振铃伪影
- sobel锐化:
    锐化效果有,但边缘亮度会增加,对增强轮廓比较有用
    - 优点:
        具方向性、抗噪性较好，输出可用于边缘定位
    - 缺点:
        对弱边缘响应弱, 斜向边缘略有偏差

# 作业1

**步骤:**
1. **加载图像**并转为浮点型；
2. **执行 2D DFT + 中心化**，分离幅度谱与相位谱；
3. **实验组 A**：对幅度谱平移 → 旋转 → 与**原相位谱**合成 → 逆变换；
4. **实验组 B**：对相位谱平移 → 旋转 → 与**原幅度谱**合成 → 逆变换；
5. **可视化**：原/平移/旋转幅度谱 + 重建图A；原/平移/旋转相位谱 + 重建图B。

**核心代码:**
```cpp
# 对图像进行二维离散傅里叶变换（DFT），并分离幅度谱与相位谱
img_float = img.astype(np.float32)
dft = cv2.dft(img_float, flags=cv2.DFT_COMPLEX_OUTPUT)
dft_shifted = np.fft.fftshift(dft)

magnitude_spectrum = np.sqrt(dft_shifted[:, :, 0]**2 + dft_shifted[:, :, 1]**2)
phase_spectrum = np.arctan2(dft_shifted[:, :, 1], dft_shifted[:, :, 0])
magnitude_spectrum_log = np.log(magnitude_spectrum + 1)

# 设置统一的几何变换参数（确保两组实验操作一致）
SHIFT_X = 10   # 幅度/相位谱向右平移10像素
SHIFT_Y = 0    # 垂直方向不平移
ROT_ANGLE = 10 # 逆时针旋转10度

# 实验组 A：固定相位谱，仅对幅度谱进行平移+旋转
mag_shifted = apply_translation(magnitude_spectrum, SHIFT_X, SHIFT_Y)
mag_rotated = apply_rotation(mag_shifted, ROT_ANGLE)
recon_mag = reconstruct_from_mag_phase(mag_rotated, phase_spectrum)

# 实验组 B：固定幅度谱，仅对相位谱进行相同平移+旋转
phase_shifted = apply_translation(phase_spectrum, SHIFT_X, SHIFT_Y)
phase_rotated = apply_rotation(phase_shifted, ROT_ANGLE)
recon_phase = reconstruct_from_mag_phase(magnitude_spectrum, phase_rotated)
```

**实验结果**:
    当幅度谱被修改(相位谱固定), 重建图结构有所保留,但出现模糊、错位或对比度异常
    当相位谱被修改(幅度谱固定),图像结构严重扭曲，几乎无法辨认

**分析原因**:
    幅度谱决定能量分布，平移/旋转破坏频率空间对应关系，相位谱决定频率分量的相对位置和干涉关系，是图像“语义结构”的载体. 因为相位维持结构,所以当幅度谱修改,相位谱固定,重建图像仍能看出部分轮廓结构

**结论**:
    “相位比幅度更重要” —— 在傅里叶变换中，相位谱承载了图像的结构和形状信息，而幅度谱主要影响图像的对比度和亮度。

# 作业2

**实验步骤：**
1. 对灰度图像进行16×16 分块 DCT，得到整图频谱
2. 设计细/粗两种量化表，对 DCT 系数分块量化（舍弃高频）；
3. 分块逆 DCT 重建图像

**量化表设计:**
    细量化表: DC步长为4,高频步长上限是32
    粗量化表: DC步长为16,高频步长上限是128

**核心代码：**
```cpp
# 1. 16×16 分块 DCT 变换（获取频域系数）
img = pad_image_to_multiple(img, block_size=16)
dct_coeff = block_dct(img)

# 2. 设计两种量化表：细量化（保留较多高频） vs 粗量化（丢弃大部分高频）
fine_q, coarse_q = design_quantization_tables(block_size=16)

# 3. 分块量化 DCT 系数（round(DCT / Q) * Q）
quant_fine = quantize_dct_blocks(dct_coeff, fine_q)
quant_coarse = quantize_dct_blocks(dct_coeff, coarse_q)

# 4. 分块逆 DCT 重建图像
recon_fine = block_idct(quant_fine).astype(np.uint8)
recon_coarse = block_idct(quant_coarse).astype(np.uint8)
```

量化表设计
```cpp
freq_dist = np.sqrt(u ** 2 + v ** 2)  
  
# 细量化表：步长 = 2 + 2 * freq_dist，上限 32
fine_table = np.clip(2 + 2 * freq_dist, 2, 32).astype(np.float32)  
fine_table = np.round(fine_table)  
  
# 粗量化表：步长 = 8 + 8 * freq_dist，上限 128
coarse_table = np.clip(8 + 8 * freq_dist, 8, 128).astype(np.float32) coarse_table = np.round(coarse_table)
```

**实验结果**:
    细量化重建图,与原图高度相似，细节基本保留
    粗量化重建图, 局部出现明显 “方块效应”(这个在局部放大图中尤其明显), 部分纹理区域变成平滑色块

**分析原因**:
    量化过程将许多小系数强制归零, 这会导致信息丢失,看上去就是重建图像失真。粗量化表因步长更大，导致更多高频系数归零，失真更严重。
    同时当高频被丢弃（粗量化），图像失去纹理、边缘变钝，但整体结构（低频）仍保留，所以仍能“看得清”。

**结论**:
    DCT 将图像能量集中于低频，量化通过舍弃高频系数实现压缩，但会引入失真。高频系数主要承载图像的细节与纹理信息，其丢失直接表现为图像平滑化与块效应。

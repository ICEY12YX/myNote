# 图像增强的定义+目的+应用场合

理解
    ![[Pasted image 20260106142922.webp]]
    ![[Pasted image 20260106143146.webp]]

定义
- 它是图像处理的基本技术之一
- 图像增强是指根据特定的应用需求，**采用一系列技术手段有目的地改善图像视觉效果**，
- 或将其转换成一种**更适合人或机器进行分析处理的形式**。
- 核心特点是处理结果**具有主观性**，即没有统一的“最佳”标准，而是以是否更适合后续任务为评价依据。

目的
1. **改善主观视觉效果**：针对人类观察者，通过增强图像的对比度、亮度，突出感兴趣的特征，抑制不感兴趣的背景或噪声
2. **突出图像数据特征**：针对计算机分析任务，将图像处理成一种**特征更突出、信息更分离**的格式，为后续的图像分割、特征提取、目标识别等提供高质量的输入。

应用场景
1. **医学影像分析**
2. **遥感与航空航天**
3. **工业无损检测**
4. **多媒体应用市场**：用于数码相机、手机的自动美化、老照片/旧电影修复、图像去雾等日常应用。

# 平滑,锐化滤波

都是空域图像处理技术
平滑
- 用于**衰减或抑制图像高频分量**
- 本质是**像素邻域的平均化（或加权平均化）操作**，通过减小局部区域的灰度突变，达到**模糊图像、消除噪声**的目的。
- 是一种**低通滤波**。
锐化
- **增强图像高频分量**
- 本质是**对像素灰度值进行微分或差分运算**，通过**增强图像中灰度突变的区域（如边缘、轮廓）**，达到**突出细节、使图像看起来更清晰**的目的。
- 是一种**高通滤波**

区别
平滑滤波
- **抹平差异**，牺牲细节来**消除噪声**,但会使图像变模糊
锐化滤波
- **放大差异**，突出细节来**增强边缘**，但会**加重噪声**。

平滑滤波
- (线性)  均值滤波  (高斯噪声)
    用<mark style="background: #FFF3A3A6;">邻域内所有像素灰度值</mark>的算术平均值代替中心像素灰度

# 直方图均衡化

定义
- 基于概率统计的**图像对比度增强方法**
- 通过**重新分配图像像素的灰度级**，使得输出图像的灰度直方图**近似均匀分布**（即在每个灰度级上具有大致相同的像素数）
- 从而**最大限度地增强图像的对比度与视觉效果**。

步骤
1. **统计原始直方图**
2. **计算归一化直方图（即概率）**
3. **计算累积分布函数**
4. **计算均衡化后的新灰度值**
5. **生成新图像**

# DFT,DCT

DFT（离散傅里叶变换）
- 将**有限长度的离散时间/空间信号**从空间/时间域变换到**频率域**的数学工具
- 将信号分解为一系列**不同频率的复指数函数**之和，揭示了信号的频谱构成。
原理 (就背这个吧)
- 图像从我们熟悉的**空间域**，“翻译”到了**频率域**
- 都基于**正交变换**的思想, 用一系列**不同频率、不同方向的余弦和正弦波** 去“拟合”你的图像, 计算出每个波需要的“强度”（系数）是多少。揭示了输入信号的频谱构成

DCT (离散余弦变换)
- **DFT的一个“特化版”**。它**只用余弦波**
- DCT通过巧妙的“折叠”和“对称延拓”方式，更好的处理图像像素值都是**实数**（比如0-255）的情况

为什么变换到新空间
1. **分析**：将信号从难以直接分析特征的“空间域”，转换到易于分析周期性、纹理成分的“频率域”
2. **处理/滤波**：在频率域中，可以根据频率特性方便地操作信号。例如，**低通滤波**保留低频（平滑去噪），**高通滤波**保留高频（锐化边缘）。
3. **图像压缩**: DCT最主要的应用,
    不同于DFT, 自然图像做DCT，发现绝大部分能量（尤其是低频信息）都集中在**变换后矩阵的左上角**（低频区域）
    因为能量集中(并且高频信息不重要)，就可以大胆地对右下角（高频）的系数进行**大尺度量化（甚至归零）**,低频信号小幅度量化,在压缩图像的同时,肉眼几乎看不出区别

# 高通,低通滤波

**DFT/DCT**后图像被表示成**不同频率“波”的组合**。
- **低频波**：代表图像中**变化平缓**的部分，比如背景, 大片天空、皮肤。它们构成了图像的**整体轮廓和基础明暗**。
    
- **高频波**：代表图像中**变化剧烈**的部分，比如物体的**边缘、纹理**，以及**细小的噪声点**。

**低通滤波**/**高通滤波**  
- 在频率域里，**设置一个“关卡”**，只允许低频的“波”通过，而**把高频的“波”拦住或减弱**。

实际做法
1. 在频率域里，图像被表示成一个**系数矩阵**（比如DFT后的复数矩阵，或DCT后的实数矩阵）( **左上角区域对应低频分量**，**右下角区域对应高频分量**)
2. **滤波过程就是用一个“滤波器函数”(一个矩阵)去乘以这个系数矩阵**。
    **低通滤波器** , 这个函数的形状是**中间亮（值大），四周暗（值小）**。乘上之后，**中心低频区域的系数被保留（甚至增强），边角高频区域的系数被衰减（甚至归零）**。
3. **做完乘法后，再进行一次逆变换，把图像从频率域“翻译”回空间域**,就得到滤波的效果

这和在空间域中做平滑,锐化滤波是等效的
- **空域和频域是看待同一事物的两个不同角度，操作是等价的，只是工具和视角不同。**
- **空域平滑/锐化滤波**是在空间域上对图像做卷积操作
- **频域高通/低通滤波**是在频率域上对图像转换后的系数阵做乘法

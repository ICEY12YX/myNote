# 经典机器学习方法
线性回归
- 试图用一个线性方程(比如二维是一条线)去拟合数据点，通过不断调整线性方程的参数(权重和偏置), 使得预测值与真实值之间差距最小
- 这个差距一般用预测值与真实值的“垂直差距”的平方和 来定义。就是均分误差, 即损失函数![[Pasted image 20260102202251.webp]]
- 要找损失函数的最低点,即朝着梯度的负方向移动

线性判别分析(LDA)
- 将高维数据投影到一条直线上,即降维，使得同类数据点尽可能“聚拢”，不同类数据点尽可能“分开”。最后生成线性判别模型, 从而可以对未来的数据进行分类预测

决策树
- **模仿人类做决策时的“if-then规则”**
- 结构是: 每个结点表示在一个属性上的测试; 每个分支代表一个测试输出; 每个叶结点代表一种类别
- 是一个**自顶向下、递归分裂**的过程,关键问题是**当前节点上，应该选择哪个特征来划分数据？从而可以快速分类**
- 以信息熵为度量构造一棵熵值下降最快的树。

朴素贝叶斯
- 基于概率论的贝叶斯定理, 算后验概率对数据进行分类,算的时候类条件概率密度不知, 用到“属性条件 独立性 假设”
- 之所以被称为「朴素」，是因为它假设每个输入变量相互之间是独立的

K均值聚类K-mean
- 无监督学习算法
- 把 n 个点划分到 k 个类,**使得每个类内的点尽可能相似(离本类中心最近)**,类间不相似

支持向量机SVM
- 一种二分类模型
- 寻找一个超平面来对样本进行分割
- 分割的原则是间隔最大化，**在两个类别之间寻找一个“最宽”的“隔离带”，并以隔离带的中心线作为分类边界。**
- 最终转化为一个凸二次规划问题来求解。

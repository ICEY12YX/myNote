# 常用模型评估方法
留出法、k折交叉验证、留一法

留出法  (留一部分做测试)
1. 将数据集随机划分为两个互斥集合
    训练/测试集划分要尽可能保持数据分布的一致性
2. 若干次随机划分+重复实验  
3. 最后取平均值(误差的平均值)
![[Pasted image 20260101163927.webp]]

k折交叉验证
1. 数据集划分为 k 个大小相似的互斥子集, 每次用 k-1 个子集的并集作为训练集，剩下的1个子集作为测试集
2. 这样,对于测试集的选取就有k种,即做k次重复实验,最后取k个测试结果的均值

p 次 k 折交叉验证法
(使用不同的划分重复 p 次) 就是多了个划p次,每次划k个子集

留一法
(就是k折交叉验证中,让k=样本集中样本的总数, 即每个子集里面只有1个样本)
1. (步骤和k折交叉验证)
- 不受随机样本划分方式的影响
- 由于训练集只比总的数据集少一个样本，即训练集特征的概率分布与数据集的分布更接近,所以结果会较为准确
- 数据集较大时,训练开销太大

# 常用回归任务的性能度量
**“模型的预测值，到底离真实值有多远？”**

解释

    ![[Pasted image 20260101165539.webp]]
    ![[Pasted image 20260101165828.webp]]
    ![[Pasted image 20260101165919.webp]]

平均绝对误差（MAE）
- 只求每个样本的**误差绝对值**，再取平均  (在误差为0处不可导)

均方误差（MSE）
- 先求每个样本的**误差平方**，再取平均  (处处可导，**易于优化**)

(注意下面的阈值 决定的是 **模型的预测结果**，**不是真实标签** )

PR曲线  (精度和召回率如何权衡？)
- 横轴是召回率,纵轴是精度
- **不断调整判定阈值**,算出每组召回率和精度,得到一条线
- 曲线越靠近**右上角**（即高 Recall 且高 Precision），模型越好

ROC曲线  (模型区分能力有多强？)
- 横轴是假正例率, 纵轴是真正例率(召回率)
- 理想曲线靠近**左上角**

# 感知器准则
(和上面的Fisher 都是找线的)

基本概念
线性可分
    在二维空间中，如果能用一条直线将两类样本完全分开，就称为**线性可分**。
样本规范化
    定义![[Pasted image 20260102192830.webp]]
    ![[Pasted image 20260102192922.webp]]

解向量
    ![[Pasted image 20260102193015.webp]]
解区
    因为线性可分时，解向量通常不唯一。可能有无数个 α 都能满足αTyi>0
    所有这样的解向量在权值空间中构成的区域，就是**解区**

了解
    ![[Pasted image 20260102193412.webp]]

基本思想
- ![[Pasted image 20260102193427.webp]]
- 感知器算法对已知类别的训练样本集的学习，寻找一个满足上式的权向量。
- 通过赏罚过程
    - 分类正确时，对权向量“赏”——这里用“不罚”，即权向量不变
    - 分类错误时，对权向量“罚”——对权向量进行修改，向正确的方向转换。
- 收敛性：经过算法的有限次迭代运算后，求出了一个使所有样本都能正确分类的W，则称算法是收敛的。
    - 可以证明,样本线性可分, 则感知器算法一定是收敛的

后验概率P(ωi | X)
- 要求的,目标
- 给定样本 X 的条件下，样本 X 属于ωi类的概率。

先验概率P(ωi )
- 根据以前的经验得出的ωi类样本出现的概率，与现在无关

类条件概率P(X | ωi)    或称ωi 的似然函数
- 已知属于ωi类的样本 X 发生的概率

# 正态分布统计决策

解释   (将类条件概率 -> 正态分布的类条件概率密度函数)
    ![[Pasted image 20260101210209.webp]]
    ![[Pasted image 20260101210355.webp]]


为什么要用正态分布？
- 许多实际的数据集, 均值附近分布较多的样本；距均值点越远，样本分布越少。正态分布（高斯分布）正好可以合理近似。
- 同时正态分布数学上比较好处理, 只由两个参数(均值和方差)决定,估计这两个参数不会太难; **对它进行线性变换、求边缘、条件分布，结果仍然是正态分布**。

# 参数估计

背景
- 贝叶斯决策需要已知先验和条件概率密度, 而很多时候这个我们并不会实现知道, 所以要估计这两个东西
- ![[Pasted image 20260101211306.webp]]
(考参数估计)
基本概念
- 概率密度函数的形式已知，而表征函数的参数未知，需要通过训练数据来估计这些未知参数

评价标准  (评价估计量)
- 无偏性   估计量的**期望值（均值）** 等于<mark style="background: #FFF3A3A6;">被估计的总体参数</mark>真实值。 (记)
- 有效性   方差小 = 估计值围绕真实参数的波动小
- 一致性   当样本容量n**趋于无穷大**，估计量依概率收敛于<mark style="background: #FFF3A3A6;">被估计的总体参数</mark>真实值

# 感知器的线性分类及其局限
(单层结构)

概念
- 二分类问题的线性分类模型,单层结构
- 找一个超平面,将数据分为两类
- 输出经过阶跃函数 最后输出类别

局限
- 只能处理线性可分数据, 无法分类线性不可分的数据(如异或问题)
-  **只能得到“某个解”，而非“最优解”**       感知器找到的解**取决于初始值和样本顺序**

# 学习规则

无监督学习规则：Hebb学习规则
- 当两神经元同时处于激活状态时，两者间的连接权值会被加强，否则被减弱。  
    - (如果两个神经元**经常同时被激活**，它们之间的连接应该**增强**；)
- 权值更新 多乘一个学习率  
    (学习率大，每次学习引起的连接强度改变量就大)
![[Pasted image 20260102220622.webp]]

有监督学习规则：Delta学习规则
- 根据神经元的实际输出与期望输出差别来调整连接权值(连接强度)。

# 概念，作用和区别

目的(作用)
- 经过选择或变换，选出任务相关特征子集 或 组成识别特征，尽可能保留分类信息
- 在保证一定分类精度的前提下，减少特征维数，使分类器的工作即快又准确
- 减轻维度灾难
- 降低学习难度

概念
![[Pasted image 20260103202523.webp]]
- **特征选择**：从已有的特征中**挑出**最重要的几个（不改变特征本身）
- **特征提取**：把已有的特征**变换/组合**成几个新的、更有效的特征（改变了特征）

# 遗传算法
(特征选择的算法)

目的 (选出最优的特征组合,进行分类)
- 来源于生物进化论, 算法捕捉了遗传，变异，自然选择的过程
- 解决组合爆炸问题, 特征数多时, 穷举特征不可能, 遗传算法在巨大搜索空间中**智能地寻找近似最优解**
- **捕捉特征间的协同作用**, 即产生1+1>2的效果
- 通过设计适应度函数，**同时优化多个目标** (分类准确率高重要,特征数量少重要)

优点
- **全局搜索能力强**
- **处理特征间的交互关系**
- 适应度函数灵活调整,**同时优化多个目标**

缺点
- **计算成本高**, 每代都要训练多个分类器
- 局部搜索能力弱, 种群很快收敛到全局最优的“附近区域”，但难以精确定位最优解
- **早熟收敛**, 种群多样性快速丧失，所有个体趋于相似,陷入局部最优，无法跳出  (遗传算法是一种贪心算法，容易陷入局部最小)

改进  **模拟退火**结合
- 模拟退火,可以在遗传算法快速找到全局最优区域后,在该区域精细搜索
- 以概率接受稍差的个体，恢复种群多样性, **保持跳出局部最优的能力**

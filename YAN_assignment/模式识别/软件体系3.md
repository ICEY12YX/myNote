```cpp
聚合边界
┌─────────────────────────────────────┐
│          订单聚合（根：Order）        │
│                                      │
│  Order (聚合根)                      │
│    - OrderId id                     │
│    - OrderStatus status             │
│    - Address deliveryAddress        │
│                                      │
│    ┌────────────────────────────┐   │
│    │   OrderItem (内部实体)       │   │
│    │   - ProductId              │   │
│    │   - Quantity(数量)               │   │
│    │   - Price                  │   │
│    └────────────────────────────┘   │
│                                      │
│    ┌────────────────────────────┐   │
│    │   DeliveryInfo (值对象)      │   │
│    │   - ExpectedTime           │   │
│    │   - RiderId (可选)          │   │
│    └────────────────────────────┘   │
└─────────────────────────────────────┘

规则：外部系统不能直接操作OrderItem或DeliveryInfo
      必须通过Order聚合根的方法来操作
```

### **四层架构（最经典）**
```cpp
┌─────────────────────────────────────┐
│         接口层 (Interface Layer)     │ ← 接收HTTP请求，返回JSON
│   - Controller                       │
│   - DTO (Data Transfer Object)       │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│        应用层 (Application Layer)    │ ← 用例编排，事务管理
│   - Application Service              │
│   - 用例：创建订单、取消订单         │
│   - 发布领域事件                    │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│        领域层 (Domain Layer)         │ ← 核心！包含所有DDD战术概念
│   ┌──────────────────────────────┐  │
│   │    聚合（实体、值对象）        │  │
│   │    领域服务                  │  │
│   │    领域事件                  │  │
│   │    仓储接口                  │  │
│   └──────────────────────────────┘  │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│      基础设施层 (Infrastructure)     │ ← 技术实现细节
│   - 数据库实现 (RepositoryImpl)     │
│   - 消息队列                        │
│   - 缓存                            │
│   - 外部API调用                     │
└─────────────────────────────────────┘
```

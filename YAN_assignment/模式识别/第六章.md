# 基本概念
决策树
- **模仿人类做决策时的“if-then规则”**
- 结构是: 每个结点表示在一个属性上的测试; 每个分支代表一个测试输出; 每个叶结点代表一种类别
- 是一个**自顶向下、递归分裂**的过程,关键问题是**当前节点上，应该选择哪个特征来划分数据？从而可以快速分类**
- 以信息熵为度量构造一棵熵值下降最快的树。

信息增益
    **用信息论中的“熵”来衡量一个提问能让数据变纯多少**。
增益率
    信息增益有个**缺点**：它偏向选择**分支多的特征**
    **增益率是“信息增益”除以“特征自身的复杂度”**
基尼指数
    **另一种衡量不纯度的方法**
    应选择那个使划分后基尼指数最小的属性

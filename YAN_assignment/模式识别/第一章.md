# 模式识别、模式分类、人工智能

解释
    ![[Pasted image 20260101152730.webp]]

模式识别:
- 通过一定的算法从数据中**发现、提取**有意义的规律,并根据规律采取决策，如将数据分为不同类别
- 让机器从一堆东西里“认出来”这是什么
模式分类:
- 模式识别后，根据已提取的特征，使用某种分类器将输入数据**自动划分到某个类别**中。
- 让机器把认出来的东西“放进该放的抽屉里”
人工智能:
- 即表现出智能的机器, 它能感知各种环境,背景因素, 并自动采取行动/进行决策, 以最大限度地实现某个目标
- 造一个能自己学会认东西、放东西，还能思考、规划和创造新办法的“机器大脑”。

# 模式类、模式、样本

解释
    ![[Pasted image 20260101154323.webp]]

模式类
- **共享相似或相同模式,特征的一组样本的抽象集合**
- “猫类”
模式
- 从具体样本中抽象出来的特征的集合, 这些抽象出的特征使这个样本区别与其他样本
- 有毛,尖耳朵....
- (为完成识别任务,用模式描述和代替识别对象)
样本
- 从问题域中采集的**一个具体的数据实例**
- 一张猫的照片

# 流媒体协议

**流媒体**是什么?
流媒体就是“边下载边播放”**的音视频技术
![[Pasted image 20250522160814.png]]
![[Pasted image 20250522160831.png]]
![[Pasted image 20250522160843.png]]![[Pasted image 20250522161057.png]]

# 封装格式

封装格式: 主要作用是把视频码流和音频码流按照一定的格式存储在一个文件中。
就像“快递箱子”**，它负责把**视频、音频、字幕、元数据**等“内容”打包成一个文件，并规定它们如何组织在一起

# 视频编码

视频编码: 将视频像素数据（RGB，YUV等）压缩成为视频码流，从而降低视频的数据量。
像H.265,H.264仅仅是一个编码标准，而不是一个具体的编码器,是给编码器的实现提供参照用的。

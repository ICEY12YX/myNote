int refresh_video(void* opaque) {

	}

## part3
```cpp
//循环读取每一帧
while (1) {
	//Wait
	SDL_WaitEvent(&event);
	if (event.type == REFRESH_EVENT) {

		//读取一帧,pixel_w * pixel_h * bpp / 8这么多字节到buffer
		//(但这个1代表以1个字节为单位读)
		if (fread(buffer, 1, pixel_w * pixel_h * bpp / 8, fp) != pixel_w * pixel_h * bpp / 8) {
			// 实现循环播放
			fseek(fp, 0, SEEK_SET);
			fread(buffer, 1, pixel_w * pixel_h * bpp / 8, fp);
		}

		//更新纹理数据(上面只是初始化,这里才是真正给纹理,视频中的图像数据)
		SDL_UpdateTexture(sdlTexture, NULL, buffer, pixel_w);

		//设置显示区域(这里就是全屏)
		sdlRect.x = 0;
		sdlRect.y = 0;
		sdlRect.w = screen_w;
		sdlRect.h = screen_h;

		//渲染三步曲
		SDL_RenderClear(sdlRenderer);  //这个句可写可不写(风险：如果即将显示的纹理有透明部分，则会显示上一帧残留内容)
		SDL_RenderCopy(sdlRenderer, sdlTexture, NULL, &sdlRect);
		SDL_RenderPresent(sdlRenderer);

	}
	else if (event.type == SDL_WINDOWEVENT) {
		//If Resize
		SDL_GetWindowSize(screen, &screen_w, &screen_h);
	}
	else if (event.type == SDL_QUIT) {
		thread_exit = 1;
	}
	else if (event.type == BREAK_EVENT) {
		break;
	}
}
```
(上面是完整的循环内的代码,可以只关注不一样的部分)

首先SDL_WaitEvent(&event); 就是等待一个事件
当线程中有push过来一个事件,WaitEvent就能检测到
然后检查其类型,是REFRESH_EVENT,那就刷新一帧

是SDL_WINDOWEVENT,那就重新获取此时的屏幕长宽,然后改变它(达到自由伸缩屏幕的效果)
是SDL_QUIT,那就让thread_exit = 1,这个等于1时,线程或push进来一个BREAK_EVENT
是BREAK_EVENT,那就退出

总体理解:
就是说先创建了一个线程，然后主线程继续执行到循环出，此时等待event。与此同时，刚刚创建的那个线程已经在执行了，然后线程不退出的情况下，就会创建一个事件，然后这个事件被推到主线程那边，主线程检测到这个事件，然后对照type继续执行。这个事件实际只是起到了一个提醒的作用

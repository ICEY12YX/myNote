# 主要讲了什么事
- **要解决什么痛点？** 现实工业中，机器的运行环境和工况总是千变万化的，这导致收集到的数据分布存在差异（Domain Shift），让本来训练好的模型到了新工况下就“水土不服”；而且，去收集新工况下机器完整的生命周期数据成本太高了 。
- **提出了什么解决方案？** 作者提出了一个名为 **JDATransformer** 的新模型 。它不仅仅是用 Transformer 的注意力机制来抓取机器长期的退化规律 ，还使用了“联合最大均值差异 (JMMD)”技术，没有像以前那样只在网络的一层做对齐，而是在全局多个网络层面上把源域（老工况）和目标域（新工况）的特征拉近对齐了 。

# 研究背景

现代工业环境中,
预测与健康管理（PHM）的核心任务, 即剩余使用寿命（RUL）预测

当前深度学习技术凭借其强大的非线性映射能力，已逐渐取代传统的物理与数学模型，成为 RUL 预测的主流方法

但在实际工业场景中，
- 由于外部环境和运行工况的变化，监测数据往往表现出不同的分布模式 。即**领域偏移**现象
    - 就是,我可能先用特定工况数据来训练模型, 但是真实工业场景下,又是另一种运行工况, 这些（分布）差异会显著降低模型的可靠性
- 同时，在新的运行工况下获取设备整个生命周期的数据是一个耗时且昂贵的过程。通常从成本的角度难以接受

---
理解
    (实验室里训练出来的 AI 模型，到了真实工厂里往往变成“人工智障”。为什么？因为实验室机器跑得慢、负载轻，真实工厂里机器跑得快、负载重。环境一变，机器振动的声音就全变了。而且，你不可能为了收集数据，把工厂里的新机器用到彻底报废，那太费钱和时间了 。)

---
传统方法:
为了缓解上述问题, 迁移学习与域自适应（Domain Adaptation）技术被广泛引入
就是**把在旧机器（也就是“源域”）上学到的知识，直接搬到新机器（“目标域”）上用**
就是迁移学习的手段, (上面不是说,不同工况下,可能发生领域偏移的问题,就是旧新机器,对于机器快坏了,呈现的特征不一样, 模型学到旧机器的特征后,在新机器上实践效果不好 ) 利用一些算法，强行把新老机器的“数据特征”拉近，让它们在 AI 眼里这个"机器快坏了"的特征 看起来差不多的。

局限:
1. 依赖于单层网络的**局部特征对齐**，忽略了全局的分布变化
2. 传统方法过度侧重于空间维度的对齐，从而缺乏捕捉设备长时间跨度下时序退化依赖（Temporal Degradation Patterns）的能力。
(就是, 可能只关注到了某一时刻的变换,没有看长远的退化规律)

本文创新点:
作者觉得，实现高精度的轴承 RUL 预测，
必须同时解决**领域偏移**和**时序退化模式建模**这两个难题。
作者提出 **联合域自适应 Transformer (JDATransformer)** 模型

# 核心方法 JDATransformer 网络架构与联合最大均值差异 (JMMD)

问题定义:
这是个迁移学习的问题
在迁移学习框架中,通常有两个域,源域和目标域

源域（Source Domain，比如旧机器）数据多且标签完整；
目标域（Target Domain，比如新机器）数据分布不同，且往往没有标签或只有少量健康标签。

核心目标是利用源域学到的预测函数，来提升目标域的预测效果。
(好像是之后的JMMD?)

    ![[Pasted image 20260722004105.webp]]

为了达成这个目标,作者选择用"领域适应" (Domain Adaptation)技术实现

核心方法:

总结
    不管是旧机器（源域）还是新机器（目标域）的数据，首先都要送进 Transformer。
    利用“多头注意力”，在一长串振动声音里，把预示着机器要坏的核心故障特征（病根）给揪出来。
    在实际的跨工况场景中，源域和目标域的特征在经过 Transformer 及其后续的全连接层提取后，依然会因为外部环境的改变而产生严重的**分布偏移（Domain Shift）**。也就是说，同样是早期故障，新老机器提取出的特征向量在空间中是完全错位的。
    所以用JMMD进行后续计算
    不断地拉近源域和目标域的联合概率分布，强迫模型去学习一种‘域不变特征’（Domain-invariant features）

为什么用
    通过注意力机制, Transformer模型擅长发现数据中隐藏的相关性, 使其在回归任务中非常有效
    同时Transformer模型捕获远程依赖性的能力,使其能更有效的对整个退化过程进行建模
轴承RUL本质是个回归问题, 目标是捕获振动信号中可能存在的故障信息,以此进行预测


![[Pasted image 20260722020630.webp]]

![[Pasted image 20260722015116.webp]]
Transformer 块主要由三个核心部件构成：
**多头自注意力模块 (multi-head self-attention module)**、
**前馈网络 (feed-forward network)**  
**残差连接 (residual connection)** 。
(即左右中)

1. 输入序列首先经过线性映射，生成查询 (Q)、键 (K) 和值 (V) 矩阵 。
    **查询矩阵 $Q$ (Query)** 代表模型当前的特征匹配需求；
    **键矩阵 $K$ (Key)** 充当序列中各时间步的特征标识；
    **值矩阵 $V$ (Value)** 具体的深层退化信息。
2. 模型通过计算 Q 和 K 的缩放点积来获取注意力分数 (Attention Score)，从而为不同时间步的特征动态分配权重。

3. 在自注意力模块提取出全局依赖特征后，前馈网络通过两个线性层以及中间引入的 **GELU 激活函数**，对数据进行非线性变换
(增强模型拟合能力)

其他
1. **Norm (层归一化 - Layer norm)：** 数据经过各种计算后，大小高低会变得参差不齐。把数据重新拉回一个水平线上
2. 残差连接 (Residual connection), 防止了深层网络训练中可能出现的退化问题

- **$Q K^T$：** 做“点积”，代表了“相似度”, 数值越大，说明这俩信号越般配
- **$\div \sqrt{d_k}$：**  $d_k$ 是维度大小。除以它的平方根, 是因为如果算出来的相似度分数太高，后面的计算就会“上头（梯度消失）”。把分数缩放回正常的范围
- **$\text{softmax}(...)$：** 概率转换函数。分数变成 0 到 1 之间的小数（百分比）
- 乘以 $V$：拿算出来的百分比，去乘以真实的内在条件 ($V$)。得出的结果就是**提炼出的的故障特征**

计算“相似度”, 算出来的数值越大，说明这俩信号越匹配

**$\div \sqrt{d_k}$：** 这里的 $d_k$ 是维度大小。除以它的平方根, 是因为如果算出来的相似度分数太高（比如几万分），后面的计算就会“梯度消失”。让分数缩放回正常的范围。
**$\text{softmax}(...)$：** 概率转换函数。变成 **0 到 1 之间的小数（百分比）**
**乘以 $V$：** 拿算出来的百分比，去乘以真实的内在条件 ($V$)。得出的结果就是**提炼出的故障特征**

<mark style="background: #FFF3A3A6;">通过点积计算出注意力分布，并使用 Softmax 将其归一化为概率权重。最终将这些权重施加在值 (V) 上。</mark>
给整段振动时间里“最异常、最能体现轴承快坏了”的片段赋予最高权重

最终通过拼接与线性融合, 丰富模型对长程时序依赖的捕捉能力。

计算新老机器在多层网络中的**联合分布差异**
![[Pasted image 20260722023548.webp]]
**$z^s$ 和 $z^t$：** 代表老机器（源域）和新机器（目标域）在网络每一层吐出来的特征。
**$\otimes_{l=1}^L$（关键符号：张量积）：** 这里的 $L$ 代表解码器里的多层网络（FC1、FC2、FC3）。即几层的特征乘一起看
**$\left\Vert{} E[...] - E[...] \right\Vert{}^2$（做减法算距离）：** 左边那一坨是老机器的“多层联合特征”，右边那一坨是新机器的“多层联合特征”。两者相减求平方，就是新老机器在全局多层网络里的**总差距**。

引入了**张量积（Tensor Product, $\otimes$）** 操作，将解码器中多个全连接层的隐层表征进行高维融合，构建出源域与目标域的**联合概率分布**。

(但是上面那个是理论公式,实际用的是这个)
$$
\hat{D}_{\mathcal{L}}(P, Q) = \frac{1}{n_s^2} \sum_{i=1}^{n_s} \sum_{j=1}^{n_s} \prod_{l \in \mathcal{L}} k^l \left( z_i^{sl}, z_j^{sl} \right) + \frac{1}{n_t^2} \sum_{i=1}^{n_t} \sum_{j=1}^{n_t} \prod_{l \in \mathcal{L}} k^l \left( z_i^{tl}, z_j^{tl} \right) - \frac{2}{n_s n_t} \sum_{i=1}^{n_s} \sum_{j=1}^{n_t} k^l \left( z_i^{sl}, z_j^{tl} \right)
$$
把**多层网络（$\text{FC}_1, \text{FC}_2, \text{FC}_3$）的所有特征全部绑在一起，** 
Joint Maximum Mean Discrepancy（联合最大均值差异，简称 JMMD）
- $s$ 和 $t$：分别代表 **Source（源域/旧机器）** 和 **Target（目标域/新机器）**。
- $n_s$ 和 $n_t$：分别代表旧机器和新机器样本的数量。
- $z^{sl}$ 和 $z^{tl}$：代表数据在网络第 $l$ 层（比如 $\text{FC}_1$ 或 $\text{FC}_2$）吐出来的特征。
- $\mathcal{Z}$：代表你要对齐的层数的集合（即把 $\text{FC}_1, \text{FC}_2, \text{FC}_3$ 全包了）。
- $k^l(\cdot)$：**核函数 (Kernel Function)**。你可以把它想象成一个“相似度计算器”，把数据丢进去，它能算出两个特征有多像。

总体上就是三项  相当于算"两点间距离"
1. **第一项（源域自己和自己比）**：计算旧机器内部多层特征的联合相似度。
2. **第二项（目标域自己和自己比）**：计算新机器内部多层特征的联合相似度。
3. **第三项（源域和目标域跨域对比）**：计算旧机器和新机器之间的多层联合相似度。
- **最终目的**：把这三项合起来一减，就算出了“旧机器整体”和“新机器整体”的**绝对差距**。
“A的内部 + B的内部 - A与B的交叉”，用来算绝对距离

![[Pasted image 20260722024105.webp]]
总损失函数（Total Loss）

- **$\mathcal{L}_{reg}$（回归损失）：** 考核模型“寿命预测得准不准”。利用有标签的老机器数据，算一算模型预测的寿命和真实寿命差了多少（通常用均方误差 MSE 算）。差得越少，得分越高。
- **$\mathcal{L}_{JMMD}$（对齐）：**  考核模型“新老机器特征拉得近不近”。就是把上面第一张图算出来的多层联合差距放进来，差距越小，说明模型越不受工况变化的影响。
- **$\lambda$（平衡杠杆）：** 这是一个调节系数（比如设为 0.1 或 0.5）。用来平衡两道大题的比重。如果工况环境特别恶劣，数据歪得厉害，就调大 $\lambda$，让模型花更多精力去对齐数据。

损失函数由两部分加权组成：
    1. **回归损失**（$L_{reg}$）
    2. **联合分布差异损失**（$L_{JMMD}$）；

![[Pasted image 20260722175940.webp]]
回归预测损失,就做了个均方误差（MSE, Mean Squared Error）
- $y_i$：**标准答案**。也就是轴承真实的剩余寿命（RUL）标签。
- $\hat{y}_i$：模型根据振动信号自己预测出来的寿命。
- $n_s$ 和 $n_t$：参与训练的源域（旧机器）和目标域（新机器）的样本总数。
- $X_s \cup X_t$：表示把源域和目标域带标签的数据放在一起算。

Source/Target Domain Raw Data -> Pre-process
数据输入和预处理
1. 两边同时输入,
    左边放的是旧机器完整生命周期数据（带有寿命标签）；右边放的是新机器刚开始运行的少量健康数据（没有完全坏的数据）。
2. 进行预处理, 数据清洗、时域与频域的特征提取，并利用滑动窗口策略将其切分为固定长度的时序特征片段 。随后，模型会给数据加上位置编码（Position encoding） 
    - **输入**：原始的水平和垂直振动信号 。
    - **输出**：带有时间位置信息的特征矩阵序列 。
3. 进入前端的 **Transformer 编码器**
    用到多头自注意力机制和前馈网络模块,在全局时间线上自适应地捕获具有**长程依赖关系**的关键退化特征
    - **输出**：包含全局长程退化趋势的深层抽象特征 。
4. 进入解码器
    深层时序特征进入由三层全连接层 (FC1, FC2, FC3) 组成的**解码器**。逐步非线性映射为一维的剩余寿命 (RUL) 预测值。
    - **输出**：预测的剩余寿命数值（图中的 Regression value） 。
以上是源域,目标域数据两边同时进行相同的处理

5. (本文创新点) 联合域自适应 (Domain Adaptation)
    在全连接层往下走的时候，中间伸出了几条线, 将源域和目标域的三层全连接层的激活特征共同提取出来，通过张量积将它们“捆绑”在一起，并计算联合最大均值差异（JMMD）
    - **输出**：联合分布差异损失（$L_{JMMD}$） 。
6. 同时,解码器层输出回归预测损失$\mathcal{L}_{reg}$
    - **输入**：回归损失（$L_{reg}$）和联合分布差异损失（$L_{JMMD}$） 。
    - **输出**：用于反向传播更新整个网络参数的总体误差值（Total Loss） 。

# 实验部分

数据集选择:
![[Pasted image 20260722191035.webp]]

IEEE PHM 2012 数据集（文中简称 Dataset 1）
**数据来源：** 来源于 PRONOSTIA 实验台 。
FOT故障发生时间来源: (用来设置轴承的RUL标签)
    直接取自前人的研究

XJTU-SY 数据集（文中简称 Dataset 2）
**数据来源：** 由西安交通大学和浙江长兴昇阳科技
有限公司联合提供的高加速寿命测试数据集 。
FOT故障发生时间来源: (用来设置轴承的RUL标签)
    根据前人研究的方法,使用3$\sigma$ 计算FOT点

作者分别在两台机器上挑了 3 种不同的转速和压力模式
Load(N) : 载荷
Speed: 转速
Bearing:  挑选的轴承命名, 每种模式下挑了 2 个轴承，一共 6 个轴承

数据预处理:
1. 提取时域特征 (RMS)
    将原始振动信号进行分段，计算每个采样窗口的时域 均方根值 (RMS) ，以此作为代表性的**时域特征 (Time-domain feature)**。
    (衡量这一小段振动到底有“多响、多剧烈”, 机器健康的时候声音平稳（RMS低），快坏的时候肯定声音较响（RMS高）)
2. 提取频域特征 (FFT)
    有时候机器内部某一个零件裂了，会发出特定频率的杂音。
    快速傅里叶变换 (FFT),把杂乱的声音拆解成了高低不同的 20 个频段。然后在每个频段里，挑出振幅最大（最刺耳）的那个音，作为特征。
3. 特征拼接 (Concatenation)
    “1个响度特征”和“20个音色特征”直接拼在一块,形成多维的综合特征向量
4. 滑动窗口策略(Sliding Window)
    为了满足 Transformer 的时序建模需求，引入了**滑动窗口策略 (Sliding-window strategy)** 构建时序输入

其他设置:
Adam优化器, 学习率0.0008, 训练轮数15

评价指标:
RMSE（均方根误差）
MAE（平均绝对误差）


目标:
1. 验证模型在换了工作环境后，不会“水土不服”, 就是在面临显著**领域偏移 (Domain Shift)** 时的迁移泛化能力
2. 为了高度贴合工业现实，在目标域（新工况/新设备）中，**仅使用了少量的早期健康状态数据参与域自适应，没有引入目标域的故障阶段数据**。考验模型在弱监督条件下的知识迁移能力。”

实验场景 :

展望:
1. 计划将全局域自适应策略与特定网络架构进行**解耦 (Decoupling)**，就是现在的JMMD是绑在全连接层上的,作者想后续做成即插即用模块,放到别的网络里也能用
